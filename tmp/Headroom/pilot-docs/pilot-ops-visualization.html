Headroom Pilot Ops View

這個視圖把 dashboard 區塊、fallback 狀態燈號、sidecar health flow 與 rollout checklist 放在同一個操作面板，方便本地 pilot 值班與協作者交接。

Headroom Health

綠燈：/health 與 /stats 正常
核心 sidecar 與觀測都可用

Fallback

黃燈：config 警告或 /stats 失敗
核心可用，但觀測不完整

Incident

紅燈：/health 不可達
立即切回不依賴 dashboard 的工作流

Idle

灰燈：尚未初始化
先檢查 extension、workspace 與 config path
Step 1
載入 extension 與 sidebar webview。
Step 2
尋找 /.agents/pilot/pilot.config.json。
Step 3
若 config 合法，採用 proxy URL、health path、stats path、poll interval。
Step 4
若 config 缺失或損壞，記錄 configError 並 fallback。
Step 5
先檢查 /health，失敗即紅燈。
Step 6
再檢查 /stats，失敗則黃燈。
