# Implementation Plan - Pixel 9a Memory Mitigation (v2.8.6)

This plan addresses the **Graphics Memory Leak** identified in v2.8.5 testing on Pixel 9a, where Graphics memory grew by +91% (116MB -> 223MB). Native heap issues appear resolved.

> [!NOTE]
> v2.8.5 successfully stabilized Native Heap and reduced peak memory by 80MB. The remaining issue is specifically in Graphics/GPU memory.

## Goal Description
Eliminate the Graphics memory leak on Pixel 9a by ensuring proper release of Bitmaps, InputImages, and Surfaces.

## User Review Required
> [!IMPORTANT]
> Investigation requires running `dumpsys gfxinfo` on the device.
> Proposed changes involve explicit resource cleanup which might affect preview smoothness if not handled carefully.
