## 1. 專案背景 (Context)

**專案名稱**: SmartCameraApp (AI Photographer)
**應用類型**: Android 智能相機應用
**套件名稱**: `com.akirachang.ai.photographer`

### 核心功能
SmartCameraApp 是一款 AI 驅動的智能攝影應用，使用 ML Kit 提供：
1. **人臉偵測 (Face Detection)**: 即時偵測人臉位置、眼睛座標、邊界框
2. **物體偵測 (Object Detection)**: 偵測場景中的物體（confidence ≥ 0.5）
3. **構圖分析 (Composition Analysis)**: 基於攝影規則提供即時引導
   - 規則三分法 (Rule of Thirds)
   - 眼睛位置分析 (Eye Position)
   - 頭部空間評估 (Headroom)
   - 邊緣距離檢測 (Edge Distance)
4. **光線分析 (Lighting Analysis)**: 曝光檢測、直方圖分析

### 技術架構
- **架構模式**: Clean Architecture (Domain/Data/Presentation)
- **UI 框架**: Jetpack Compose
- **相機框架**: CameraX
- **ML 框架**: ML Kit (Face Detection + Object Detection)
- **依賴注入**: Hilt
- **測試框架**: JUnit + Robolectric + Mockito + Truth

```kotlin
/**
 * Safe division helper function to prevent NaN propagation
 *
 * v2.5.3: Added comprehensive NaN/Infinity protection
 * - Zero denominator check
 * - NaN input validation
 * - Infinity result validation
 * - Default value fallback
 *
 * @param numerator The dividend
 * @param denominator The divisor
 * @param defaultValue Value to return if division is invalid (default: 0f)
 * @return The division result, or defaultValue if invalid
 */
private fun safeDivide(
    numerator: Float,
    denominator: Float,
    defaultValue: Float = 0f
): Float {
    // Check for zero denominator
    if (denominator == 0f) {
        Log.w(TAG, "safeDivide: Zero denominator detected, returning default value $defaultValue")
        return defaultValue
    }

    // Check for NaN inputs
    if (numerator.isNaN() || denominator.isNaN()) {
        Log.w(TAG, "safeDivide: NaN input detected (numerator=$numerator, denominator=$denominator), returning $defaultValue")
        return defaultValue
    }

    // Perform division
    val result = numerator / denominator

    // Check for invalid result
    if (result.isNaN() || result.isInfinite()) {
        Log.w(TAG, "safeDivide: Invalid result ($result) from $numerator / $denominator, returning $defaultValue")
        return defaultValue
    }

    return result
}
```

```kotlin
override suspend fun detectObjects(
    image: com.google.mlkit.vision.common.InputImage
): List<com.google.mlkit.vision.objects.DetectedObject> {
    return suspendCancellableCoroutine { continuation ->
        objectDetector.process(image)
            .addOnSuccessListener { detectedObjects ->
                // Filter by confidence threshold
                val filteredObjects = detectedObjects.filter {
                    it.trackingId != null ||
                    (it.labels.firstOrNull()?.confidence ?: 0f) >= MIN_OBJECT_CONFIDENCE
                }

                Log.d(TAG, "detectObjects: Detected ${filteredObjects.size} objects (filtered from ${detectedObjects.size})")
                filteredObjects.forEachIndexed { index, obj ->
                    Log.d(TAG, "  Object $index: bbox=${obj.boundingBox}, labels=${obj.labels.size}")
                }

                continuation.resume(filteredObjects)
            }
            .addOnFailureListener { e ->
                Log.e(TAG, "detectObjects: Object detection failed", e)
                continuation.resume(emptyList())
            }
    }
}

companion object {
    private const val TAG = "CameraRepositoryImpl"
    private const val MIN_OBJECT_CONFIDENCE = 0.5f
}
```
