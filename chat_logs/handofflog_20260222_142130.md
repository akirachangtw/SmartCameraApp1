## 1. 專案背景 (Context)

SmartCameraApp v2.11.4 APK 在 Pixel 9a 實機測試發現 3 項問題：

1. **Bug 1（高優先）**：有人臉時，Saliency Auto-Focus 對焦框**完全不出現**。根因：`calculateSaliencyScore()` 使用螢幕尺寸（1080×2340 px）正規化 ML Kit image-space bbox（480×640 px），導致 score 永遠 ≈ 42 < 閾值 50，永遠不觸發。

2. **Bug 2（高優先）**：點擊牙線盒等非人臉物體時，對焦框**偶爾（~1-5% 機率）跑到人臉位置**。根因：`lastManualTapTime` 在 `viewModelScope.launch {}` **內部**設定，而非外部同步設定。若 ML Kit 分析（~48ms 在 Dispatchers.Default）在 coroutine 首行前完成，`autoFocusOnSalientTarget()` 看到舊的 `lastManualTapTime`，誤判為可觸發 → 呼叫 `focusOnPoint(..., isUserTap=false)` → 取消 user tap coroutine → 框移至人臉。

3. **Fix 3（中優先）**：對焦框跟隨速度太慢。v2.11.4 將 `Spring.StiffnessHigh` 改為 `Spring.StiffnessMedium`，過渡時間從 ~150ms 增至 ~400ms，ML Kit bbox 更新頻率 ~100ms，框跟不上。
