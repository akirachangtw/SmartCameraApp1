### 技術規格

**構圖分析演算法 (Rule of Thirds)**:
```kotlin
// 三分法檢查邏輯
fun checkRuleOfThirds(
    faceCenterX: Float,
    faceCenterY: Float,
    imageWidth: Float,
    imageHeight: Float
): Boolean {
    val leftThird = imageWidth / 3f
    val rightThird = imageWidth * 2f / 3f
    val topThird = imageHeight / 3f
    val bottomThird = imageHeight * 2f / 3f
    val tolerance = imageWidth * 0.1f  // ±10% tolerance

    val isHorizontallyAligned =
        abs(faceCenterX - leftThird) < tolerance ||
        abs(faceCenterX - rightThird) < tolerance

    val isVerticallyAligned =
        abs(faceCenterY - topThird) < tolerance ||
        abs(faceCenterY - bottomThird) < tolerance

    return isHorizontallyAligned && isVerticallyAligned
}
```

#### **Phase 3: 完整構圖規則** (預計 2-3 工作日)

**規則清單**:

**Rule 1: Rule of Thirds (增強)**
- 當前: 簡單的交點檢查
- 改進: 四個交點的精確評分系統
- 權重: 30%

**Rule 2: Headroom Check (新增)**
- 檢查人臉上方空間比例
- 理想範圍: 5-15% 畫面高度
- 過多: "Too much headroom"
- 過少: "Too little headroom"
- 權重: 25%

**Rule 3: Edge Distance (新增)**
- 檢查主體與畫面邊緣距離
- 最小邊距: 5% 畫面寬度
- 過於靠近: "Subject too close to edge"
- 權重: 25%

**Rule 4: Subject Detection (增強)**
- 當前: 僅檢查有無人臉
- 改進: 單主體 vs 多主體分析
- 多主體: 選擇最大/最靠近中心者
- 權重: 20%
