## 🚀 三步驟開始

### 步驟 1: 啟動模擬器並安裝應用（2 分鐘）
```bash
# 啟動模擬器（如果未啟動）
emulator -avd <your_emulator_name>

# 安裝應用
./gradlew.bat installEmulatorDebug
```

### 步驟 2: 執行截圖腳本（15 分鐘）
```powershell
.\tools\capture-emulator-screenshots.ps1
```

**操作提示**:
- 腳本會提示您每個測試場景
- 在模擬器上操作到對應場景
- 按 Enter 捕獲截圖
- 輸入 'q' 隨時退出

### 步驟 3: 查看報告（3 分鐘）
- 自動開啟 `index.html`（互動式圖片瀏覽器）
- 查看 `VISUAL_COMPARISON.md`（對比清單）

## 🎯 5 分鐘快速驗證

如果時間有限，僅測試這 5 個關鍵場景：

### 1. 構圖引導框_良好 ✅
```
檢查點:
☑️ 引導框為綠色
☑️ 引導框位置在上三分線附近
☑️ 眼睛在引導框的上 1/3 處
☑️ 無調整提示或顯示「構圖良好」

對比: others/v2.4.6-Testing/optimized/後鏡頭Screenshot_20251213-170034.jpg
```

### 2. 構圖引導框_需調整 ⚠️
```
檢查點:
☑️ 引導框為黃色
☑️ 顯示調整提示（中文）
☑️ 有方向指示器（箭頭）
☑️ 引導框顯示理想位置

對比: others/v2.4.6-Testing/optimized/後鏡頭Screenshot_20251213-170145.jpg
```

### 3. 格線顯示 📐
```
檢查點:
☑️ 兩條垂直線（33%, 67%）
☑️ 兩條水平線（33%, 67%）
☑️ 線條清晰可見
☑️ 不過於突兀
```

### 4. 前鏡頭 🔄
```
檢查點:
☑️ 預覽已鏡像
☑️ 人臉偵測正常
☑️ 引導框位置正確
☑️ 座標轉換正確

對比: others/v2.4.6-Testing/optimized/前鏡頭_20251213-170234.jpg
```

### 5. 構圖提示文字 💬
```
檢查點:
☑️ 文字為繁體中文
☑️ 內容清晰專業
☑️ 背景半透明，文字可讀
☑️ 位置不遮擋主體
```

## 🛠️ 常見問題

### Q: 截圖腳本執行錯誤？
**A**: 確保：
1. 模擬器已啟動（`adb devices` 確認）
2. PowerShell 執行政策允許（`Set-ExecutionPolicy RemoteSigned -Scope CurrentUser`）
3. 應用已安裝

### Q: 截圖檔案太大？
**A**: 截圖為 PNG 格式，單張約 500KB-2MB 是正常的

### Q: 如何手動捕獲單張截圖？
**A**:
```bash
adb exec-out screencap -p > my_screenshot.png
```

### Q: HTML 報告無法開啟？
**A**: 直接用瀏覽器開啟 `screenshots/emulator-testing/session_[timestamp]/index.html`
