**initOrientationListener() 方法修改** (Line 540-566):
```kotlin
private fun initOrientationListener() {
    // v2.9.6 Phase 1 Fix: Read current device orientation before enabling listener
    val windowManager = context.getSystemService(Context.WINDOW_SERVICE) as? WindowManager
    val display = windowManager?.defaultDisplay
    currentRotation = display?.rotation ?: Surface.ROTATION_0
    Log.i(TAG, "Initial device rotation: $currentRotation")

    orientationListener = object : OrientationEventListener(context) {
        override fun onOrientationChanged(orientation: Int) {
            if (orientation == ORIENTATION_UNKNOWN) return

            // v2.9.6 Phase 1 Fix: Mark listener as triggered
            if (!orientationListenerTriggered) {
                orientationListenerTriggered = true
                Log.i(TAG, "OrientationEventListener first trigger confirmed")
            }

            val rotation = when (orientation) {
                in 45..134 -> Surface.ROTATION_270   // Landscape left
                in 135..224 -> Surface.ROTATION_180  // Upside down
                in 225..314 -> Surface.ROTATION_90   // Landscape right
                else -> Surface.ROTATION_0           // Portrait
            }

            if (rotation != currentRotation) {
                currentRotation = rotation
                updateTargetRotation(rotation)
                Log.i(TAG, "Orientation changed: $orientation° → rotation=$rotation")
            }
        }
    }

    if (orientationListener?.canDetectOrientation() == true) {
        orientationListener?.enable()
        Log.i(TAG, "OrientationEventListener enabled")
    } else {
        Log.w(TAG, "OrientationEventListener cannot detect orientation on this device")
    }
}
```

### 技術探索重點

**拍照自動化方案**:
- **方案 A**: ADB UI Automator (使用座標點擊快門按鈕)
  ```bash
  adb shell input tap <x> <y>
  ```
  - 優點: 簡單直接，無需修改 APK
  - 缺點: 座標可能因裝置解析度而異

- **方案 B**: ADB Broadcast Intent (透過 Intent 觸發拍照)
  ```bash
  adb shell am broadcast -a <custom_action>
  ```
  - 優點: 不依賴座標，更可靠
  - 缺點: 需要在 APK 中加入 BroadcastReceiver

- **方案 C**: Instrumented Test (使用 Espresso/Compose Test)
  ```bash
  ./gradlew connectedAndroidTest
  ```
  - 優點: 最穩定，可完整模擬用戶操作
  - 缺點: 需要編寫測試程式碼

**裝置旋轉模擬方案**:
- **方案 A**: ADB accelerometer 模擬
  ```bash
  adb shell content insert --uri content://settings/system --bind name:s:accelerometer_rotation --bind value:i:0
  adb shell content insert --uri content://settings/system --bind name:s:user_rotation --bind value:i:<0|1|2|3>
  ```

- **方案 B**: Display rotation 設定
  ```bash
  adb shell settings put system user_rotation <0|1|2|3>
  ```
