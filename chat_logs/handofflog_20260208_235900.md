#### 2. AspectRatioMode Enum 實作
**檔案**: `presentation/camera/model/AspectRatioMode.kt`

```kotlin
package com.akirachang.ai.photographer.presentation.camera.model

import android.util.Rational
import androidx.camera.core.AspectRatio
import androidx.camera.view.PreviewView

enum class AspectRatioMode {
    RATIO_4_3,
    RATIO_16_9,
    RATIO_1_1;

    fun next(): AspectRatioMode = when (this) {
        RATIO_4_3 -> RATIO_16_9
        RATIO_16_9 -> RATIO_1_1
        RATIO_1_1 -> RATIO_4_3
    }

    val displayName: String
        get() = when (this) {
            RATIO_4_3 -> "4:3"
            RATIO_16_9 -> "16:9"
            RATIO_1_1 -> "1:1"
        }

    val toCameraXAspectRatio: Int
        get() = when (this) {
            RATIO_4_3 -> AspectRatio.RATIO_4_3
            RATIO_16_9 -> AspectRatio.RATIO_16_9
            RATIO_1_1 -> AspectRatio.RATIO_4_3  // ⚠️ 問題！Fallback 到 4:3
        }

    fun toRational(): Rational = when (this) {
        RATIO_4_3 -> Rational(4, 3)
        RATIO_16_9 -> Rational(16, 9)
        RATIO_1_1 -> Rational(1, 1)
    }

    val toScaleType: PreviewView.ScaleType
        get() = when (this) {
            RATIO_16_9 -> PreviewView.ScaleType.FILL_CENTER
            else -> PreviewView.ScaleType.FIT_CENTER
        }
}
```

```kotlin
private fun toggleAspectRatio() {
    val newMode = _state.value.aspectRatioMode.next()
    _state.update { it.copy(aspectRatioMode = newMode, isRebindingCamera = true) }

    viewModelScope.launch {
        try {
            cameraRepository.setAspectRatioMode(newMode)
            Log.i(TAG, "[v2.10.0] Aspect ratio mode toggled: ${newMode.displayName}")
            kotlinx.coroutines.delay(300)
        } catch (e: Exception) {
            Log.e(TAG, "Failed to toggle aspect ratio: ${e.message}", e)
            _state.update { it.copy(error = "切換長寬比失敗: ${e.message}") }
        } finally {
            _state.update { it.copy(isRebindingCamera = false) }
        }
    }
}
```

## 4. 🚨 發現的關鍵問題 (Critical Issues)

### ❌ 問題 1：1:1 模式 WYSIWYG 破壞

#### 症狀
- **Preview 顯示**：正方形（因 FIT_CENTER + 黑邊）
- **Capture 輸出**：**1440 x 1920 (3:4 比例)**
- **結果**：使用者看到正方形，但拍出來是 3:4！

#### 根本原因
**檔案**: `AspectRatioMode.kt` (Line 19-24)

```kotlin
val toCameraXAspectRatio: Int
    get() = when (this) {
        RATIO_4_3 -> AspectRatio.RATIO_4_3
        RATIO_16_9 -> AspectRatio.RATIO_16_9
        RATIO_1_1 -> AspectRatio.RATIO_4_3  // ← CameraX 沒有 RATIO_1_1，fallback 到 4:3
    }
```

**技術限制**：
- CameraX `AspectRatio` 類別只有兩個常數：
  - `AspectRatio.RATIO_4_3`
  - `AspectRatio.RATIO_16_9`
- **沒有 `AspectRatio.RATIO_1_1`！**

#### 影響評估
- ✅ 4:3 模式：可能正常（待驗證實際解析度）
- ❓ 16:9 模式：待驗證實際解析度
- ❌ **1:1 模式：完全錯誤**（WYSIWYG 破壞）

---

### ❌ 問題 2：16:9 模式 FOV 過度裁切

#### 症狀（圖片對比證據）
**Sony 內建相機 vs SmartCameraApp**（檔案位於 `tmp/v2.9.9_zoom-aspect-ratio/`）

| 模式 | Sony 內建相機 | SmartCameraApp | 結果 |
|------|--------------|---------------|------|
| 1:1  | DSC_1-1.JPG (完整 FOV) | SmartAPP_1-1.jpg (1440x1920, 3:4) | ❌ 長寬比錯誤 |
| 4:3  | DSC_4-3.JPG (完整 FOV) | SmartAPP_4-3.jpg (待驗證) | ❓ 待確認 |
| 16:9 | DSC_16-9.JPG (完整 FOV) | SmartAPP_16-9.jpg (明顯放大) | ❌ FOV 過窄 |

**視覺證據**：
- Sony 16:9：包裝袋文字正常大小，完整 FOV
- SmartApp 16:9：包裝袋文字變特寫，FOV 比 Sony 窄約 30-40%

#### 根本原因
**檔案**: `LiveCameraSource.kt` (Line 932-935)

```kotlin
val viewPort = ViewPort.Builder(
    currentAspectRatioMode.toRational(),
    currentRotation
).build()  // ← 沒有設定 ScaleType，預設 FILL_CENTER！
```

**問題**：
- `ViewPort.Builder` 預設使用 **`ViewPort.FILL_CENTER`**（類似 CENTER_CROP）
- 這會對所有 UseCase 的**共同裁切區域**進行額外裁切
- 即使 AspectRatioStrategy 選中正確解析度，ViewPort 仍會裁切以填滿目標長寬比

#### 雙層裁切問題
當前錯誤組合：
```
ViewPort.ScaleType = FILL_CENTER（預設）→ 過度裁切
PreviewView.ScaleType = FILL_CENTER (16:9) → 再次填滿
結果：16:9 被裁切兩次，FOV 過窄！
```

```kotlin

// 改用 toResolutionSelector

fun toResolutionSelector(): ResolutionSelector = when (this) {
    RATIO_4_3 -> ResolutionSelector.Builder()
        .setAspectRatioStrategy(
            AspectRatioStrategy(AspectRatio.RATIO_4_3, FALLBACK_RULE_AUTO)
        ).build()

    RATIO_16_9 -> ResolutionSelector.Builder()
        .setAspectRatioStrategy(
            AspectRatioStrategy(AspectRatio.RATIO_16_9, FALLBACK_RULE_AUTO)

        .setResolutionStrategy(
            ResolutionStrategy(
                Size(1920, 1920),  // 固定正方形解析度
                FALLBACK_RULE_CLOSEST_HIGHER_THEN_LOWER
            )
        ).build()
}
```
