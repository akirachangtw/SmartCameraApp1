## 1. 專案背景 (Context)

SmartCameraApp1 是一個 Android AI 攝影助手，使用 CameraX + ML Kit + OpenCV。
目前焦點是 Optical Flow (OF) 追蹤功能的穩定性改善，讓用戶點擊畫面後，對焦框能持續「黏著」主體移動。

### 根本問題（已解決）
`OpticalFlowTracker` 中 `trackedCenter` 同時作為：
1. UI 輸出（需 velocity clamp 防抖）
2. `detectFeatures()` 的 ROI 中心（需精確位置）

快速移動時 clamp 造成 center 落後 300+px → redetection ROI 偏離主體 → LK 追蹤背景特徵 → 2-cluster → RANSAC median≈0 → quality LOST

## 4. 最新交付成果 (Latest Deliverable)

### 4A. OpticalFlowTracker.kt（核心架構 — 關鍵變更）

```kotlin
// === 關鍵欄位：兩個 center 分開 ===
private var trackedCenter: Point? = null   // Clamped center (UI output only)
private var logicCenter: Point? = null     // Unclamped true center (ROI redetection base)

// === startTracking() ===
val initialX = initialPoint.x * scaleX
val initialY = initialPoint.y * scaleY
trackedCenter = Point(initialX, initialY)  // UI output (clamped)
logicCenter = Point(initialX, initialY)    // ROI base (unclamped)

// === track() — isValid 成功路徑 ===
// newCenter = logicCenter + median, clamped to frame bounds
val newCenter = Point(
    (logicCenter!!.x + medDx).coerceIn(0.0, (downsampledGray.width() - 1).toDouble()),
    (logicCenter!!.y + medDy).coerceIn(0.0, (downsampledGray.height() - 1).toDouble())
)

if (isValid) {
    logicCenter = newCenter                        // unclamped true position
    val uiDistance = calculateDistance(trackedCenter!!, newCenter)
    trackedCenter = clampVelocity(trackedCenter!!, newCenter, uiDistance)  // clamped UI

    // 周期性 redetection 使用 logicCenter（關鍵修復）
    if (redetectionFrameCount >= config.redetectionInterval) {
        detectFeatures(downsampledGray, logicCenter!!)
    }

    return TrackingResult(
        point = scalePointToOriginal(trackedCenter!!),  // UI uses trackedCenter
        ...
    )
}
```
