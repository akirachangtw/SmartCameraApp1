**相關檔案**:
- `AnalyzeCompositionUseCase.kt` (lines 130-220)

**演算法**:
```kotlin
// 三分線位置計算
val leftThird = imageWidth / 3
val rightThird = imageWidth * 2 / 3
val topThird = imageHeight / 3
val bottomThird = imageHeight * 2 / 3

// 方向向量
directionX = when {
    faceCenterX < leftThird -> -0.5f  // 相機向右移
    faceCenterX > rightThird -> 0.5f  // 相機向左移
    else -> 0f
}
```

- ✅ 中文建議提示
  - 「頭部空間略多，可微微上提手機」
  - 「頭部空間不足，可稍向下移動」

**相關檔案**:
- `AnalyzeCompositionUseCase.kt` (lines 250-280)

**評分機制**:
```kotlin
val headroomRatio = faceTop / imageHeight
val headroomScore = when {
    headroomRatio < IDEAL_HEADROOM_MIN ->
        (headroomRatio / IDEAL_HEADROOM_MIN).coerceAtLeast(0f)
    headroomRatio > IDEAL_HEADROOM_MAX ->
        1f - ((headroomRatio - IDEAL_HEADROOM_MAX) / 0.3f)
    else -> 1f // Perfect
}
```
