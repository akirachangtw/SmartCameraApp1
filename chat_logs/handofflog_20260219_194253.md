## 1. 專案背景 (Context)

**專案**：SmartCameraApp1 — Android AI 攝影助手
**分支**：`feature/camera-core-v2.11.0`
**測試裝置**：Pixel 9a (Device ID: `59131JEBF17244`)
**版本**：v2.11.2 第三輪修復

本 session 修復了 OF (Optical Flow) 追蹤框偏移量 2.24x 過大的問題（Fix G）。

**問題根因**：
`SmartCameraAnalyzer.startOpticalFlowTracking()` 使用 `CoordinateMapper.previewToImage()` 進行座標轉換，採用 CENTER_CROP 縮放公式（`max(scaleX, scaleY)`），但實際預覽是 FIT_CENTER（`min(scaleX, scaleY)`）。

數學驗證（1:1 模式, image=1920×1920, PreviewView=1080×2424）：
- `CoordinateMapper` CENTER_CROP：`uniformScale = max(0.5625, 1.2625) = 1.2625` ❌
- `CoordinateTransformer` FIT_CENTER：`scale = 1080/1920 = 0.5625` ✅
- 偏差：`1.2625 / 0.5625 = 2.24x` → 框移動量是正確值的 2.24 倍

**修復方向**：在 `CameraViewModel` 層用 `CoordinateTransformer`（正確）取代 `CoordinateMapper`（錯誤），並在 `SmartCameraAnalyzer` 新增 image-coords 直接輸入的方法，使 `analyze()` 和 `trackFromBitmap()` 回傳 image coords 讓 ViewModel 轉換。

```

  ↓ CameraViewModel.focusOnPoint()

  ↓ cameraRepository.startOpticalFlowTrackingImageCoords(imageX, imageY)
  ↓ SmartCameraAnalyzer.startOpticalFlowTrackingImageCoords()  [no CoordinateMapper]

Every frame:
  ↓ OpticalFlowTracker.track()  → TrackingResult(point in IMAGE coords)
  ↓ SmartCameraAnalyzer callback  [no CoordinateMapper.imageToPreview]
  ↓ CameraViewModel.setupOpticalFlowTracking callback
  ↓ transformer.imageToScreen(imageX, imageY)  [FIT_CENTER, correct scale]
  ↓ _state.update { focusPoint = Pair(screenX, screenY) }
  ↓ FocusIndicator draws at correct screen position ✅
```
