## 1. 專案背景 (Context)

SmartCameraApp1 是一個 Android AI 攝影助理 App，使用 CameraX + ML Kit。
本 session 目標：完成雙鏡頭對焦（AF）完整功能，使其達到現代手機內建相機的基本 AF 水準。

- 前後鏡頭：對焦框恆為正方形（AR clamp bug）
- 後鏡頭人臉：偶發 `OperationCanceledException` → 不必要的 backoff
- 後鏡頭物件：框不準物件（bbox 座標映射錯誤）

// Fixed-focus lenses (e.g. Pixel 9a front camera) have no VCM motor;
// startFocusAndMetering(FLAG_AF) always returns isFocusSuccessful=false,
// causing AfState to enter endless FAILED→backoff loops.
// Instead: trigger AE+AWB only (exposure/white-balance still benefit from
// metering point) and return success immediately so ViewModel sets AfState.Locked.

        focusPoint,
        androidx.camera.core.FocusMeteringAction.FLAG_AE or
                androidx.camera.core.FocusMeteringAction.FLAG_AWB
    ).apply {
        setAutoCancelDuration(4, java.util.concurrent.TimeUnit.SECONDS)
    }.build()
    cameraControl.startFocusAndMetering(aeOnlyAction)
    continuation.resume(Result.success(Unit))
    return@suspendCancellableCoroutine
}

// Build focus metering action (autofocus-capable lenses)
// v2.12.0-06 H2.1: Add FLAG_AE so rear-camera HAL can gate exposure before locking AF.
// v2.12.0-06 H2.2: autoCancelDuration 5s→4s

### 4b. `CameraScreen.kt` — Focus Frame Clamp（⚠️ 仍有 Bug，v2.12.0-08 待修）

目前程式碼（約 line 717-733）— **有 bug，下一步要修**：
```kotlin
// v2.12.0-06 H3.3: Aspect-ratio-preserving clamp — avoids degenerating rectangles into squares.
// Independent coerceIn() on W and H (old code) could turn a 5:1 bbox into 48×48 square.
// Fix: scale both axes uniformly so neither exceeds maxDp, then floor each to minDp.
val (targetWidthDp, targetHeightDp) = if (focusFrameWidthPx > 0f && focusFrameHeightPx > 0f) {
    val rawW = with(density) { focusFrameWidthPx.toDp() }
    val rawH = with(density) { focusFrameHeightPx.toDp() }
    val minDp = 48.dp
    val maxDp = 200.dp
    // Compute a single uniform scale-down so the larger axis fits within maxDp.
    val scaleDown = minOf(
        if (rawW > maxDp) maxDp / rawW else 1f,
        if (rawH > maxDp) maxDp / rawH else 1f
    )
    val scaledW = (rawW * scaleDown).coerceAtLeast(minDp)  // ⚠️ BUG: 獨立 floor 破壞 AR
    val scaledH = (rawH * scaleDown).coerceAtLeast(minDp)  // ⚠️ BUG: 同上
    scaledW to scaledH
} else 48.dp to 48.dp
```

**v2.12.0-08 修復方式**（用此替換上方程式碼）：
```kotlin
// v2.12.0-08: Full AR-preserving clamp (scale-down AND scale-up, both uniform).
// Bug fixed: independent coerceAtLeast(minDp) on W and H broke aspect ratio —
//   e.g. rawW=36dp, rawH=43dp both got floored to 48dp → square (wrong).
// Fix: after scale-down, check if either dim < minDp and scale BOTH up uniformly,
//   so the smaller dimension reaches minDp while preserving the original aspect ratio.
val (targetWidthDp, targetHeightDp) = if (focusFrameWidthPx > 0f && focusFrameHeightPx > 0f) {
    val rawW = with(density) { focusFrameWidthPx.toDp() }
    val rawH = with(density) { focusFrameHeightPx.toDp() }
    val minDp = 48.dp
    val maxDp = 200.dp
    // Step 1: Uniform scale-down so the larger axis fits within maxDp.
    val scaleDown = minOf(
        if (rawW > maxDp) maxDp / rawW else 1f,
        if (rawH > maxDp) maxDp / rawH else 1f
    )
    val downW = rawW * scaleDown
    val downH = rawH * scaleDown
    // Step 2: Uniform scale-up so the smaller axis reaches minDp (preserves AR).
    val scaleUp = if (downW < minDp || downH < minDp) minDp / minOf(downW, downH) else 1f
    (downW * scaleUp) to (downH * scaleUp)
} else 48.dp to 48.dp
```
