## 1. 專案背景 (Context)

### 核心問題
用戶在 Pixel 9a 實機測試 v2.9.9 Day 1-2 Traycer v2 專業對焦系統時，回報兩個關鍵問題：

1. **追蹤不精準**：點擊 Sony 耳機盒上的點 A 後移動手機，圓圈無法精準跟隨同一個視覺特徵點
2. **Fade-out 行為錯誤**：對焦成功後自動淡化消失，應該變成透明 Alpha 0.7 且持續顯示

### 問題根源分析
經過完整的座標系統驗證後，發現：

- **✅ 座標系統正確**：Compose Canvas → PreviewView → ImageAnalysis 轉換無誤
- **⚠️ ML Kit Tracking 限制**：
  - ML Kit 物件偵測的 BoundingBox 太大（幾乎覆蓋整個畫面）
  - trackingId 不穩定（不斷變化）
  - 無法精準定位「物體上的特定局部點」（如耳機盒角點 A）

### 解決方案
1. **短期**：修正 fade-out 行為（本次對話已完成）
2. **長期**：實作 Optical Flow Point Tracking（下一對話開始）

```kotlin
    // v2.9.9 Day 1-2: Lock mode - fixed alpha 1.0
    // v2.9.9 Day 1-2 Optimize: Fade-out animation support
    val alpha by animateFloatAsState(
        targetValue = when {
            isTracking || isLocked -> 1.0f  // Tracking/Lock: alpha 1.0
            isFading -> 0.7f  // v2.9.9 Day 1-2 Optimize: Fading out to 0.7 (persistent visibility)

        animationSpec = if (isFading) {
            tween(durationMillis = 500)  // v2.9.9 Day 1-2 Optimize: 500ms fade-out
        } else {
            tween(durationMillis = 500)
        },
        label = "focus_alpha"
    )
```
