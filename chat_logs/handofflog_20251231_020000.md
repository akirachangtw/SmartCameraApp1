## 5. Problem Solving

### Problem 1: Real Device Camera System Failure
**Symptoms**: 
- Preview black screen during use
- "Not bound to a valid Camera" error when taking photos
- Front camera switch not working

**Root Cause Identified**: 
Two independent camera management systems in the app:
- **System A (LifecycleCameraController)**: Used for takePicture(), switchCamera(), HDR control
- **System B (ProcessCameraProvider/LiveCameraSource)**: Used for preview stream, image analysis

When user switched cameras, only System A was updated, causing System B to remain bound to the old camera, resulting in black screen and capture failures.

**Solution Implemented**:
1. Synchronized switchCamera() to call both systems
2. Added defensive error handling in bindToLifecycle()
3. Added camera binding check before takePicture()

**Status**: Fixes implemented and built successfully, ready for device installation and testing

### Problem 2: Why Emulator Worked But Device Failed
**Analysis**: Emulator uses StaticImageSource (test images) which doesn't use CameraX at all, so dual system conflict never triggered. Real device uses LiveCameraSource with actual CameraX, exposing the architectural flaw.
