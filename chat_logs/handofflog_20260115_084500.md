## 🎯 三個核心問題與根本原因

### 問題 1：後置鏡頭橫向拍照方向錯誤
**現象**: 橫向拍照時，照片在圖庫顯示方向錯誤（逆時針旋轉 90 度）

**根本原因**:
`LiveCameraSource.kt:664` - ImageCapture.targetRotation 被固定為 `Surface.ROTATION_0`

```kotlin
// ❌ 當前代碼（錯誤）
imageCapture = ImageCapture.Builder()
    .setCaptureMode(ImageCapture.CAPTURE_MODE_MAXIMIZE_QUALITY)
    .setTargetRotation(Surface.ROTATION_0)  // 永遠是豎屏
    .build()
```

**影響範圍**: 所有橫向拍照（前後鏡頭皆受影響）

**測試證據**:
- `tmp/v2.9.5_Testing/Smartcamera橫向_074.jpg` - App 拍攝（方向錯誤）
- `tmp/v2.9.5_Testing/內建相機橫向_DSC_2747.JPG` - 內建相機（正確）

---

### 問題 2：預覽畫面模糊
**現象**: 預覽畫面解析度低，在 1080p+ 螢幕上顯示模糊

**根本原因**:
`LiveCameraSource.kt:1175` - 解析度限制過於保守（最大 800x600）

```kotlin
// ❌ 當前代碼（過於保守）
// Ultimate fallback
return Triple(Size(640, 480), 800, 600)  // Sony XQ-BT52 螢幕是 1080x2520
```

**技術細節**:
- Sony XQ-BT52 螢幕解析度: 1080x2520
- 當前 Preview 解析度: 800x600
- 放大倍率: 2.7x → 視覺上嚴重模糊

---

### 問題 3：照片清晰度低於內建相機
**現象**: 照片細節流失，不如原生相機清晰

**根本原因**: 二次壓縮流程

**當前流程（錯誤）**:
```
Camera Sensor → ImageProxy (YUV原始數據)
              ↓ 解碼
           Bitmap (ARGB記憶體格式)
              ↓ 壓縮 JPEG 95%
           JPEG 檔案 → MediaStore
```

**問題點**:
1. CameraX 已經產生優化的 JPEG
2. App 將其解碼為 Bitmap（耗記憶體 + 可能降樣）
3. App 再次壓縮為 JPEG（累積有損壓縮）

**相關檔案**:
- `LiveCameraSource.kt:436-528` - takePicture() 使用 Bitmap callback
- `CameraRepositoryImpl.kt:184-237` - saveBitmapToMediaStore() 二次壓縮

### Step 2: 實作 initOrientationListener()

**插入位置**: `bindToLifecycle()` 方法內部，UseCase 綁定之前

```kotlin
private fun initOrientationListener() {
    orientationListener = object : OrientationEventListener(context) {
        override fun onOrientationChanged(orientation: Int) {
            if (orientation == ORIENTATION_UNKNOWN) return

            val rotation = when (orientation) {
                in 45..134 -> Surface.ROTATION_270   // Landscape left
                in 135..224 -> Surface.ROTATION_180  // Upside down
                in 225..314 -> Surface.ROTATION_90   // Landscape right
                else -> Surface.ROTATION_0           // Portrait
            }

            if (rotation != currentRotation) {
                currentRotation = rotation
                updateTargetRotation(rotation)
                Log.d(TAG, "Orientation changed: $orientation° → rotation=$rotation")
            }
        }
    }

    if (orientationListener?.canDetectOrientation() == true) {
        orientationListener?.enable()
        Log.i(TAG, "OrientationEventListener enabled")
    } else {
        Log.w(TAG, "OrientationEventListener cannot detect orientation")
    }
}
```

---

### Step 3: 實作 updateTargetRotation()

```kotlin
private fun updateTargetRotation(rotation: Int) {
    if (::preview.isInitialized) {
        preview.targetRotation = rotation
    }
    if (::imageAnalysis.isInitialized) {
        imageAnalysis.targetRotation = rotation
    }
    if (::imageCapture.isInitialized) {
        imageCapture.targetRotation = rotation
        Log.d(TAG, "ImageCapture targetRotation updated: $rotation")
    }
}
```
