## 🎨 UI 元素詳細說明

### 1. 構圖引導框（Composition Guide Frame）

#### 良好構圖（綠色框）
```
特徵:
- 顏色: #4CAF50 (綠色) 或 Green 400
- 線條寬度: 3-4dp
- 圓角: 8-12dp
- 透明度: 80-90%
- 位置: 眼睛在框的上三分處
- 動畫: 淡入 (300ms)

視覺效果:
    ┌──────────────┐
    │              │
    │   [眼睛👀]   │  ← 在框的上 1/3
    │              │
    │              │
    │              │
    └──────────────┘
    🟢 綠色線條
```

#### 需調整構圖（黃色框）
```
特徵:
- 顏色: #FFC107 (琥珀色/黃色) 或 Amber 500
- 線條寬度: 3-4dp
- 圓角: 8-12dp
- 透明度: 80-90%
- 位置: 顯示理想位置（非當前人臉位置）
- 動畫: 輕微脈動 (可選)

視覺效果:
    ┌──────────────┐  ← 理想位置
    │   [應在此]   │
    │              │
    └──────────────┘
    🟡 黃色線條

           ⬆️  向上移動

    當前位置 👤
```

---

### 2. 三分法格線（Rule of Thirds Grid）

```
特徵:
- 顏色: #FFFFFF (白色) 或 #E0E0E0 (淺灰)
- 線條寬度: 1-1.5dp
- 透明度: 30-40%
- 位置: 精確 33.33% 和 66.67%

視覺效果:
    ┌─────┬─────┬─────┐
    │     │     │     │
    │     │     │     │
    ├─────┼─────┼─────┤  ← 上三分線 (33.33%)
    │     │     │     │
    │     │     │     │
    ├─────┼─────┼─────┤  ← 下三分線 (66.67%)
    │     │     │     │
    │     │     │     │
    └─────┴─────┴─────┘
      ↑33% ↑67%

    交點 = 最佳構圖點
```

### 3. 構圖提示文字（Composition Hints）

#### 樣式規格
```
字體: Noto Sans TC (繁體中文)
大小: 14-16sp
顏色: #FFFFFF (白色)
背景: #000000 60% 透明度
內邊距: 12dp 水平, 8dp 垂直
圓角: 8dp
位置: 頂部或底部（不遮主體）
最大寬度: 螢幕寬度 - 32dp
對齊: 居中
```

#### 提示訊息範例

**良好構圖**:
```

```

```
    │              │
    │      👃      │
    │              │
    │      👄      │
    └──────────────┘
```

#### 次要人臉（多人場景）
```
特徵:

    │          │
```

## 🎨 顏色規範

### 主要顏色
```kotlin

// 格線

// 文字
val HintText = Color(0xFFFFFFFF)           // 白色
val HintBackground = Color(0xFF000000).copy(alpha = 0.6f)  // 黑色 60%

// 按鈕
val ButtonPrimary = Color(0xFFFFFFFF)      // 白色

// 光影警示
val HDRWarning = Color(0xFFFFC107)         // 琥珀色
```

## ✨ 動畫效果

### 構圖引導框出現
```kotlin
// Fade In + Scale
animateFloatAsState(
    targetValue = if (visible) 1f else 0f,
    animationSpec = tween(durationMillis = 300)
)
```

### 方向指示器
```kotlin
// 上下滑動循環
infiniteRepeatable(
    animation = tween(durationMillis = 1000),
    repeatMode = RepeatMode.Reverse
)
```

### 拍照按鈕點擊
```kotlin
// 縮放效果
animateFloatAsState(
    targetValue = if (pressed) 0.9f else 1f,
    animationSpec = spring(
        dampingRatio = Spring.DampingRatioMediumBouncy
    )
)
```

## 🔍 視覺檢查快速參考

### 5 秒快速檢查
```
✓ 引導框顏色正確？ (綠/黃)
✓ 引導框位置準確？ (上三分線)
✓ 提示文字為中文？
✓ 格線位置正確？ (33%, 67%)
✓ 無 UI 元素重疊？
```

### 關鍵視覺指標
```
1. 構圖引導框位置誤差 < 5%
2. 顏色符合規範（色碼一致）
3. 文字可讀性 ≥ AA 級別（對比度 4.5:1）
4. 動畫流暢 ≥ 30 FPS
5. 無視覺閃爍或跳動
```
