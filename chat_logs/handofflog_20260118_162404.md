## 1. 專案背景 (Context)

### 核心問題

我們正在為 SmartCameraApp1 建立**標準化的雙機測試交接流程**，解決以下問題：

1. **Home NB（開發機）** 與 **Work NB（測試機 + Pixel 9a）** 之間的測試交接流程缺乏標準化
2. 手動執行 git add/commit/push/pull 操作容易出錯且耗時
3. 測試文檔需要人工編寫 commit 訊息，格式不統一
4. Work NB 的 Claude Code 需要清晰的測試執行指引

### 解決方案

將測試交接流程整合到 **VSCode Tasks** 中，建立 4 個一鍵式操作：

1. **📤 Test Handoff: 1. Home NB (Push)** - 推送測試文檔到 GitHub
2. **📥 Test Handoff: 2. Work NB (Pull)** - 拉取測試文檔並顯示執行提示
3. **📤 Test Handoff: 3. Work NB (Push)** - 提交測試報告到 GitHub
4. **📥 Test Handoff: 4. Home NB (Pull)** - 拉取測試報告並自動打開

### 工作流程

```
Home NB (開發機)
  ↓ 撰寫測試文檔
  ↓ Run Task: "📤 Test Handoff: 1. Home NB (Push)"
  ↓ Commit + Push to GitHub

GitHub Repository
  ↓ 同步

Work NB (測試機 + Pixel 9a)
  ↓ Run Task: "📥 Test Handoff: 2. Work NB (Pull)"
  ↓ Claude Code 讀取測試文檔
  ↓ 執行測試指令（ADB、Logcat 等）
  ↓ 生成測試報告
  ↓ Run Task: "📤 Test Handoff: 3. Work NB (Push)"
  ↓ Commit + Push to GitHub

Home NB
  ↓ Run Task: "📥 Test Handoff: 4. Home NB (Pull)"
  ↓ Pull + 自動打開測試報告
```
