## Bugs Found — Pending Fix (v2.12.0-06)

### Bug A — Square frame (both cameras)
**File**: [CameraViewModel.kt:1333](app/src/main/java/com/akirachang/ai/photographer/presentation/camera/CameraViewModel.kt#L1333)
```kotlin
max(screenW, screenH) * 1.5f   // forces square, user expects rectangle
```
FocusIndicator only draws `Size(size, size)` — single size variable.

**Fix**: Separate `focusFrameWidthPx` + `focusFrameHeightPx` in `CameraState`, update FocusIndicator to support non-square.

### Bug B — `focusFrameSizePx` reset every ML Kit frame during LOCKED cooldown
**File**: [CameraViewModel.kt:1335](app/src/main/java/com/akirachang/ai/photographer/presentation/camera/CameraViewModel.kt#L1335)
```kotlin
_state.update { it.copy(focusFrameSizePx = focusSizePx) }  // line 1335
if (!eyeAfThrottle.shouldTrigger(...)) return               // line 1339
```
During 5s postLockCooldown: size overwritten every frame. If transformer null → always 0f → 48dp → front camera "same size always".

**Fix**: Move `focusFrameSizePx` update to AFTER throttle gate passes.

### Bug C — Eye-AF selects wrong candidate (object instead of face)
**Root cause**: When ML Kit detects 0 faces + N objects, `autoFocusOnSalientTarget()` mixes faces + objects in candidates list. Highest-scoring object picked → wrong position → Sony HAL can't focus flat surface → always fails.

**Screenshot**: `tmp/screenshots_temp/Screenshot_20260303-224649.png` (0 人臉 6 物件, frame at upper-left)

**Fix**: When faces > 0: focus ONLY on faces; when faces = 0: fall through to objects.
