# **「AI 即時攝影師」功能 \- 專項開發計畫**

本文件專注於拆解中提到的核心功能 **AI 即時攝影師 (AI Live Photographer)**，並提供其專屬的開發藍圖、技術棧與環境建議。

此功能的終極目標是：**在使用者按下快門前，即時在相機預覽畫面上提供專業級的構圖引導與光影優化。**

## **1\. 核心技術拆解 (Core Technology Breakdown)**

要實現即時分析與引導，我們必須在相機的**預覽流 (Preview Stream)** 上即時運行 AI 模型和圖像處理算法。這對效能是極大的挑戰。

### **1.1 智慧構圖引導 (Smart Composition Guide)**

* **目標**：即時分析畫面中的主體、線條、人臉，並提供動態 UI 提示（例如「鏡頭上移」、「將人臉置於此處」）。  
* **技術實現**：  
  1. **主體偵測**：使用 **Google ML Kit** 的 **Object Detection (物體偵測)** 和 **Face Detection (人臉偵測)**。這能即時回傳畫面中主要物體和人臉的邊界框 (Bounding Box)。  
  2. **啟發式演算法 (Heuristics)**：開發一套「構圖規則引擎」。  
     * **三分法**：檢查主體（例如人臉）是否位於三分線的交點附近。  
     * **引導線**：(V2.0) 偵測畫面中的線條（如道路、欄杆），引導使用者利用線條延伸視覺。  
     * **頭部空間 (Headroom)**：偵測人臉上方空間是否過多或過少。  
  3. **UI 覆蓋層**：使用 **Jetpack Compose** 在相機預覽畫面上繪製動態的輔助線或提示文字泡泡，根據演算法的結果即時移動。

### **1.2 光影即時優化 (Real-time Light Optimization)**

* **目標**：在預覽畫面即時展示 HDR 和對比度調整後的效果，讓使用者「所見即所得」。  
* **技術實現**：  
  1. **即時直方圖分析**：分析每一幀預覽影像的**亮度直方圖 (Luminance Histogram)**。  
  2. **高動態範圍 (HDR) 模擬**：  
     * 當偵測到直方圖兩端（全黑、全白）像素過多時，判斷為高反差場景。  
     * 使用 **OpenGL ES (GLES) Shaders** 或 **Vulkan** 在 GPU 上即時渲染預覽畫面。  
     * 套用 **Tone Mapping (色調映射)** 算法，壓縮高光、提亮陰影，在預覽中即時模擬出 HDR 效果。

### **1.3 AI 智能補光 (AI Smart Fill Light)**

* **目標**：即時偵測逆光或臉部陰影，並在預覽中自動「補光」，讓主體更清晰。  
* **技術實現**：  
  1. **逆光偵測**：  
     * 結合 **ML Kit 人臉偵測** 和 **直方圖分析**。  
     * **規則**：如果偵測到人臉，且「人臉區域的平均亮度」遠低於「非人臉區域的平均亮度」，則判定為逆光。  
  2. **智能補光 Shader**：  
     * 這是一個客製化的 **GLES Shader**。  
     * 它會接收 AI 模型的指令（例如「補光強度 40%」）。  
     * **Segmentation (影像分割)**：(V2.0) 理想狀態是訓練一個輕量級的 **TensorFlow Lite (TFLite) 影像分割模型**，即時將人像與背景分離。  
     * **即時處理**：Shader 只對偵測到的人臉區域進行曲線提亮，同時保持背景曝光不變。這能實現最自然、最專業的補光效果。

## **2\. 建議開發藍圖 (Feature Roadmap)**

此功能開發難度極高，建議分階段迭代，逐步優化效能與智慧程度。

### **階段一：基礎建設與啟發式引導 (V1.0 \- 預計 2 個月)**

* **目標**：打通管線，實現基礎的「靜態」引導。  
* **任務**：  
  1. **相機整合**：使用 **CameraX** 建立穩定的相機預覽 (Preview) 和影像分析 (ImageAnalysis) 用例。  
  2. **ML Kit 整合**：將 ML Kit 人臉/物體偵測器附加到 ImageAnalysis 數據流上，並能在 Logcat 中印出偵測到的物體座標。  
  3. **UI 覆蓋層**：建立 Compose UI 覆蓋層，繪製靜態的「三分法網格線」和「水平儀」。  
  4. **啟發式構圖 (Heuristic)**：實現第一個構圖引導：偵測畫面中「沒有人臉/主體」時，提示「請將主體放入畫面」。

### **階段二：動態構圖與光影分析 (V2.0 \- 預計 2 個月)**

* **目標**：實現動態的構圖建議與光影分析。  
* **任務**：  
  1. **動態 UI**：讓 UI 覆蓋層根據 ML Kit 偵測到的座標即時移動，例如用方框框出黃金分割點上的主體。  
  2. **構圖引擎 V1**：實現基於啟發式規則的構圖建議，例如「偵測到人臉過於靠近邊緣，請置中」。  
  3. **光影分析**：完成即時直方圖分析，並在 UI 上顯示一個簡單的「高反差」或「逆光」警告圖示。

### **階段三：即時光影渲染 (V3.0 \- 預計 3 個月)**

* **目標**：在預覽中即時套用光影優化效果（最關鍵階段）。  
* **任務**：  
  1. **Shader 整合**：建立 CameraX 到 GLES / Vulkan 的渲染管線，能將相機預覽流作為紋理 (Texture) 傳入 Shader。  
  2. **基礎濾鏡**：先實現一個簡單的「提高亮度」或「增加對比度」的 GLES Shader，並成功套用在即時預覽上。  
  3. **Tone Mapping**：實現 Tone Mapping 演算法的 GLES Shader，並根據 V2 的光影分析結果（是否為高反差）自動啟用。

### **階段四：AI 驅動的智能補光 (V4.0 \- 預計 3-4 個月)**

* **目標**：實現 TFLite 模型驅動的「AI 智能補光」。  
* **任務**：  
  1. **模型訓練**：(此為線下任務) 訓練一個超輕量級的人像分割 TFLite 模型。  
  2. **TFLite 整合**：將 TFLite 執行器整合到 ImageAnalysis 數據流中。  
  3. **智能補光 Shader**：編寫最終的 GLES Shader，它能：  
     * 接收「人像分割 MASK」。  
     * 只針對 MASK 區域（即人像）進行提亮。  
     * 根據逆光偵測結果，自動調整提亮強度。  
  4. **效能調優**：瘋狂優化管線中每一步的延遲，確保在主流中階手機上也能流暢運行。

## **3\. 所需開發環境 (Development Environment)**

### **3.1 硬體 (Hardware)**

1. **開發主機**：配備高效能 CPU (Ryzen 7 / Core i7 或以上)、32GB RAM 的 Windows / macOS / Linux 主機。  
2.   
   1. **AI 訓練機 (可選，推薦)**：配備 NVIDIA GPU (RTX 3070 / 4070 或以上) 的本地主機，用於訓練 TFLite 模型。  
   2. **測試手機 (必要)**：  
   * **高效能機**：Google Pixel 8/9 Pro, Samsung S24/S25 Ultra (用於驗證 GLES/Vulkan 效能上限)。  
   * **中階機**：Google Pixel 7a / Samsung A 系列 (用於效能基準測試，確保 APP 的可用性)。  
   * **低階機**：(用於相容性測試)。  
   * **強烈不建議**：*絕對不能*只依賴 Android 模擬器，相機和 GPU 效能無法準確模擬。

### **3.2 軟體 (Software)**

1. **IDE**：**Android Studio** (最新穩定版)。  
2. **語言**：**Kotlin** (100% Kotlin-first)。  
3. **核心 SDK/Library**：  
   * **Android Jetpack \- CameraX**：處理相機預覽、拍照、影像分析。  
   * **Android Jetpack \- Compose**：建構所有 UI 介面與覆蓋層。  
   * **Google ML Kit**：用於即時的人臉、物體偵測。  
   * **TensorFlow Lite (TFLite) SDK**：用於運行自訂的 AI 模型 (如人像分割)。  
   * **Android NDK**：用於整合 C++ 程式碼 (如果 GLES 渲染邏輯過於複雜)。  
   * **OpenGL ES (GLES) 3.0+** 或 **Vulkan**：用於即時 GPU 圖像處理與渲染。

### **3.3 AI 訓練環境 (Cloud / AI Services)**

* **雲端訓練 (替代方案)**：如果沒有本地 AI 訓練機，可使用 **Google Colab Pro** 或 **Google Cloud Vertex AI** 來訓練您的 TFLite 模型。  
* **資料集**：需要大量標記數據來訓練模型，尤其是「人像分割」和「構圖好壞」模型。
