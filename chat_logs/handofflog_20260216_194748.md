## 4. 最新交付成果 (Latest Deliverable)

### 📊 最終確認：4 項視覺語言

Focus Indicator 的視覺設計已精簡為以下 **4 項視覺語言**（僅此四項，不允許新增）：

#### 1. 機械咬合動畫（「咔嗒」節奏感）

**效果**: Scale 1.0 → 0.9 → 1.0（縮小→彈回）

**時長**: **350ms** 總時長
- 階段 2（縮小）: **150ms**
- 階段 3（彈回）: **200ms**（Spring 高剛性）

**實作規範**:
```kotlin
// CameraScreen.kt - FocusIndicator

val scale = remember { Animatable(1.0f) }

LaunchedEffect(focusSuccess) {
    if (focusSuccess == true && !isFocusing) {
        // 階段 1: 角落括號出現（瞬間）
        showCornerBrackets.value = true

        // 階段 2: 快速縮小至 0.9（150ms）
        scale.animateTo(
            targetValue = 0.9f,
            animationSpec = tween(
                durationMillis = 150,  // ✅ v2.11.1 修正（原 500ms）
                easing = FastOutLinearInEasing
            )
        )

        // 階段 3: 快速彈回至 1.0（200ms, Spring 高剛性）
        scale.animateTo(
            targetValue = 1.0f,
            animationSpec = spring(
                dampingRatio = Spring.DampingRatioMediumBouncy,
                stiffness = Spring.StiffnessHigh  // 高剛性，快速彈回
            )
            // Spring 動畫約 200ms
        )
    }
}
```

**視覺效果**:
- ✅ 清脆「咔嗒」節奏感
- ✅ 快速反饋，即時確認
- ✅ 接近真實相機快門體驗

**⚠️ Critical Warning**:
- ❌ DO NOT use 1000ms (v2.11.0 設計缺陷)
- ❌ DO NOT implement "bracket clamp 4dp" as separate animation（誤解）
- ✅ MUST use 350ms (150ms + 200ms)

// Alpha 動畫: 1.0 → 0.4
val alpha by animateFloatAsState(

    animationSpec = tween(durationMillis = 500),
    label = "alpha"

// 線條變細動畫: 2.5dp → 1.5dp
val animatedStroke by animateFloatAsState(

    animationSpec = tween(durationMillis = 500),

#### 4. 靜態 Glow 效果（霓虹輝光）

**效果**: 科技感視覺增強，「懸浮光束」美學

**實作**: 雙層 Canvas 繪製

**實作規範**:
```kotlin
// CameraScreen.kt - FocusIndicator

Canvas(modifier = modifier) {
    val halfSize = focusFrameSize.toPx() / 2

    // ========== Glow 層（底層）==========
    // 四邊形輪廓（寬度 2.4 倍，Alpha 0.3）
    drawRect(
        color = color,
        topLeft = Offset(x - halfSize, y - halfSize),
        size = Size(halfSize * 2, halfSize * 2),
        alpha = alpha * 0.3f,  // ✅ 固定值 0.3，不做呼吸脈衝
        style = Stroke(width = strokeWidth * 2.4f)
    )

    // ========== Core 層（頂層）==========
    // 四邊形輪廓（原寬度，原 Alpha）
    drawRect(
        color = color,
        topLeft = Offset(x - halfSize, y - halfSize),
        size = Size(halfSize * 2, halfSize * 2),
        alpha = alpha,
        style = Stroke(width = strokeWidth)
    )

    // ========== 角落括號（條件顯示）==========
    if (showCornerBrackets) {
        drawCornerBrackets(
            x = x,
            y = y,
            size = halfSize * 2,
            bracketLength = 12.dp.toPx(),
            strokeWidth = strokeWidth,
            color = color,
            alpha = alpha
        )
    }
}
```
