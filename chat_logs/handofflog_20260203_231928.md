## 1. 專案背景 (Context)

SmartCameraApp 的 Optical Flow 追蹤功能存在**前置鏡頭追蹤異常抖動**問題：
- 正常追蹤時 distance < 5px
- 異常時突然跳動 30-35px（quality 降至 0.80）
- 視覺上呈現「抖動」或「閃爍」效果

**根因**：LK 追蹤的 `minQuality=0.3f` 和 `maxTrackingDistance=200f` 閾值過於寬鬆，無法過濾低質量結果。

```kotlin
/**
 * Clamp point velocity to prevent visual jitter
 * Limits maximum displacement per frame while preserving movement direction
 *
 * @param oldPoint Previous tracked point
 * @param newPoint New tracked point from LK
 * @param distance Pre-calculated distance between points
 * @return Clamped point if distance exceeds threshold, otherwise newPoint
 */
private fun clampVelocity(oldPoint: Point, newPoint: Point, distance: Float): Point {
    if (distance <= config.maxDistancePerFrame) {
        return newPoint
    }

    val scale = config.maxDistancePerFrame / distance
    val dx = newPoint.x - oldPoint.x
    val dy = newPoint.y - oldPoint.y

    Log.v(TAG, "Velocity clamped: ${distance}px -> ${config.maxDistancePerFrame}px")

    return Point(
        oldPoint.x + dx * scale,
        oldPoint.y + dy * scale
    )
}
```

```kotlin

data class OpticalFlowConfig(

     */
    val minQualityForJumpDetection: Float = 0.85f,

    /**
     * Maximum distance threshold for jump detection (pixels)
     */
    val maxDistanceForJumpDetection: Float = 10f,

    val maxDistancePerFrame: Float = 15f
) {
    // ... existing code ...
}
```

修改 `OpticalFlowTracker.kt` - 新增 `lastValidResult` 狀態和過濾邏輯：
```kotlin
class OpticalFlowTracker(
    private val config: OpticalFlowConfig = OpticalFlowConfig.DEFAULT
) {
    // ... existing state ...

    // Last valid tracking result for jitter rejection fallback
    private var lastValidResult: TrackingResult? = null

    // In track() method, before validateTracking():
    private fun isJitterFrame(quality: Float, distance: Float): Boolean {
        return quality < config.minQualityForJumpDetection &&
               distance > config.maxDistanceForJumpDetection
    }

    // In track() method, after LK calculation:
    if (isJitterFrame(quality, distance)) {
        Log.w(TAG, "Jitter rejected: quality=$quality, distance=$distance")
        // Return last valid result instead of LOST
        return lastValidResult ?: TrackingResult(
            point = scalePointToOriginal(trackedPoint!!),
            quality = 1.0f,
            distance = 0f,
            isValid = true
        )
    }

    // After successful tracking, save as last valid:
    lastValidResult = TrackingResult(
        point = scalePointToOriginal(trackedPoint!!),
        quality = quality,
        distance = distance,
        isValid = true
    )
}
```
