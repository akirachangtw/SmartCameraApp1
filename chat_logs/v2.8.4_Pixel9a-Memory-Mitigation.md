# Implementation Plan - Pixel 9a Memory Mitigation

This plan addresses the memory usage anomalies reported in `docs/V2.8.4_MEMORY_TEST_REPORT_THREE_PLATFORMS.md` specifically for the Pixel 9a device.

## Goal Description
Reduce memory accumulation on Pixel 9a devices by:
1.  Reducing ML Kit analysis frequency.
2.  Ensuring safe camera resolution.
3.  Adding user warnings about potential memory issues.

## User Review Required
> [!IMPORTANT]
> These changes introduce device-specific logic (`if Build.MODEL == "Pixel 9a"`). This is a temporary workaround until the underlying driver/hardware issue is resolved.

## Proposed Changes

### Logic Layer
#### [MODIFY] [SmartCameraAnalyzer.kt](file:///d:/MyDocuments/DevSources/AndroidStudioProjects/SmartCameraApp1/app/src/main/java/com/akirachang/ai/photographer/data/source/camera/SmartCameraAnalyzer.kt)
- Increase `THROTTLE_INTERVAL_MS` from 100ms to 500ms for Pixel 9a.
- Add device detection util or inline check.

#### [MODIFY] [LiveCameraSource.kt](file:///d:/MyDocuments/DevSources/AndroidStudioProjects/SmartCameraApp1/app/src/main/java/com/akirachang/ai/photographer/data/source/camera/LiveCameraSource.kt)
- Check for Pixel 9a when building `Preview` and `ImageAnalysis` use cases.
- Force resolution to 480x480 (or keep 640x480 but ensure no higher) for Pixel 9a to reduce buffer size.

#### [MODIFY] [CameraViewModel.kt](file:///d:/MyDocuments/DevSources/AndroidStudioProjects/SmartCameraApp1/app/src/main/java/com/akirachang/ai/photographer/presentation/camera/CameraViewModel.kt)
- Add initialization check for Pixel 9a.
- Show a one-time warning toast or snackbar to the user via `CameraUiEvent.ShowError` (or a new warning state) advising them of potential instability.

## Verification Plan

### Manual Verification
1.  **Pixel 9a (Goal)**: 
    - Install app on Pixel 9a.
    - Confirm warning message appears on startup.

2.  **Other Devices (Regression)**:

    - Confirm NO warning message.
