## ⚠️ 已知問題與限制

### 技術限制
1. **不支援 Upside Down (180°)**：大多數 Android 裝置預設禁用
2. **OrientationListener 延遲**：100-300ms 延遲是正常的
3. **模擬器限制**：加速度計模擬有限，無法完全模擬實體旋轉

### 發現事項
1. **Sony XQ-BT52 Sensor Orientation = 90°**
   - 與預期的 270° 不同
   - 需要根據實際測試結果調整 rotation mapping（如果照片方向仍錯誤）

### 編譯警告
1. **Deprecated API 警告**:
   ```
   'val defaultDisplay: Display!' is deprecated. Deprecated in Java.
   ```
   - 位置: LiveCameraSource.kt:545
   - 影響: 低（功能正常，僅警告）
   - 建議: 未來可考慮使用 `DisplayManager` API
