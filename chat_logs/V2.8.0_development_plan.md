## 1. 專案背景

### 1.1 專案資訊

**專案名稱**: SmartCameraApp (AI Photographer)
**應用類型**: Android 智能相機應用
**套件名稱**: `com.akirachang.ai.photographer`
**開發分支**: `feature/camera-input-abstraction`

### 1.2 核心功能

SmartCameraApp 是一款 AI 驅動的智能攝影應用，使用 ML Kit 提供：

1. **人臉偵測 (Face Detection)**: 即時偵測人臉位置、眼睛座標、邊界框
2. **物體偵測 (Object Detection)**: 偵測場景中的物體（confidence ≥ 0.5）
3. **構圖分析 (Composition Analysis)**: 基於攝影規則提供即時引導
   - 規則三分法 (Rule of Thirds)
   - 眼睛位置分析 (Eye Position)
   - 頭部空間評估 (Headroom)
   - 邊緣距離檢測 (Edge Distance)
   - 對稱性分析 (Symmetry) - v2.5.4 新增
4. **光線分析 (Lighting Analysis)**: 曝光檢測、直方圖分析

### 1.3 技術架構

- **架構模式**: Clean Architecture (Domain/Data/Presentation)
- **UI 框架**: Jetpack Compose
- **相機框架**: CameraX
- **ML 框架**: ML Kit (Face Detection + Object Detection)
- **依賴注入**: Hilt
- **測試框架**: JUnit + Robolectric + Mockito + Truth
- **計劃整合**: OpenCV (Phase 2)

**解決方案**: 實現基於優先順序的構圖分析系統

**核心變更** (`AnalyzeCompositionUseCase.kt`):

1. **重構 invoke() 方法** (Lines 182-215):
   ```kotlin
   operator fun invoke(
       detectionResult: DetectionResult,
       previewWidth: Int? = null,
       previewHeight: Int? = null,
       isFrontCamera: Boolean = false
   ): CompositionState {
       val faces = detectionResult.faces
       val objects = detectionResult.objects

       // Priority 1: Face composition (portraits)
       if (faces.isNotEmpty()) {
           return analyzeFaceComposition(...)
       }

       // Priority 2: Object composition (landscapes)
       if (objects.isNotEmpty()) {
           return analyzeObjectComposition(...)
       }

       return CompositionState.NoSubject
   }
   ```

         fun detectVerticalSymmetry(image: Mat): SymmetryResult {

## 10. 風險與限制

### 10.1 技術風險

| 風險 | 影響 | 機率 | 緩解措施 |
|------|------|------|---------|
| OpenCV 整合複雜 | 高 | 中 | 預留充足時間，參考官方範例 |
| 引導線檢測準確度不足 | 中 | 中 | 調校演算法參數，多場景測試 |
| 性能不達標（FPS < 25） | 高 | 低 | 降低處理頻率，多執行緒優化 |
| ML Kit Object Detection 模擬器失效 | 低 | 高 | 使用實機測試 |
| 記憶體使用過高 | 中 | 中 | OpenCV Mat 記憶體管理，及時釋放 |

### 10.2 時程風險

| 風險 | 影響 | 機率 | 緩解措施 |
|------|------|------|---------|
| OpenCV 學習曲線 | 中 | 中 | 提前研究，使用成熟方案 |
| 測試時間不足 | 高 | 低 | 每個 Phase 預留測試時間 |
| Bug 修復延誤 | 中 | 中 | 持續集成，及早發現問題 |

### 10.3 已知限制

1. **ML Kit Object Detection**:
   - 模擬器無法使用
   - 需實機測試

2. **OpenCV 效能**:
   - Canny + HoughLines 計算密集
   - 需降低處理頻率（每 5 幀）

3. **對稱性檢測**:
   - 僅支援軸對稱（垂直/水平/對角線）
   - 不支援旋轉對稱、徑向對稱

4. **場景分類**:
   - 基於規則，非 ML 模型
   - 準確度有限
