## 🎯 根本原因分析

### DetectionOverlay.kt 動畫系統問題

**檔案位置**: `app/src/main/java/.../presentation/camera/components/overlay/DetectionOverlay.kt`

**問題程式碼** (Line 75-91):
```kotlin
LaunchedEffect(detectionResult) {
    detectionResult?.let { result ->
        result.faces.forEachIndexed { index, face ->
            val trackingId = face.trackingId ?: index
            val screenRect = face.boundingBox.toComposeRect()

            val animatable = animatedFaceBoxes.getOrPut(trackingId) {
                Animatable(screenRect, Rect.VectorConverter)
            }

            animatable.animateTo(  // ❌ 問題：順序執行！
                targetValue = screenRect,
                animationSpec = tween(durationMillis = 150)
            )
        }
    }
}
```

**問題分析**：

1. **順序執行問題**：
   - `animateTo` 是 suspend 函數，**預設順序執行**
   - N 張臉需要 N × 150ms 才能全部動畫完成
   - 例如：4 張臉需要 600ms

2. **高頻更新衝突**：
   - ML Kit 偵測更新頻率：約每 100-200ms
   - 新的 LaunchedEffect 會**取消舊的動畫**
   - 結果：只有第 1 個動畫完成，其餘被取消

3. **為什麼滑動螢幕會讓框框出現？**
   - 滑動時觸發 UI recompose
   - 重新啟動動畫週期
   - 剛好在某些時機點讓更多動畫完成
   - 但位置可能不準確（使用舊座標）

### 時序圖

```
時間軸 →
T=0ms:   ML Kit 偵測 4 張臉 → LaunchedEffect 開始
T=0ms:   開始動畫 Face #0
T=150ms: Face #0 完成 ✅
T=150ms: 開始動畫 Face #1
T=200ms: ML Kit 新偵測 → LaunchedEffect 取消 ❌
T=200ms: 新的 LaunchedEffect 開始 → 重頭開始
結果：   只有 Face #0 顯示在畫面上
```

## 💡 解決方案

### 方案 A：移除動畫系統 ✅ **推薦**

**優點**：
- ✅ 徹底解決順序執行問題
- ✅ 所有框框即時顯示，無延遲
- ✅ 程式碼更簡單（~150 行 → ~100 行）
- ✅ 效能更好（無動畫計算）
- ✅ 更符合偵測工具的使用情境（即時反應更重要）

**缺點**：
- ❌ 無平滑過渡動畫（但這不是必需功能）

**實作計劃**：
1. 移除 `remember` 的 `animatedFaceBoxes` 和 `animatedObjectBoxes`
2. 移除 `LaunchedEffect` 整個區塊
3. 改為在 `Canvas` 內直接繪製
4. 保留 `drawFaceBoundingBox` 和 `drawObjectBoundingBox` 函數

### 方案 B：修正動畫並行執行

**使用 launch 讓動畫並行**：
```kotlin
LaunchedEffect(detectionResult) {
    result.faces.forEach { face ->
        launch {  // 每個動畫在獨立的 coroutine
            animatable.animateTo(...)
        }
    }
}
```

**優點**：
- ✅ 保留動畫效果
- ✅ 所有動畫並行執行

**缺點**：
- ❌ 複雜度較高
- ❌ 可能還有其他潛在問題
- ❌ 高頻更新時仍可能有效能問題

**建議**：採用方案 A（移除動畫系統）

```kotlin
@Composable
fun DetectionOverlay(
    detectionResult: DetectionResult?,
    modifier: Modifier = Modifier
) {
    Canvas(modifier = modifier.fillMaxSize()) {
        detectionResult?.let { result ->
            // 直接繪製人臉框
            result.faces.forEachIndexed { index, face ->
                val trackingId = face.trackingId ?: index
                val rect = face.boundingBox.toComposeRect()
                drawFaceBoundingBox(rect, trackingId, face)
            }

            // 直接繪製物件框
            result.objects.forEachIndexed { index, obj ->
                val trackingId = obj.trackingId ?: index
                val rect = obj.boundingBox.toComposeRect()
                drawObjectBoundingBox(rect, trackingId, obj)
            }
        }
    }
}
```

**保留內容**：
- Line 149-204: `drawFaceBoundingBox` 函數
- Line 206-269: `drawObjectBoundingBox` 函數
- Line 271-284: `toComposeRect` 擴展函數

## Problem
- ML Kit detected N faces (UI shows correct count)
- But only 1 bounding box displayed on screen

- DetectionOverlay animation system executes sequentially
