## 🎯 方法 1：VSCode 終端機 + 命令列（推薦）

### 步驟 1：找到您的 Android SDK 路徑

Android SDK 通常位於以下位置之一：

**Windows**:
```
C:\Users\<您的使用者名稱>\AppData\Local\Android\Sdk
```

**驗證方法**：
1. 按 `Win + R`
2. 輸入 `%LOCALAPPDATA%\Android\Sdk`
3. 如果資料夾開啟，這就是您的 SDK 路徑

**或者在 Android Studio 中查看**：
1. 開啟 Android Studio
2. `File` → `Settings` → `Appearance & Behavior` → `System Settings` → `Android SDK`
3. 複製 "Android SDK Location" 路徑

---

### 步驟 2：設定環境變數（一次性設定）

#### 方法 A：透過 Windows 系統設定（永久生效）

1. **開啟環境變數設定**：
   - 按 `Win + R`，輸入 `sysdm.cpl`，按 Enter
   - 點擊「進階」標籤
   - 點擊「環境變數」

2. **新增 ANDROID_HOME**：
   - 在「使用者變數」區塊，點擊「新增」
   - 變數名稱：`ANDROID_HOME`
   - 變數值：您的 SDK 路徑（例如：`C:\Users\YourName\AppData\Local\Android\Sdk`）

3. **編輯 PATH**：
   - 在「使用者變數」區塊，選擇 `Path`，點擊「編輯」
   - 點擊「新增」，加入以下兩個路徑：
     ```
     %ANDROID_HOME%\emulator
     %ANDROID_HOME%\platform-tools
     ```

4. **套用變更**：
   - 點擊「確定」關閉所有對話框
   - **重新啟動 VSCode**（重要！）

---

#### 方法 B：透過 PowerShell（臨時生效，每次重開 VSCode 需重新設定）

在 VSCode 終端機中執行：

```powershell
# 設定 ANDROID_HOME（替換成您的實際路徑）
$env:ANDROID_HOME = "C:\Users\YourName\AppData\Local\Android\Sdk"

# 加入到 PATH
$env:Path += ";$env:ANDROID_HOME\emulator;$env:ANDROID_HOME\platform-tools"

# 驗證設定
echo $env:ANDROID_HOME
emulator -version
```

**輸出範例**：
```
C:\Users\YourName\AppData\Local\Android\Sdk
Android emulator version 31.3.14.0 (build_id 9619184)
```

---

### 步驟 3：列出可用的模擬器

```bash
emulator -list-avds
```

**輸出範例**：
```
Pixel_5_API_33
Pixel_6_API_34
Medium_Phone_API_30
```

---

### 步驟 4：啟動模擬器

```bash
# 啟動指定模擬器（替換成您的 AVD 名稱）
emulator -avd Pixel_5_API_33

# 或使用背景啟動（推薦，不佔用 terminal）
emulator -avd Pixel_5_API_33 &
```

**啟動參數（選用）**：
```bash
# 啟用硬體加速（更流暢）
emulator -avd Pixel_5_API_33 -gpu host

# 無視窗框架啟動（節省螢幕空間）
emulator -avd Pixel_5_API_33 -no-window
```

> ⚠️ **注意**：解析度由 AVD Manager 設定，不可用命令列參數臨時更改。

---

### 步驟 5：驗證模擬器已啟動

```bash
adb devices
```

**預期輸出**：
```
List of devices attached
emulator-5554    device
```

✅ 看到 `emulator-xxxx` 就代表成功！

## 🔧 方法 2：建立啟動腳本（最方便）

### 建立 PowerShell 腳本

1. **建立檔案**：`start-emulator.ps1`

```powershell
# start-emulator.ps1 - Android 模擬器啟動腳本

param(
    [string]$AvdName = "Pixel_5_API_33",  # 預設模擬器名稱
    [switch]$List = $false                # 列出可用模擬器
)

# 設定 Android SDK 路徑（請替換成您的實際路徑）
$ANDROID_HOME = "C:\Users\Administrator\AppData\Local\Android\Sdk"

if (-not (Test-Path $ANDROID_HOME)) {
    Write-Host "❌ Android SDK 未找到: $ANDROID_HOME" -ForegroundColor Red
    Write-Host "請修改腳本中的 ANDROID_HOME 路徑" -ForegroundColor Yellow
    exit 1
}

$emulatorPath = Join-Path $ANDROID_HOME "emulator\emulator.exe"

if (-not (Test-Path $emulatorPath)) {
    Write-Host "❌ Emulator 執行檔未找到: $emulatorPath" -ForegroundColor Red
    exit 1
}

# 列出可用模擬器
if ($List) {
    Write-Host "📱 可用的模擬器:" -ForegroundColor Cyan
    & $emulatorPath -list-avds
    exit 0
}

# 檢查模擬器是否已在運行
$runningEmulator = adb devices | Select-String "emulator"
if ($runningEmulator) {
    Write-Host "⚠️  模擬器已在運行:" -ForegroundColor Yellow
    adb devices
    $continue = Read-Host "是否繼續啟動新的模擬器? (y/N)"
    if ($continue -ne 'y') {
        exit 0
    }
}

# 啟動模擬器
Write-Host "🚀 啟動模擬器: $AvdName" -ForegroundColor Green
Write-Host "   路徑: $emulatorPath" -ForegroundColor Gray
Write-Host "   參數: -avd $AvdName -gpu host" -ForegroundColor Gray

Start-Process $emulatorPath -ArgumentList "-avd", $AvdName, "-gpu", "host" -NoNewWindow

Write-Host "⏳ 等待模擬器啟動..." -ForegroundColor Cyan
Start-Sleep -Seconds 5

# 等待模擬器完全啟動
$timeout = 60  # 60 秒超時
$elapsed = 0
while ($elapsed -lt $timeout) {
    $devices = adb devices | Select-String "emulator.*device"
    if ($devices) {
        Write-Host "✅ 模擬器啟動成功！" -ForegroundColor Green
        adb devices
        exit 0
    }
    Start-Sleep -Seconds 2
    $elapsed += 2
    Write-Host "." -NoNewline
}

Write-Host "`n⚠️  模擬器啟動超時（60秒）" -ForegroundColor Yellow
Write-Host "請手動檢查模擬器狀態" -ForegroundColor Yellow
```

2. **使用方式**：

```powershell
# 列出可用模擬器
.\start-emulator.ps1 -List

# 啟動預設模擬器（Pixel_5_API_33）
.\start-emulator.ps1

# 啟動指定模擬器
.\start-emulator.ps1 -AvdName "Pixel_6_API_34"
```

## 🎨 方法 3：Android Studio GUI（最簡單）

雖然您希望不開 Android Studio，但這是**最穩定**的方法：

1. **開啟 Android Studio**
2. **不需要開啟專案**，直接在歡迎畫面點擊：
   - `More Actions` → `Virtual Device Manager`
   - 或點擊右上角的 📱 圖示
3. **啟動模擬器**：
   - 選擇 AVD
   - 點擊 ▶️

**優點**：
- ✅ 100% 成功率
- ✅ 可視化介面
- ✅ 自動處理所有設定

**缺點**：
- ❌ 需要開啟 Android Studio

**小技巧**：啟動後可以關閉 Android Studio，模擬器會繼續運行！

## ⚡ 方法 4：VSCode Tasks 整合（終極方案）

### 新增到 `.vscode/tasks.json`

在 `tasks` 陣列中加入以下項目（`inputs` 陣列中加入 `avdName` input）：

```json
// tasks 陣列中新增
{
    "label": "📱 Start Emulator",
    "type": "shell",
    "command": "emulator",
    "args": [
        "-avd",
        "${input:avdName}",
        "-gpu",
        "host"
    ],
    "isBackground": true,
    "presentation": {
        "reveal": "always",
        "panel": "dedicated"
    },
    "problemMatcher": []
},

// inputs 陣列中新增
{
    "id": "avdName",
    "type": "promptString",
    "description": "輸入 AVD 名稱（如 Pixel_5_API_33）",
    "default": "Pixel_5_API_33"
}
```

### 使用方式

1. 按 `Ctrl+Shift+P`，輸入 `Tasks: Run Task`
2. 選擇 `📱 Start Emulator`
3. 輸入 AVD 名稱（或直接按 Enter 使用預設值）

> **前提**：需先確認 `emulator` 已在系統 PATH（參考方法 1 步驟 2）。
