## 6. 關鍵架構守則（不可違背，本輪確立）

### 守則 1：Analyzer = Dumb Pipe
- 禁止在 `SmartCameraAnalyzer` 內做座標轉換、target ranking、UI state 決策
- 唯一正確 OF 入口：`startOpticalFlowTrackingImageCoords()`（image-space）
- `CoordinateMapper` 路徑已完全退役，禁止復活

### 守則 2：幾何單一真相
- `GeometryMapper`（FIT_CENTER）= 新 pipeline 唯一座標真相來源
- `CoordinateTransformer`（FIT_CENTER）= legacy ViewModel 路徑
- `CoordinateMapper`（CENTER_CROP）= 已退役，僅保留 class 本身未刪除

### 守則 3：硬體 Provider Lifecycle-Safe
- `getCameraControl()` / `getMeteringPointFactory()` 必須在 `apply()` 時才呼叫（lambda 懶取值）
- 禁止在 ViewModel init 或 constructor 預取硬體物件

### 守則 4（v2.12.0-14 延續）：Scope Discipline
- 座標/幾何票據只允許修改 ViewModel 層
- 禁止同一票據連帶改動 `CameraScreen.kt` / `FocusIndicator` / 動畫邏輯

### 守則 5（v2.12.0-13 延續）：isFocusIndicatorLocked 語義
- `isFocusIndicatorLocked = isAEAFLocked`（只對應 Yellow）
- Eye-AF `afState=Locked` 絕不加入此條件（Cyan 路徑獨立）
- alpha 優先順序：`isLocked(Yellow) → isEyeAfLocked(Cyan) → isFading(0.4) → isTracking → else`
