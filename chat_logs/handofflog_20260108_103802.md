## 1. 專案背景 (Context)

### 問題描述
SmartCameraApp1 的即時相機預覽處理 pipeline 存在效能瓶頸，導致 FPS 僅達 19-20 (目標 ≥26)。

### 技術分析
**當前 Pipeline (v2.8.3)**:
```
Stage 1: YUV→RGB 轉換 (RenderScript GPU) → 5.4ms ✅ 已優化
Stage 2: Transform (CPU Canvas) → 16ms avg, 40ms peak ❌ 瓶頸
Total: 21.4-45.4ms/frame
FPS: 19-20 (受限於 Transform 抖動)
```

**根本原因**:
1. **Transform 瓶頸**: CPU Canvas 操作 (rotation + mirror) 耗時 16ms (平均) ~ 40ms (峰值)
2. **BitmapPool 鍵值爆炸**: 旋轉導致尺寸變化 (640x480 ↔ 480x640)，`ceil()` 浮點誤差產生 721、719 等非預期尺寸，Pool hit rate <50%
3. **記憶體壓力**: 頻繁記憶體分配，GC 壓力大

### 解決方案
**Plan B: RenderScript YUV+Transform Fusion**
- 將 YUV→RGB + Rotation + Mirror 合併為單一 RenderScript kernel
- 目標: 總處理時間 21ms → 7-10ms, FPS 19-20 → 28-30

**Traycer 分析建議**:
- 先執行 **Quick Win**: 修復 BitmapPool 鍵值爆炸 (1-2 小時)
- 可能直接讓 FPS 達標 (22-24)，無需完整 Plan B
- 未達標再執行 RenderScript fusion (2.5-3.5 天)

 * Rotate and optionally mirror a bitmap
 *
 * v2.6.1: Added mirror parameter for front camera selfie view
 * v2.8.3 Phase D: Minimal optimization - reuse Paint, skip CLEAR
 */
private fun transformBitmap(
    source: BitmapPool.BitmapBuffer,
    degrees: Int,
    mirror: Boolean = false
): BitmapPool.BitmapBuffer {
    if (degrees == 0 && !mirror) return source

    // v2.8.3 Phase D: Preserve original logic, only optimize allocations
    val baseMatrix = Matrix()
    if (degrees != 0) {
        baseMatrix.postRotate(degrees.toFloat())
    }
    if (mirror) {
        baseMatrix.postScale(-1f, 1f)
    }

    val srcRect = RectF(0f, 0f, source.bitmap.width.toFloat(), source.bitmap.height.toFloat())
    val dstRect = RectF(srcRect)
    baseMatrix.mapRect(dstRect)  // ← 問題: 計算動態尺寸

    val translateMatrix = Matrix(baseMatrix).apply {
        postTranslate(-dstRect.left, -dstRect.top)
    }

    // ⚠️ 問題: ceil() 產生浮點誤差 (721, 719)
    val outWidth = ceil(dstRect.width()).toInt().coerceAtLeast(1)
    val outHeight = ceil(dstRect.height()).toInt().coerceAtLeast(1)
    val out = bitmapPool.acquire(outWidth, outHeight, Bitmap.Config.ARGB_8888)

    val canvas = Canvas(out.bitmap)
    canvas.drawColor(Color.TRANSPARENT, PorterDuff.Mode.CLEAR)
    canvas.drawBitmap(source.bitmap, translateMatrix, transformPaint)

    return out
}

1. `mapRect()` + `ceil()` 產生非預期尺寸 (640→721, 480→479)

3. BitmapPool key 爆炸 (應該只有 2 組，實際可能有 10+ 組)
4. Pool miss rate >50% → 頻繁記憶體分配 → GC 壓力 → Transform 時間抖動

**完整修改後的 transformBitmap()**:
```kotlin
private fun transformBitmap(
    source: BitmapPool.BitmapBuffer,
    degrees: Int,
    mirror: Boolean = false
): BitmapPool.BitmapBuffer {
    if (degrees == 0 && !mirror) return source

    // v2.8.4 Quick Win: Fixed output size to eliminate pool key explosion
    val srcWidth = source.bitmap.width
    val srcHeight = source.bitmap.height

    // Calculate output dimensions based on rotation (no floating point)
    val (outWidth, outHeight) = when (degrees) {
        90, 270 -> srcHeight to srcWidth  // Swap dimensions
        else -> srcWidth to srcHeight      // Keep dimensions
    }

    val out = bitmapPool.acquire(outWidth, outHeight, Bitmap.Config.ARGB_8888)
    val canvas = Canvas(out.bitmap)

    // Build transformation matrix
    val matrix = Matrix()

    when {
        degrees == 90 && !mirror -> {
            matrix.postRotate(90f)
            matrix.postTranslate(outWidth.toFloat(), 0f)
        }
        degrees == 270 && !mirror -> {
            matrix.postRotate(270f)
            matrix.postTranslate(0f, outHeight.toFloat())
        }
        degrees == 180 && !mirror -> {
            matrix.postRotate(180f)
            matrix.postTranslate(outWidth.toFloat(), outHeight.toFloat())
        }
        degrees == 0 && mirror -> {
            matrix.postScale(-1f, 1f)
            matrix.postTranslate(outWidth.toFloat(), 0f)
        }
        else -> {
            // Combined rotation + mirror (general case)
            if (degrees != 0) {
                matrix.postRotate(degrees.toFloat())
            }
            if (mirror) {
                matrix.postScale(-1f, 1f)
            }
            val srcRect = RectF(0f, 0f, srcWidth.toFloat(), srcHeight.toFloat())
            val dstRect = RectF(srcRect)
            matrix.mapRect(dstRect)
            matrix.postTranslate(-dstRect.left, -dstRect.top)
        }
    }

    canvas.drawColor(Color.TRANSPARENT, PorterDuff.Mode.CLEAR)
    canvas.drawBitmap(source.bitmap, matrix, transformPaint)

    return out
}
```
