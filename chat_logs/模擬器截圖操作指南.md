## 步驟 1️⃣：啟動 Android 模擬器 (2 分鐘)

### 方法 A：使用 Android Studio（推薦）

1. **開啟 Android Studio**
2. **打開 Device Manager**：
   - 點擊頂部工具列 `Tools` → `Device Manager`
   - 或點擊右側邊欄的手機圖示 📱

3. **啟動模擬器**：
   - 在 Device Manager 中找到您的 AVD
   - 推薦使用：
     - ✅ Pixel 5 或 Pixel 6 (API 30-34)
     - ✅ 1080x2400 或 1440x3040 解析度
   - 點擊 ▶️ 按鈕啟動模擬器

4. **等待完全啟動**（約 30-60 秒）
   - 看到完整的 Android 主畫面
   - 解鎖畫面（如果需要）

### 方法 B：使用命令列

```bash
# 列出所有可用的模擬器
emulator -list-avds

# 啟動指定模擬器（替換 <模擬器名稱>）
emulator -avd <模擬器名稱>
```

### ✅ 確認模擬器已連接

在 PowerShell 或 CMD 中執行：

```bash
adb devices
```

**預期輸出**：
```
List of devices attached
emulator-5554    device
```

> ⚠️ **重要**：必須看到 `emulator-xxxx` 開頭的裝置，而非實機序號

## 步驟 2️⃣：建置並安裝應用 (3 分鐘)

在專案根目錄執行以下命令：

```bash
# 建置模擬器專用版本
./gradlew.bat assembleEmulatorDebug

# 安裝到模擬器
./gradlew.bat installEmulatorDebug
```

### ✅ 確認安裝成功

1. 在模擬器上查看應用列表
2. 找到 **SmartCameraApp** 圖示
3. 點擊啟動應用

**預期行為**：
- ✅ 應用啟動，顯示相機預覽畫面
- ✅ 如果是首次啟動，會請求相機權限 → **授予權限**
- ✅ 看到**測試圖片循環播放**（這是模擬器模式的特徵）

> 💡 **提示**：模擬器版本會自動使用 `FakeCameraDataSource`，顯示預設的測試圖片

### ⚠️ 常見問題處理

#### Q: 腳本顯示「未偵測到模擬器」？
```
❌ 未偵測到模擬器！請先啟動模擬器
   提示: emulator -avd <your_emulator_name>
```
**解決**：
1. 確認模擬器已啟動
2. 執行 `adb devices` 確認連接
3. 如果看到實機序號，請拔除實機 USB

---

#### Q: 測試圖片沒有人臉？
**解決**：
1. 檢查 `app/src/debug/assets/test_images/` 是否有圖片
2. 如果沒有，應用會生成**灰底白框**的 fallback 圖片
3. 可以暫時使用 fallback 進行測試

---

#### Q: 應用沒有偵測到人臉？
**可能原因**：
1. 測試圖片中確實沒有人臉（正常）
2. ML Kit 無法辨識 fallback 圖片（正常）
3. 使用**實機拍攝的測試圖片**可獲得最佳效果

---

#### Q: 想跳過某個場景？
**操作**：
- 當腳本提示時，輸入 **`s`** (skip) 並按 Enter
- 或直接按 Enter 不捕獲（取決於腳本版本）

---

#### Q: 想提前結束測試？
**操作**：
- 輸入 **`q`** (quit) 並按 Enter
