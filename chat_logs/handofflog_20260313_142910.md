## 1. 專案背景 (Context)

SmartCameraApp1 是一個 Android AI 攝影助手 App（Kotlin + CameraX + ML Kit + Jetpack Compose）。

本 session 的任務是實作 **v2.12.0-15：Focus Domain Model Pipeline**，這是一套全新的對焦管線，以「並行雙軌 + Feature Flag」策略與舊路徑共存，未來驗收後才移除舊路徑。

**核心問題**：現有對焦管線（CameraViewModel → focusOnPoint → AfStateMachine）混雜 UI 狀態、座標轉換、硬體觸發，難以測試與擴展。新 Pipeline 拆分為：
- `TargetTracker`：目標追蹤（IoU rebinding + TTL）
- `EyeAfPolicyResolver`：對焦策略決策
- `FocusController`：硬體觸發（CameraX）
- `FocusStateMachine`：UI 狀態機
- `FocusUiState`：Compose UI 消費的輸出
