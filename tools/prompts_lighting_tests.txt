# Key Features - Technical Specifications for Lighting Tests:
# Based on AnalyzeLightingUseCase.kt detection criteria:
#
# Normal Lighting:
#   - Highlights < 15% of pixels
#   - Average luminance >= 20% (51/255)
#   - Dynamic range < 180
#
# Overexposure:
#   - Highlight ratio (240-255 luminance) > 15% of pixels
#   - Blown out details in bright areas
#
# Underexposure:
#   - Average luminance < 20% (51/255)
#   - Dark shadows dominate the image
#
# High Contrast:
#   - Highlights > 10% AND Shadows > 10%
#   - OR Dynamic range > 180
#   - Mixed bright and dark regions
#
# Backlight (Highest Priority):
#   - Subject luminance < 30% (76/255)
#   - Background luminance > 70% (178/255)
#   - OR Significant luminance difference > 80
#   - Subject appears as silhouette
