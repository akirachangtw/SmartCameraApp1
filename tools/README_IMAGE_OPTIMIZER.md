# 圖片優化工具 - Python GUI 版本

## 🎯 功能特色

✅ **GUI 介面** - 直覺的圖形化操作介面
✅ **目錄選擇** - 自由選擇來源圖片目錄
✅ **自動輸出** - 輸出至 `[來源目錄]/optimize/` 子目錄
✅ **批次處理** - 一次處理整個資料夾
✅ **尺寸調整** - 自動調整至適合手機螢幕的尺寸
✅ **高品質壓縮** - JPEG 品質 85，保留細節
✅ **即時日誌** - 顯示每個檔案的處理結果

## 📐 處理規則

### 尺寸調整規則

| 圖片方向 | 最大尺寸 | 說明 |
|---------|---------|------|
| **直向** (高 > 寬) | 1080 × 1920 | 適配直向手機螢幕 |
| **橫向** (寬 ≥ 高) | 1920 × 1080 | 適配橫向顯示 |

### 處理邏輯

```mermaid
graph TD
    A[讀取圖片] --> B{判斷方向}
    B -->|直向| C[最大 1080×1920]
    B -->|橫向| D[最大 1920×1080]
    C --> E[保持寬高比縮放]
    D --> E
    E --> F{需要轉換格式?}
    F -->|PNG/透明| G[轉換為 RGB 白底]
    F -->|其他| H[保持 RGB]
    G --> I[JPEG 壓縮 品質85]
    H --> I
    I --> J[儲存至 optimize 資料夾]
```

### 壓縮設定

- **JPEG 品質**: 85 (0-100)
- **縮放演算法**: LANCZOS (高品質)
- **優化**: 啟用 JPEG 優化
- **格式轉換**: 所有圖片統一輸出為 `.jpg`

## 📝 使用步驟

### 1️⃣ 選擇來源目錄
1. 點擊「📁 選擇目錄」按鈕
2. 瀏覽並選擇包含圖片的資料夾
3. 工具會自動：
   - 掃描圖片數量
   - 設定輸出目錄為 `[來源]/optimize/`

### 2️⃣ 確認設定
- 檢查來源目錄路徑
- 確認輸出目錄（自動建立）
- 查看優化設定（固定參數）

### 3️⃣ 開始處理
1. 點擊「▶ 開始處理」按鈕
2. 確認處理對話框
3. 等待處理完成
4. 查看日誌了解每個檔案的處理結果

### 4️⃣ 檢查結果
- 開啟 `[來源目錄]/optimize/` 資料夾
- 所有優化後的圖片都在此目錄
- 檔名格式：`opt-原檔名.jpg`（自動轉小寫）
- **`opt-` 前綴的好處**：
  - ✅ 容易識別已優化的檔案
  - ✅ 避免與原始檔案混淆
  - ✅ 批次處理時更好管理

## 💡 實際範例

### 輸入範例
```
D:\Photos\TestImages\
├── IMG_001.PNG      (4000 × 3000, 2.5 MB)
├── photo_002.jpg    (6000 × 4000, 3.8 MB)
└── screenshot.png   (1080 × 2340, 1.2 MB)
```

### 處理後
```
D:\Photos\TestImages\
├── optimize\
│   ├── opt-img_001.jpg      (1920 × 1440, 480 KB)  # opt- 前綴
│   ├── opt-photo_002.jpg    (1920 × 1280, 520 KB)  # opt- 前綴
│   └── opt-screenshot.jpg   (1080 × 2340, 380 KB)  # opt- 前綴
└── [原始檔案保持不變]
```

**檔名規則**：
- ✅ 統一轉為小寫
- ✅ 加上 `opt-` 前綴（optimize 的縮寫）
- ✅ 統一副檔名為 `.jpg`

## 🔧 技術細節

### 支援的圖片格式

**輸入格式**:
- `.jpg` / `.jpeg`
- `.png`
- `.bmp`
- `.gif`
- `.webp`

**輸出格式**:
- `.jpg` (統一格式)

### 特殊處理

1. **透明背景**: PNG 透明背景會轉換為白色背景
2. **檔名處理**:
   - 自動轉換為小寫
   - 加上 `opt-` 前綴
   - 統一副檔名為 `.jpg`
3. **尺寸檢查**: 已符合尺寸的圖片僅進行壓縮
4. **錯誤處理**: 個別檔案錯誤不影響其他檔案

## 🐛 疑難排解

### 問題 1: 缺少 Pillow 模組

**錯誤訊息**:
```
ModuleNotFoundError: No module named 'PIL'
```

**解決方法**:
```bash
pip install Pillow
```

### 問題 2: 圖片處理失敗

**可能原因**:
- 檔案損壞
- 格式不支援
- 檔案權限問題

**解決方法**:
- 查看日誌中的錯誤訊息
- 嘗試單獨處理該檔案
- 確認檔案可正常開啟

### 問題 3: 輸出目錄建立失敗

**可能原因**:
- 權限不足
- 磁碟空間不足

**解決方法**:
- 以管理員身分執行
- 檢查磁碟空間

## 📊 效能參考

**處理速度** (依硬體而異):
- 小圖片 (<1MB): ~0.1 秒/張
- 中圖片 (1-5MB): ~0.3 秒/張
- 大圖片 (>5MB): ~0.5 秒/張

**壓縮效果**:
- 平均壓縮率: 60-80%
- PNG → JPG: 通常可減少 70-90%
- JPG → JPG: 通常可減少 40-60%
