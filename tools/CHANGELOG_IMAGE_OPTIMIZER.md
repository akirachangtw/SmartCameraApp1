# 圖片優化工具 - 更新日誌

## v1.1 (2026-01-15)

### ✨ 新增功能
- **檔名前綴**: 輸出檔名自動加上 `opt-` 前綴
  - 範例：`IMG_001.PNG` → `opt-img_001.jpg`
  - 好處：更容易識別優化後的檔案

### 🎨 改進項目
- **日誌顯示**: 處理成功後顯示輸出檔名
  - 範例日誌：
    ```
    [14:30:25] [i] [1/5] 處理: IMG_001.PNG
    [14:30:25] [i]   原始尺寸: 4000x3000
    [14:30:25] [✓]   ✓ 4000×3000 → 1920×1440 | 2400.0KB → 480.0KB (-80.0%)
    [14:30:25] [i]   → 儲存為: opt-img_001.jpg
    ```

### 📝 更新說明文件
- 更新所有範例反映新的檔名格式
- 新增 `opt-` 前綴的好處說明
- 更新 GUI 介面預覽

---

## v1.0 (2026-01-15)

### 🎉 首次發布
- 完整的 GUI 圖形介面
- 支援自由選擇來源目錄
- 自動建立 `optimize` 子目錄
- 智慧尺寸調整（1080×1920 / 1920×1080）
- 高品質 JPEG 壓縮（品質 85）
- 批次處理多個圖片
- 即時處理日誌
- 支援多種圖片格式（JPG/PNG/BMP/GIF/WebP）
- 使用 `.pyw` 副檔名（無主控台視窗）
- 非同步處理（GUI 不凍結）

| 版本 | 輸入 | 輸出 |
|------|------|------|

## 升級說明

**從 v1.0 升級到 v1.1**:
- ✅ 直接覆蓋 `optimize-test-images.pyw` 即可
- ✅ 不需要重新安裝依賴套件
- ✅ 向下相容，不影響現有功能

**注意事項**:
- 新版本處理的檔案會有 `opt-` 前綴
- 如需保持舊的檔名格式，可繼續使用 v1.0
- 兩個版本可以共存（重新命名其中一個）
