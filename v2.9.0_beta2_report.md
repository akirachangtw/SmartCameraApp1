## Root Cause Analysis

### Why is Graphics Memory Higher?

**Primary Cause**: Resolution Mismatch
- **Expected**: 480x360 = 172,800 pixels
- **Actual**: 1080x1080 = **1,166,400 pixels (6.75x larger!)**
- Each Bitmap: 1080×1080×4 bytes = **4.4 MB** (vs 0.66 MB for 480x360)

**Secondary Cause**: CameraX Resolution Selection
- 480x360 may not be in Pixel 9a's supported resolution list
- CameraX fallback to nearest: 1080x1080
- Need to check supported resolutions via CameraX API

### Why is Beta2 Better than Beta1?
