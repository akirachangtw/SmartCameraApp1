# SmartCameraApp1 功能缺失分析報告

根據對 SmartCameraApp1 專案的 `README.md`、`CameraScreen.kt` 及 `CameraViewModel.kt` 的代碼分析，目前應用程式主要專注於 **AI 構圖輔助** 與 **光線分析**。

以下是與市面上專業手機相機 App 相比，目前尚缺少的常見功能分析：

### 📸 拍攝模式類 (Shooting Modes)

*   **錄影模式 (Video Recording)**
    *   支援拍攝影片，通常包含解析度選擇 (1080p, 4K) 與幀率設定 (30fps, 60fps) 及防手震功能。
*   **人像模式 (Portrait Mode)**
    *   利用 AI 算法識別主體與背景，模擬單眼相機的大光圈背景虛化效果 (Bokeh) 以突出人物。
*   **夜景模式 (Night Mode)**
    *   透過長曝光與多幀合成 (Multi-frame stacking) 技術，在極低光環境下提升亮度並減少噪點。
*   **全景模式 (Panorama)**
    *   引導使用者水平或垂直移動手機，自動將多張連續照片接合為一張寬幅全景照片。
*   **慢動作 (Slow Motion)**
    *   以高幀率 (如 120fps, 240fps) 錄製影片，播放時呈現慢動作效果，適合拍攝快速運動。
*   **縮時攝影 (Time Lapse)**
    *   以低幀率長時間錄製，將長時間的變化 (如雲朵移動、車流) 濃縮在短時間內播放。
*   **微距模式 (Macro Mode)**
    *   針對極近距離 (通常 < 5cm) 的物體進行對焦優化，用於拍攝花蕊、昆蟲等微小細節。

### ⚙️ 專業控制類 (Pro Controls)

*   **專業模式 (Pro / Manual Mode)**
    *   允許使用者手動單獨調整 **ISO 感光度**、**快門速度 (Shutter Speed)**、**白平衡 (White Balance)**、**手動對焦 (Manual Focus)** 與 **曝光補償 (EV)**。
*   **RAW 格式支援 (RAW Support)**
    *   支援儲存 DNG 格式的原始影像數據，保留完整的感光元件資訊，提供專業攝影師更大的後期修圖寬容度。
*   **對焦峰值 (Focus Peaking)**
    *   在手動對焦模式下，以高亮顏色標示畫面中合焦的邊緣，輔助使用者確認對焦準確度。

### 🛠️ 實用工具類 (Tools & Settings)

*   **倒數計時器 (Timer)**
    *   提供延遲拍攝選項 (常見為 3秒、10秒)，方便自拍或防止按下快門時的手震。
*   **連拍模式 (Burst Mode)**
    *   長按快門鍵時進行高速連續拍摄，用於捕捉運動瞬間或挑選最佳表情。
*   **即時濾鏡 (Live Filters)**
    *   提供多種色彩風格檔 (如黑白、冷暖色调、復古風)，讓使用者在拍攝前即可預覽效果。
*   **QR Code 掃描器 (QR Code Scanner)**
    *   整合掃描功能，直接辨識畫面中的 QR Code 並提供連結跳轉。
*   **地理標記 (Geo-tagging)**
    *   在照片的 EXIF 資訊中記錄拍攝地點的 GPS 座標。
*   **快門聲音控制 (Shutter Sound Control)**
    *   允許使用者關閉拍照時的快門聲音 (視地區法規而定)。

### 結論

目前 SmartCameraApp1 的優勢在於 **AI 構圖分析 (三分法、水平儀)** 與 **光線智慧偵測 (HDR 警告)**，若要邁向全功能相機，建議優先考慮加入 **倒數計時器** 與 **錄影模式**。
