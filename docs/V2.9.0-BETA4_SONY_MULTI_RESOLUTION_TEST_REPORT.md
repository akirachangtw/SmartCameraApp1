## Analysis

### Resolution Selection Behavior

**Sony XQ-BT52 Supported Resolutions** (within ≤800px filter):
- Only **640x480** is available
- 480x360: Not supported → CameraX selects 640x480
- 720x540: Not supported → CameraX selects 640x480
- 800x600: Not supported → CameraX selects 640x480

**Conclusion**: All plans run at the same actual resolution (640x480).

### Graphics Memory Comparison

```
Plan B (640x480): 45.9 MB  ⭐ Best
Plan A (480x360): 47.5 MB  (+3.5%)
Plan C (720x540): 46.5 MB  (+1.3%)
Plan D (800x600): 53.4 MB  (+16.3%) ⚠️
```

**Why Plan D has higher memory?**
- Possible buffer allocation based on target resolution
- CameraX may pre-allocate for 800x600 even though actual is 640x480

### FPS Performance Comparison

```
Plan B: 27.6-30.2 FPS  ⭐ Best
Plan A: 28.1-29.6 FPS  (Similar)
Plan C: 25.1-28.3 FPS  (Slightly lower)
Plan D: 27.0-28.2 FPS  (Similar)
```

**All plans deliver >25 FPS** (target: >20 FPS) ✅

### Battery Impact Discovery

**Critical Finding**:
- First test (17:36) with battery <1%: FPS 11-13 ❌
- Re-test (20:52) with battery charged: FPS 28-30 ✅

**Battery level significantly affects performance!** Always test with >50% battery.

## Recommendations

### 🎯 Production Recommendation: Plan B (640x480)

**Reasons**:
1. **Exact match** with hardware capability (640x480)
2. **Lowest Graphics memory** (45.9 MB)
3. **Highest FPS** (27.6-30.2 FPS)
4. **Code clarity**: Target = Actual (no confusion)
5. **No overhead**: No wasted buffer allocation

### Implementation

Set target resolution to **640x480**:

```kotlin
val targetResolution = Size(640, 480)
```

**Expected Production Performance**:
- Graphics Memory: ~46 MB @ T0, ~80-100 MB @ T10 (estimated)
- FPS: 25-30 FPS (normal conditions)
- FPS: 20-25 FPS (after thermal throttling at 4-6 min)

### Alternative Considerations

**If AI accuracy requires higher resolution**:
- Must use resolution >800px (e.g., 1280x720)
- Modify ResolutionFilter to allow `width <= 1280 && height <= 720`
- Accept higher Graphics memory (~150-180 MB)

**Current 640x480 should be sufficient for**:
- ML Kit face detection at 1-2m distance ✅
- OpenCV composition analysis ✅
- Portrait photography use cases ✅
