- Camera increases exposure time to capture more light
- Longer exposure = Lower FPS (~16-17 FPS)
- Trade-off: Better image quality vs lower frame rate
- ✅ **Hardware auto-optimization, not a bug**

**Good Light (Lamp ON)**:
- Camera uses shorter exposure time
- Shorter exposure = Higher FPS (27-29 FPS)
- Optimal performance achieved
- ✅ **Software optimization working correctly**

## Technical Deep Dive

### BitmapPool Optimization Details

**Problem**: Floating-point dimension calculation causing key explosion
```kotlin
// Before (v2.8.3): Floating-point errors
val dstRect = RectF(...)
matrix.mapRect(dstRect)
val outWidth = ceil(dstRect.width()).toInt()  // 721, 719, 722, etc.
val outHeight = ceil(dstRect.height()).toInt()
```

**Solution**: Fixed integer dimension calculation
```kotlin
// After (v2.8.4): Exact integer dimensions
val (outWidth, outHeight) = when (degrees) {
    90, 270 -> srcHeight to srcWidth  // Swap for portrait
    else -> srcWidth to srcHeight      // Keep for landscape
}
```

**Result**:
- Before: 10+ pool keys (721x720, 719x720, 720x721, 720x719, etc.)
- After: 1 pool key (720x720 consistently)
- Hit rate: <50% → 99%

### Pipeline Architecture

**Camera Pipeline** (runs at 27-29 FPS):
```
CameraX ImageAnalysis (30 FPS cap)
  ↓ YUV Image (720x720)
  ↓
LiveCameraSource
  ↓ YUV→RGB Conversion (4.6ms) - RenderScript
  ↓ RGB Bitmap (720x720)
  ↓ Transform/Rotation (18.3ms) - Canvas
  ↓ Final Bitmap (720x720)
  ↓
StateFlow → CameraViewModel → CameraScreen
  ↓ Compose Rendering
  ↓ Display (27.2 FPS actual)
```

**Analysis Pipeline** (runs at 10 FPS, decoupled):
```
CameraViewModel.previewBitmap
  ↓ .sample(100ms) - Throttle to 10 FPS
  ↓
observePreviewForAnalysis()
  ↓ Bitmap → ML Kit InputImage (~0ms)
  ↓ ML Kit Detection (~120ms) - Face + Object
  ↓ Composition Analysis (~5ms)
  ↓ Lighting Analysis (~28ms)
  ↓ Total E2E: ~140ms (supports 7 FPS theoretical max)
  ↓ Actual: 10 FPS (throttled, doesn't block camera)
```

**Key Insight**: Analysis pipeline is **decoupled** from camera pipeline via `.sample(100)`, so ML Kit's 120ms latency **does not affect camera FPS**.
