## Implementation Details

### New Function: `selectDeviceOptimalResolution()`

**Location**: `LiveCameraSource.kt:1086-1119`

**Signature**:
```kotlin
private fun selectDeviceOptimalResolution(supportedSizes: List<Size>): Triple<Size, Int, Int>
```

**Returns**:
- `targetResolution`: Size - The target resolution to request from CameraX
- `maxFilterWidth`: Int - Maximum width for ResolutionFilter
- `maxFilterHeight`: Int - Maximum height for ResolutionFilter

### Device Detection Strategy

**1. Google Pixel Devices**:
```kotlin
if (manufacturer.equals("Google", ignoreCase = true) && model.contains("Pixel", ignoreCase = true)) {
    val has800x600 = acceptableResolutions.any { it.width == 800 && it.height == 600 }
    return if (has800x600) {
        Triple(Size(800, 600), 1280, 720)  // Prefer 800x600 for better AI
    } else {
        Triple(Size(640, 480), 800, 600)   // Fallback
    }
}
```

**2. Sony Devices**:
```kotlin
if (manufacturer.equals("Sony", ignoreCase = true)) {
    return Triple(Size(640, 480), 800, 600)  // Hardware limitation confirmed
}
```

**3. Generic Devices**:
```kotlin
// Auto-detect: Select largest resolution ≤800x600 from supported list
val optimal = acceptableResolutions.lastOrNull { s -> s.width <= 800 && s.height <= 600 }
if (optimal != null) {
    return Triple(optimal, 800, 600)
}
```

**4. Fallback**:
```kotlin
// If nothing matches, default to 640x480
return Triple(Size(640, 480), 800, 600)
```

## Technical Notes

### Why Sony Can't Use 800x600

**Hardware Constraint Confirmed**:
Sony XQ-BT52's camera HAL only exposes one 4:3 resolution within the ≤800x600 range: **640x480**.

**Evidence**:
1. beta4 testing: Target 800x600 → Actual 640x480
2. beta4 testing: Target 1280x720 → Actual 640x480 (even with relaxed filter)
3. beta5 supported list: Only 640x480 appears in 4:3 ratio below 720p

**Other available resolutions**:
- 720x480 (3:2 ratio) ❌ Wrong aspect ratio
- 720x720 (1:1 ratio) ❌ Wrong aspect ratio
- 1280x720 (16:9 ratio) ❌ Would exceed 800px filter

**Conclusion**: 640x480 is the only viable choice for Sony within memory constraints.

### Why Pixel Should Use 800x600

**AI Analysis Requirements**:

**ML Kit Face Detection**:
- Minimum: 320x240 ✅
- Recommended: 640x480 ✅
- Optimal: 800x600 ⭐ (especially for far distance 4m+)

**OpenCV Composition Analysis**:
- Less resolution-sensitive
- 640x480 sufficient ✅
- 800x600 nice-to-have ⭐

**Multi-person Scenarios**:
- 640x480: Good for 1-2 people at 1-2m ✅
- 800x600: Better for 3+ people or 2-4m distance ⭐

**Memory Trade-off**:
- 640x480: 103 MB Graphics on Pixel 9a
- 800x600: 107 MB Graphics on Pixel 9a
- **Delta**: Only +4 MB for significantly better AI

**Conclusion**: 800x600 is worth the 4 MB memory cost for improved AI accuracy.
