## 驗收架構基線（每個 TC 均須符合）

> 根據 `devspec/feature_record_Backlog.md` §M / §N / §O 三條真理

1. **§M 真理一**：`reduceLensState()` 中 `isFixedFocus` guard 必須是第一個判斷
   - `isFixedFocus=true && primaryTarget != null` → `LensFocusState.Focused`（Cyan 夾爪）
   - `isFixedFocus=true && primaryTarget == null` → `LensFocusState.NotRequested`（無任何鎖定 UI）
   - `UnsupportedFixedFocus` 語義僅保留給 HAL 告知 AF 不支援的情境

2. **§N 真理二**：Tap-to-Focus 同步路徑
   - 點擊後同步 push `FocusUiState(TrackingStable, YELLOW, 72dp box)` — 不等待 HAL
   - `tap_optimistic` stableId 僅出現在 `setTapToFocusIntent()` push 中
   - `runNewFocusPipeline()` 輸出絕不產生 `primaryStableId = "tap_optimistic"`
   - `DefaultFocusStateMachine.buildOverlayModel()` 禁止產生 `OverlayColor.YELLOW` unless `AEAFLocked`

3. **§O 真理三**：Primary Monopoly
   - Primary: 1-Euro Filter（`RectFilter`）平滑 + 完整動畫
   - Secondary: 10dp 四角 brackets、固定 alpha=0.3、`FocusOverlay` 內無 `animateXxx`

## TC-01：後鏡頭基本對焦（Pixel 9a 後鏡頭）

**裝置**: Pixel 9a
**鏡頭**: 後鏡頭（`isFixedFocus=false`）
**前置條件**: 應用啟動至相機畫面

### 步驟

1. 對準有明顯特徵的靜態物體
2. 單指點擊畫面任意位置

### 預期行為

- [ ] 點擊後 **<16ms** 出現 Yellow 72dp 正方形框（§N 樂觀 UI）
- [ ] **約 100ms** 後框變為 Cyan、出現夾爪收縮動畫（3-phase tween 350ms）
- [ ] Logcat 出現 `[v2.12.0-17][SV-FIX-2] AF+AE (rear camera) shouldTriggerFocus=true`
- [ ] AF 完成後框穩定，無 AF Hunting（反覆 `NotFocused` 循環）

### FAIL 判定

- Yellow 框未出現（§N 違反）
- Yellow 持續超過 500ms 未切換至 Cyan
- Logcat 出現 `AF Hunting` 或連續 `lens=NotFocused` 超過 3 次

## TC-02：前鏡頭固定焦距視覺欺騙（Pixel 9a 前鏡頭）

**裝置**: Pixel 9a
**鏡頭**: 前鏡頭（`isFixedFocus=true`）
**前置條件**: 切換至前鏡頭，對準自己臉部（須在 ML Kit 偵測範圍內）

### 步驟

1. 切換前鏡頭
2. 確認 ML Kit 偵測到人臉（`primaryTarget != null`）
3. 單指點擊臉部區域

### 預期行為

- [ ] 點擊後立即顯示 Yellow 72dp 框（§N 樂觀 UI）
- [ ] **不等待 HAL**，約 100ms 後直接顯示 Cyan 夾爪動畫
- [ ] Logcat 出現 `[v2.12.0-17][SV-FIX-2] AE+AWB only (front/fixed-focus)`（確認無 FLAG_AF）
- [ ] **不出現** `UnsupportedFixedFocus` log（§M 語義正規化）
- [ ] Logcat 確認 `LensFocusState=Focused`（§M 強制映射）
- [ ] Cyan 夾爪框穩定顯示（無死鎖、無 Hunting）

### FAIL 判定

- 前鏡頭出現 AF Hunting（代表 FLAG_AF 被錯誤送出）
- 夾爪動畫不觸發（`UnsupportedFixedFocus` 未修正）
- Logcat 出現 FLAG_AF 被 HAL 靜默失敗的跡象
