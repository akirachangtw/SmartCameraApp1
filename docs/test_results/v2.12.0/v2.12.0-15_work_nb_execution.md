```bash

```


## 3. 測試案例

### TC-15-S1：App 啟動 DI 圖完整性

**步驟**：
1. 啟動 App
2. 等待 Camera Preview 顯示（約 3 秒）

**預期**：
- App 正常啟動，無 crash
- Logcat **不得**出現 `Hilt injection exception` 或 `DaggerComponent` 相關錯誤

---

### TC-15-S2：新 Pipeline 啟動確認

**步驟**：
1. App 啟動後，讓鏡頭對準人臉或物體（不需點擊）
2. 等待 Eye-AF 自動觸發（約 2-5 秒）

**預期 Logcat**：
```
[v2.12.0-15] Pipeline: visual=TrackingStable
```
或
```
[v2.12.0-15] Pipeline:
```

> 若 Logcat 無此行但 App 正常：確認 `FOCUS_PIPELINE_V2=true` 路徑已走到，可搜尋 `Pipeline:` 確認

---

### TC-15-S3：FocusController 觸發

**步驟**：
1. 點擊預覽畫面（tap-to-focus）
2. 觀察對焦框出現

**預期 Logcat**：
```
[v2.12.0-15] FocusController result: triggerSent=true
```

---

### TC-15-S4：Dumb Pipe No-op 確認（可選）

本 TC 為 optional — `setPreviewSize()` / `startOpticalFlowTracking(x,y)` 的呼叫路徑在 v2.12.0-15 已升級為 no-op，但 CameraViewModel 現有路徑已不再呼叫 preview-coord 版本，故此 log 可能不出現。

**若出現**，Logcat 應顯示：
```
[v2.12.0-15] setPreviewSize no-op
[v2.12.0-15] startOpticalFlowTracking(preview-coord) no-op — use startOpticalFlowTrackingImageCoords()
```

**若不出現**：為預期行為（呼叫路徑已完全切換至 image-coord 版本）

---

### TC-R-12~14：v2.12.0-12/13/14 核心 Regression

| TC | 描述 | 預期行為 |
|----|------|---------|
| TC-05 | 後鏡頭 Eye-AF Locked 動畫 + dwell 淡出 | Cyan 框 → Locked 機械夾爪動畫 → alpha=0.4 淡出 |
| TC-11 | 鏡頭切換後 AF 不死鎖 | 後鏡頭 Locked → 切換前鏡頭 → 前鏡頭可正常 AF，無 Locked 殘留 |
| TC-13-T1 | bbox 追蹤框隨人臉縮放 | 後鏡頭人臉靠近/遠離，框連續縮放不凍結 |
| TC-13-T2 | Cyan vs Yellow 分離 | Eye-AF → Cyan；長按 → Yellow；顏色不混淆 |
| TC-14-T1-02 | 前鏡頭 tap 精準度 | 對焦框貼合人臉，不明顯偏移 |
| TC-14-T1-03 | 後鏡頭 tap 精準度 | 對焦框貼合目標，不明顯偏移 |

Regression 詳細步驟參考：`docs/test_results/v2.12.0/v2.12.0-13-14_work_nb_execution.md`
