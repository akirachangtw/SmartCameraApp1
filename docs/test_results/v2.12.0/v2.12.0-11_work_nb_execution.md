## 3. 測試案例

### TC-05 【Regression】後鏡頭正常 AF Lock/Dwell

**操作**：後鏡頭對準人臉，靜置等待 Eye-AF 自動觸發

**預期**：
- 對焦框出現並縮放至人臉大小
- 框進入 Locked 動畫（機械夾爪）
- 5 秒 dwell 後淡出（α→0.4）

**PASS 標準**：AF 正常 lock，無異常 hunting

---

### TC-06a-v2 【Main】前鏡頭對焦框隨距離縮放

> 此為 v2.12.0-10 TC-06a FAIL 的修復版驗收

**操作**：
1. 切換至前鏡頭
2. 對準人臉（近距 ~30cm）→ 觀察框大小
3. 遠離（~80cm）→ 觀察框縮小
4. 再次靠近 → 觀察框再次放大

**預期**：框隨人臉 bbox 動態縮放，近大遠小

**Logcat 確認**：
```
[v2.12.0-11] Fixed-focus Locked — UI-only update, skipping focusOnPoint
```

**PASS 標準**：框大小隨距離改變，不固定在初次 lock 的大小

---

### TC-06b 【Regression】後鏡頭非人臉點擊顯示 72dp 正方形

**操作**：後鏡頭對準非人臉區域（牆壁、桌面），點擊對焦

**預期**：出現 72dp 正方形對焦框，非臉部形狀

**PASS 標準**：正方形框（之前 v2.12.0-10 已 PASS，確認 regression 未發生）

---

### TC-07 【Main】前鏡頭 AF Hunting 消除

**操作**：
1. 前鏡頭對準人臉
2. 等待 Eye-AF 自動觸發並 Locked
3. 保持靜止 10-15 秒，觀察是否持續重新對焦

**預期**：
- 第一次對焦成功後進入 Locked
- Logcat 持續出現 `Fixed-focus Locked — UI-only update`（只更新 UI，不呼叫 HAL）
- **不再出現** 反覆的 `startFocusAndMetering` / `Focus successful` / `Focus failed` 循環

**Logcat 確認**：
```
[v2.12.0-11] Fixed-focus Locked — UI-only update, skipping focusOnPoint
```

**PASS 標準**：Locked 後 10 秒內，上述 Log 出現 5 次以上，且無 `Focus failed` / `Focus successful` 反覆出現

---

### TC-08 【Main】後鏡頭 Hysteresis 抑制微抖動

**操作**：
1. 後鏡頭對準人臉，等待 AF Locked
2. 保持臉部相對靜止（允許輕微移動），觀察 AF 是否過度重觸發

**預期（DEBUG build）**：
```
[v2.12.0-11] Hysteresis gate (Locked): delta=XXpx < 135px — skip
```

**PASS 標準**：Locked 後靜止狀態下，AF 不在 5 秒內重觸發（除非明顯移動 > 135px）

---

### TC-09 【Main】Suspended 模式觸發（模擬連續失敗）

> ⚠️ 此 TC 較難在正常場景重現，視設備條件決定是否執行

**操作**：後鏡頭對準極難對焦的場景（純白牆壁、無紋理表面），等待多次 AF 失敗

**預期**：
```
[v2.12.0-11] Auto-retry suspended (failCount=3) — awaiting UserTap
```
出現後，AF 停止自動重試

**PASS 標準**：Logcat 出現 Suspended log 後，後續不再出現 `startFocusAndMetering`

---

### TC-10 【Main】UserTap 解除 Suspended

**操作**：TC-09 的 Suspended 狀態下，手動點擊螢幕對焦

**預期**：
```
[v2.12.0-11] UserTap: eyeAfThrottle.reset() — Suspended state cleared
```
點擊後 AF 正常觸發

**PASS 標準**：UserTap 後 AF 恢復正常觸發

---

### TC-11 【Main】鏡頭切換後 AF 狀態乾淨重置

**操作**：
1. 前鏡頭對焦 Locked
2. 切換至後鏡頭
3. 觀察 AF 狀態是否乾淨（無 Locked 殘留）

**預期**：
```
[v2.12.0-11] switchCamera: eyeAfThrottle.reset() + afState=Idle
```

**PASS 標準**：切換後對焦框歸零，後鏡頭從 Idle 重新開始
