## Step 4：驗收標準

### TC-25-01：[CoordSystem] log 輸出正常

**操作**：啟動 App → 對準人臉 → 等待 ML Kit 偵測

**預期 log 格式**：
```
[CoordSystem] imageProxy=480x640 (raw=640x480, rot=90°) preview=1080x2340 contentBounds=[L=0.0, T=0.0, W=1080.0, H=2340.0]
```

**驗收規則**：

| 欄位 | 驗收條件 | 說明 |
|------|---------|------|
| `preview=` | **不得為 `0x0`** | SP-3：純 PreviewView 尺寸，若為 0 代表賦值時機問題 |
| `imageProxy=` | W > H（直立手機）| SP-1：rotation swap 正確，480x640 表示 90° 旋轉已套用 |
| `preview=` 值 | **不等於** `contentBounds.right` | 確認 fallback 已移除 |
| `contentBounds` | L=0, T=0, W/H 合理正值 | UI 邊界資訊僅供診斷，不影響幾何計算 |

### TC-25-02：無 SecurityException（HIGH_SAMPLING_RATE_SENSORS）

**操作**：啟動 App → 移動手機觸發 IMU

**預期**：Logcat 無 `SecurityException: HIGH_SAMPLING_RATE_SENSORS` 錯誤

**失敗判斷**：若出現以下 log 代表權限仍未生效（需確認 Manifest 是否正確打包）：
```
SecurityException: To use SENSOR_DELAY_FASTEST, app needs HIGH_SAMPLING_RATE_SENSORS permission
```

### TC-25-03：PreviewView size unknown 警告不出現

**預期**：Logcat 無以下 log（若出現代表 previewWidth/Height 仍為 null）：
```
[CoordSystem] PreviewView size is unknown, fallback path triggered
```
