**結果**: ❌ FAIL

**現象**: 對焦框不顯示 Locked 動畫（機械夾爪），不淡出至 α=0.4

**Logcat 關鍵行**:
```
[v2.12.0-11] UI frame update (AfState=AfState$Locked@f050c37)
FocusClamp: LaunchedEffect(focusSuccess=null, isLocked=false) → Clamp RESET
```

### TC-11【Main】鏡頭切換後 AF 狀態乾淨重置

**結果**: ❌ FAIL（嚴重）

**現象**: 後鏡頭 AF Locked 後切換前鏡頭，前鏡頭 HAL AF 永久失效，需重啟 App 才能恢復

**可重現步驟**:
1. 啟動 App（後鏡頭）
2. 對準人臉，等待 AF 自動觸發（Locked 狀態）
3. 切換至前鏡頭
4. 前鏡頭對準人臉 → AF 完全無反應

**Logcat 關鍵行**:
```
# switchCamera reset log 完全未出現
[v2.12.0-11] switchCamera: eyeAfThrottle.reset() + afState=Idle  ← 未出現！

# 前鏡頭啟動後立即 Locked（AfState 未被重置）
[v2.12.0-11] UI frame update (AfState=AfState$Locked@627f94c)   ← 新 PID 仍重現
[v2.12.0-11] Fixed-focus Locked — UI-only update, skipping focusOnPoint  ← 每幀
```

**根因 Race Condition**:
```
1. 後鏡頭 focusOnPoint() coroutine in-flight（等待 HAL 結果）
2. switchCamera() → afState = AfState.Idle（line 579）
3. [Race] in-flight coroutine 回傳 Success → afState = AfState.Locked（line 1121）
         ← 覆蓋掉剛設定的 Idle！
4. 前鏡頭以 isFixedFocusLens=true + afState=Locked 啟動
5. line 1466: isFixedFocusLens && afState is Locked → return（永久跳過 HAL AF）
6. 前鏡頭 AF 死鎖，無法自動恢復
```

**修復方向**: `switchCamera()` 需先 cancel 所有 in-flight `focusOnPoint()` Job，再執行 `afState=Idle`
