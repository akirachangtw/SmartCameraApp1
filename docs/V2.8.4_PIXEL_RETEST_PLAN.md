## 🔧 故障排除

### 問題 1: FPS 低於預期

**症狀**: Average FPS < 25

**可能原因**:
1. 光線不足
2. 背景 App 占用資源
3. Debug build (非 Release)
4. 裝置溫度過高

**解決方法**:
```powershell
# 1. 確認光線
# 目視檢查 + 拍照記錄

# 2. 關閉背景 App
adb shell am force-stop <package>

# 3. 確認 build 類型
adb shell pm list packages -f | Select-String "photographer"

# 4. 檢查裝置溫度
adb shell dumpsys battery | Select-String "temperature"
```

### 問題 2: BitmapPool Hit Rate < 99%

**症狀**: Hit Rate 90-95%

**可能原因**:
1. 裝置記憶體壓力
2. Pool 配置不足
3. v2.8.4 優化未正確應用

**檢查方法**:
```powershell
# 查看 BitmapPool 日誌
adb logcat -d | Select-String "BitmapPool|Pool Keys|acquire|release"
```

### 問題 3: Memory Growth 過高

**症狀**: Memory Growth > 100MB

**可能原因**:
1. 記憶體洩漏
2. BitmapPool 未正確釋放
3. 其他資源洩漏

**檢查方法**:
```powershell
# 每分鐘記錄記憶體
for ($i=1; $i -le 10; $i++) {
    adb shell dumpsys meminfo com.akirachang.ai.photographer | Select-String "TOTAL PSS"
    Start-Sleep -Seconds 60
}
```
