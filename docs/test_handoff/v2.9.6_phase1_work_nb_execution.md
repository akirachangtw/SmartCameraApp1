## 🔧 故障排除 (Troubleshooting)

### Issue 1: ADB 裝置未連接

**症狀**: `adb devices` 不顯示 Pixel 9a

**解決方案**:
```bash
# Restart ADB server
adb kill-server
adb start-server

# Re-check devices
adb devices

# If still not working:
# 1. Reconnect USB cable
# 2. On Pixel 9a: Settings → Developer options → Revoke USB debugging authorizations
# 3. Re-enable USB debugging
```

### Issue 2: 應用啟動失敗

**症狀**: 應用閃退或黑屏

**解決方案**:
```bash
# Clear app data
adb -s $env:PIXEL9A_SERIAL shell pm clear com.akirachang.ai.photographer

# Reinstall app
adb -s $env:PIXEL9A_SERIAL install -r app\build\outputs\apk\device\debug\app-device-debug.apk

# Check crash logs
adb -s $env:PIXEL9A_SERIAL logcat -d | Select-String -Pattern "FATAL|AndroidRuntime"
```

### Issue 3: 照片未找到

**症狀**: `/sdcard/DCIM/SmartCamera/` 目錄為空

**解決方案**:
```bash
# Search for photos in all locations
adb -s $env:PIXEL9A_SERIAL shell "find /sdcard -name '*.jpg' -type f -mmin -10"

# Check app permissions
adb -s $env:PIXEL9A_SERIAL shell "dumpsys package com.akirachang.ai.photographer | grep -i STORAGE"

# If permission missing, manually grant on device:
# Settings → Apps → SmartCameraApp1 → Permissions → Storage → Allow
```

### Issue 4: EXIF 分析腳本失敗

**症狀**: `python tools/analyze_exif.py` 報錯

**解決方案**:
```bash
# Check Python installation
python --version

# Install Pillow library
pip install pillow

# Or use pip3
pip3 install pillow

# Verify installation
pip list | Select-String pillow
```

### Issue 5: 快門按鈕座標不正確

**症狀**: `adb shell input tap` 未觸發拍照

**解決方案**:
```bash
# Dump UI hierarchy
adb -s $env:PIXEL9A_SERIAL shell uiautomator dump
adb -s $env:PIXEL9A_SERIAL pull /sdcard/window_dump.xml $TEST_DIR\

# Analyze XML to find correct coordinates
# Search for: FloatingActionButton, CameraAlt icon, or resource-id containing "capture"

# Test new coordinates
adb -s $env:PIXEL9A_SERIAL shell input tap <NEW_X> <NEW_Y>
```
