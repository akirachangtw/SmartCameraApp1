## Objective

Fix BitmapPool key explosion issue to improve Transform pipeline performance before attempting full RenderScript YUV+Transform fusion (Plan B).

## Root Cause Identified

**Problem**: `transformBitmap()` used `ceil(mapRect())` to calculate output dimensions, causing floating-point errors:
- Expected: 720x720 → Actual: 721x720, 719x720, 722x720, etc.
- Result: Pool keys exploded from 2 to 10+, hit rate dropped to <50%

**Solution**: Use fixed integer dimensions based on rotation angle:
```kotlin
val (outWidth, outHeight) = when (degrees) {
    90, 270 -> srcHeight to srcWidth  // Swap for portrait
    else -> srcWidth to srcHeight      // Keep for landscape
}
```
