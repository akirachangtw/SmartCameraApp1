# v2.8.2-PhaseC Performance Optimization Plan

## Goal Description
Fix FPS drops and Memory Growth using GPU acceleration.
Analysis of Phase B-1 proved that CPU-based Integer Math is insufficient to overcome the JNI memory bottleneck. We will pivot to using **RenderScript (GPU)** for high-performance YUV conversion.

## User Review Required
> [!IMPORTANT]
> **RenderScript Deprecation**: We are using `renderscript.support.mode` to support Android 12+ devices. This is a robust production-ready solution despite the formal deprecation notice, as full migration to Vulkan/OpenGL is out of scope for this emergency fix.
