### 4. `FocusIndicator` 目前如何被呼叫

位於 `CameraScreen.kt` 第 **381–393** 行：

```kotlin
state.focusPoint?.let { (x, y) ->
    FocusIndicator(
        x = x,
        y = y,
        isTracking = state.trackedObjectId != null || state.trackedPointActive,
        ...
    )

```

- `focusPoint` 是**畫面空間 (screen-space) 座標**的 `Pair<Float, Float>`，由 `CameraState` 持有。
- 目前傳入的是單點 `(x, y)`，**沒有寬高資訊**，對焦框固定為 48.dp 正方形。

### 5. ML Kit Bounding Box 資料流

```mermaid
sequenceDiagram
    participant ML as MLKitDetector / SmartCameraAnalyzer
    participant VM as CameraViewModel
    participant State as CameraState.focusPoint
    participant UI as FocusIndicator Canvas

    ML->>VM: DetectionResult (faces, objects, imageWidth, imageHeight)
    VM->>VM: updateTrackedObjectPosition(detectionResult)
    Note over VM: boundingBox.exactCenterX/Y() → imageToScreen(x,y)
    VM->>State: state.copy(focusPoint = Pair(screenX, screenY))
    State->>UI: x=screenX, y=screenY (center only, no size)
    UI->>UI: drawRect 固定 48.dp 正方形
```

**關鍵觀察**：`CameraViewModel.updateTrackedObjectPosition()`（第 738–870 行）中：
- 從 `face.boundingBox` 或 `obj.boundingBox`（型別為 `android.graphics.Rect`）取出 `exactCenterX()` / `exactCenterY()`
- 透過 `CoordinateTransformer.imageToScreen()` 轉換為畫面座標
- 只有**中心點**被存入 `focusPoint`；**寬高完全被丟棄**
