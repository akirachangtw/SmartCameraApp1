### 架構師說明：getCameraControl 為何仍為 null？

`CameraRepository` 介面沒有 `getCameraControl()` 方法，且 `LiveCameraSource` 的 `camera.cameraControl` 是 `private lateinit var`。要真正接線需要擴展 `CameraRepository` 介面，這屬於 Step 6 的工作範圍。

目前的降級行為是正確的：`CameraXFocusController.apply()` 在 `cameraControl == null` 時會 log warning 並回傳 `triggerSent = false`，不會 crash，且 `getMeteringPointFactory` 已透過 `previewViewRef` 真正接線。
