## **2\. Core Problems to Solve**

1. **Front Camera Fixed Focus:** Focus box appears and disappears instantly because the front camera lacks a VCM (Voice Coil Motor).  
2. **Back Camera Face AF Loop:** Continuous face tracking triggers endless ACTIVE\_SCAN states, preventing a "focus successful" state.  
3. **Back Camera Object Tracking:** The focus box remains a static square and fails to dynamically map to the real object's dimensions on the UI.

## **3\. Architecture & Implementation Directives**

### **Directive A: UI Decoupling & Smoothing (FocusUiSmoother)**

* **Fixed Focus Detection:** During CameraControlAdapter initialization, use CameraCharacteristics.LENS\_INFO\_MINIMUM\_FOCUS\_DISTANCE. If the value is 0.0f, the lens is Fixed Focus. You MUST cut off the startFocusAndMetering call to the camera for this lens, allowing the UI to only draw the visual focus box without triggering hardware exceptions.  
* **UI Refresh Rate Limiting:** Implement StateFlow.sample(16L) to ensure the Compose UI receives coordinate updates at a maximum of \~60FPS.  
* **Coordinate Smoothing:** Implement a 1 Euro Filter within a FocusUiSmoother component to filter high-frequency jitter from the bounding box.  
* **State Indication:** When FocusMeteringResult.isFocusSuccessful returns true, emit a signal via CameraUiState to instantly change the smoothed bounding box color from white to green.

### **Directive B: Smart Face Tracking (FaceFocusPolicy)**

* **ML Kit Configuration:** Initialize FaceDetectorOptions with PERFORMANCE\_MODE\_FAST.  
* **Frame Rate Throttling:** The image analysis via ML Kit MUST be suppressed to **15 FPS \~ 30 FPS** to prevent CPU throttling. Implement a Token Bucket algorithm in FrameDispatcher. Use STRATEGY\_KEEP\_ONLY\_LATEST for backpressure.  
* **Multiple Faces Logic:** Default to selecting the face with the largest bounding box area or the one closest to the center. If a USER\_TAP occurs, cache the tapped face ID in FaceFocusPolicy to establish a hard lock, overriding the default selection.  
* **Low-Light Jitter Compensation:** Sample the Luma (brightness) from the ImageProxy. In low-light scenarios, dynamically increase movementTolerancePx (tolerance) and extend the lockHoldMs cooldown to prevent meaningless rescanning. Use SurfaceOrientedMeteringPointFactory to project the smoothed target back to sensor coordinates.

### **Directive C: AI-driven Object Tracking (TargetTracker)**

* **Tracking Configuration:** You MUST enable ObjectDetectorOptions.STREAM\_MODE in ML Kit to generate stable, cross-frame trackingIds.  
* **Background Threading:** Execute ObjectDetector.process() inside an isolated Executors.newSingleThreadExecutor() to avoid blocking other camera pipelines.  
* **Target Lost Grace Period:** Implement a TTL (Time to Live) Grace Period of **400ms \- 500ms** in the TargetStateStore. If a target is not reported for 500ms, declare it lost and revert the UI to the Scanning state; otherwise, maintain the old bounding box during this window.  
* **Dynamic BBox Animation:** Integrate with FocusUiSmoother to apply a spring animation to the bounding box's width/height changes, creating a fluid, dynamic scaling effect similar to native iOS camera behavior.

### **5.1 One Euro Filter (1€ Filter) Implementation**

**Context:** Used within FocusUiSmoother to filter the bounding box coordinates (Left, Top, Right, Bottom). It reduces jitter at low speeds (high noise) and reduces lag at high speeds.

// mathematically accurate 1 Euro Filter  
class OneEuroFilter(  
    private val minCutoff: Float \= 1.0f,  
    private val beta: Float \= 0.007f,  
    private val dCutoff: Float \= 1.0f  
) {  
    private var firstTime \= true  
    private var lastTime: Long \= 0L  
    private var xPrev \= 0f  
    private var dxPrev \= 0f

    private fun alpha(cutoff: Float, dt: Float): Float {  
        val tau \= 1.0f / (2.0f \* Math.PI.toFloat() \* cutoff)  
        return 1.0f / (1.0f \+ tau / dt)  
    }

    fun filter(value: Float, timestamp: Long): Float {  
        if (firstTime) {  
            firstTime \= false  
            lastTime \= timestamp  
            xPrev \= value  
            dxPrev \= 0f  
            return value  
        }

        val dt \= (timestamp \- lastTime) / 1000f // Convert ms to seconds  
        if (dt \<= 0f) return value // Prevent division by zero

        // 1\. Calculate the raw derivative (speed)  
        val dx \= (value \- xPrev) / dt  
        // 2\. Filter the derivative  
        val alphaD \= alpha(dCutoff, dt)  
        val dxHat \= dxPrev \+ alphaD \* (dx \- dxPrev)  
        // 3\. Calculate cutoff frequency based on speed  
        val cutoff \= minCutoff \+ beta \* kotlin.math.abs(dxHat)  
        // 4\. Filter the value  
        val alpha \= alpha(cutoff, dt)  
        val xHat \= xPrev \+ alpha \* (value \- xPrev)

        // Store states for next iteration  
        lastTime \= timestamp  
        xPrev \= xHat  
        dxPrev \= dxHat

        return xHat  
    }  
}

### **5.2 Token Bucket Algorithm (Frame Rate Throttling)**

**Context:** Used within FrameDispatcher to throttle the ImageProxy frames sent to ML Kit. A fast mechanism to drop frames if they arrive faster than the target FPS.

// Token Bucket for ML Kit Frame Throttling  
class TokenBucket(  
    private val maxCapacity: Int,  
    private val refillRatePerSecond: Double  
) {  
    private var tokens \= maxCapacity.toDouble()  
    private var lastRefillTimestamp \= System.nanoTime()  
    private val lock \= Any()

    /\*\*  
     \* Attempts to consume 1 token.   
     \* @return true if token was consumed (process frame), false if bucket is empty (drop frame).  
     \*/  
    fun tryConsume(): Boolean {  
        synchronized(lock) {  
            refill()  
            return if (tokens \>= 1.0) {  
                tokens \-= 1.0  
                true  
            } else {  
                false  
            }  
        }  
    }

    private fun refill() {  
        val now \= System.nanoTime()  
        // Convert nanoTime to seconds for accurate floating-point math  
        val elapsedTimeInSeconds \= (now \- lastRefillTimestamp) / 1\_000\_000\_000.0  
          
        val tokensToAdd \= elapsedTimeInSeconds \* refillRatePerSecond  
        if (tokensToAdd \> 0.001) { // Prevent micro-updates floating point inaccuracies  
            tokens \= kotlin.math.min(maxCapacity.toDouble(), tokens \+ tokensToAdd)  
            lastRefillTimestamp \= now  
        }  
    }  
}
