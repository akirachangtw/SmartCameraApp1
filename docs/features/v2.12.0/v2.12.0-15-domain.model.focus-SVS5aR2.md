### 架構師說明：為什麼用 `as? LiveCameraSource` 而非擴展 `CameraInputSource` 介面？

`CameraInputSource` 是一個通用介面，`StaticImageSource` 也實作它。若在 `CameraInputSource` 新增 `getCameraControl()`，`StaticImageSource` 需要實作（回傳 null），這樣也可以，但會污染測試用的 `StaticImageSource`。

用 `as? LiveCameraSource` 的 safe cast 更精確：只有真實硬體路徑才會回傳非 null，測試路徑自動回傳 null，符合「最小改動」原則。
