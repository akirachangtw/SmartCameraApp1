## 資料模型規格（依 §17.12.3 + §17.11）

### FocusTarget（§17.11.5）
- `stableId: String`（格式：`face:123` / `object:7` / `tap:manual:{sessionId}`）
- `type: TargetType`（FACE / OBJECT / TAP_SUBJECT / TAP_TEXTURE）
- `rectImage: RectF`、`rectView: RectF`
- `leftEyeView: PointF?`、`rightEyeView: PointF?`
- `confidence: Float`、`priorityScore: Float`
- `trackingId: Int?`、`firstSeenMs: Long`、`lastSeenMs: Long`
- `source: TargetSource`（ML_KIT_FACE / ML_KIT_OBJECT / OPTICAL_FLOW / USER_TAP）

### FocusStates（§6.2）
- `VisualTargetState`：None / Candidate / TrackingStable / VisualLocked / TrackingFade / Lost
- `LensFocusState`：NotRequested / PassiveContinuous / ActiveScan / Focused / NotFocused / UnsupportedFixedFocus
- `ExposureLockState`：Unlocked / AEAFLocked

### OverlayModel（§17.11.10）
- `primaryBox: RectF?`（null 時 Compose 必須完全隱藏，禁止 fallback 36dp 預設框）
- `secondaryBoxes: List<RectF>`
- `primaryColor: OverlayColor`（CYAN / YELLOW）
- `alpha: Float`、`showLockIcon: Boolean`
- `animation: OverlayAnimation`（NONE / PULSE / FADE / REACQUIRE）
