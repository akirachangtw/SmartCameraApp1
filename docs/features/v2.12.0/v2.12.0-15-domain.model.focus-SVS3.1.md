### 架構師說明：為什麼這個修正很重要？

`VisualLocked` 語義代表「系統已確認鎖定眼睛位置，UI 應顯示 Cyan 鎖定框」。  
`TrackingStable` 語義代表「系統正在追蹤人臉，但尚未達到眼睛級別的精確鎖定，UI 應顯示追蹤框」。

在 fixed-focus 前鏡頭上，若只有 face box 而無眼睛 landmark，顯示 `VisualLocked` 會誤導使用者認為眼睛已被精確鎖定，這違反了 SSOT 規範的視覺語義定義。

這個修改只有 1 行，風險極低，但語義正確性至關重要。
