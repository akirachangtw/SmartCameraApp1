### 關鍵分歧點分析

#### 1. Jitter 動畫 - 三種方案對比

**Claude 方案**: 微震動脈衝（正弦波 ±2px）
```kotlin
sin(time * 0.01f) * 2f * jitterIntensity
```
- 優勢: 科技感強，GPU 負載低
- 劣勢: 實作複雜度較高（1.5 天）

**Traycer 方案**: 不實作（改用 Alpha 脈衝）
```kotlin
// Alpha 0.8 ↔ 1.0 緩慢振盪（1 秒週期）
```
- 優勢: 實作簡單，零風險
- 劣勢: 視覺效果較弱

**Gemini 方案**: 呼吸訊號（StrokeWidth 呼吸）
```kotlin
// StrokeWidth 或 Glow Alpha 正弦波呼吸（800ms 週期）
```
- 優勢: 「生命感」強，符合 AI 運算概念
- 劣勢: 需測試 StrokeWidth 動畫性能

---

#### 2. 科技感增強 - 設計對比

| 方案 | 技術 | 視覺效果 | GPU 負載 | 實作時程 |
|------|------|---------|---------|---------|
| **Claude 呼吸燈** | Alpha 0.6↔1.0 + Rotation | ⭐⭐⭐⭐ | 🟡 中 | 0.5 天 |

**關鍵發現**: Gemini 的「霓虹輝光」方案性價比最高：
- ✅ 視覺效果極強（光束質感）
- ✅ GPU 負載極低（無需高斯模糊）
- ✅ 實作簡單（雙層 `drawArc`）

#### ⭐ Phase 2A: 霓虹輝光效果（推薦實作）

**實作內容**（採用 Gemini 方案）：
```kotlin
// 雙層繪製法（Double-Layer Drawing）
// 1. 底層 Glow（6dp, Alpha 0.3）
drawArc(
    color = color,
    startAngle = 5f,
    sweepAngle = 80f,
    ...
    alpha = alpha * 0.3f,
    style = Stroke(width = 6.dp.toPx())  // 寬度 2.4 倍
)

// 2. 頂層 Core（2.5dp, Alpha 1.0）
drawArc(
    color = color,
    startAngle = 5f,
    sweepAngle = 80f,
    ...
    alpha = alpha,
    style = Stroke(width = strokeWidth)  // 原寬度
)
```

**效果**: 對焦框看起來像「懸浮光束」而非「貼紙」

**優勢**:
- ✅ 科技感極強（光束質感）
- ✅ GPU 負載極低（比高斯模糊便宜 95%）
- ✅ 實作簡單（僅增加 4 個 `drawArc` 調用）
- ✅ 暗色背景效果極佳

**時程**: 0.5 天
**風險**: 🟢 極低
**決策**: ⭐ **強烈推薦**

---

#### ✅ Phase 2B: 呼吸訊號動畫（推薦實作）

**實作內容**（結合 Gemini + Claude 方案）：
```kotlin
// 搜尋中狀態：Glow Alpha 呼吸（替代 Jitter）
val breathingIntensity by animateFloatAsState(
    targetValue = if (isFocusing && !isTracking && !isLocked) 1.0f else 0f,
    animationSpec = infiniteRepeatable(
        animation = tween(durationMillis = 800, easing = FastOutSlowInEasing),
        repeatMode = RepeatMode.Reverse
    ),
    label = "breathing"
)

// 應用至 Glow 層
val glowAlpha = alpha * (0.2f + 0.1f * breathingIntensity)  // 0.2 - 0.3 範圍呼吸
```

**效果**: 「AI 正在思考」的生命感，替代機械式抖動

**優勢**:
- ✅ 符合「AI 運算中」概念（Gemini 洞察）
- ✅ GPU 負載極低（僅 Alpha 插值）
- ✅ 避免 Jitter 的性能風險（Traycer 警告）
- ✅ 視覺效果柔和且專業（Claude 設計）

**時程**: 0.5 天
**風險**: 🟢 極低
**決策**: ✅ **推薦實作**
