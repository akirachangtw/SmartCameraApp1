## ✅ 推薦方案：混合智慧對焦策略

### 方案定位

**核心理念**：結合 Traycer 的 Eye-AF + Gemini 的 Smart Subject Focus

```
智慧對焦優先級（Priority Cascade）:
1. 👆 手動點擊 (Manual Tap)         → 最高優先級（永遠覆蓋 AI）
2. 👁️ 人臉眼睛追蹤 (Eye-AF)         → 高優先級（人像攝影專業規則）
3. 🎯 智慧主體鎖定 (Smart Subject)  → 中優先級（啟發式權重演算）
4. 📍 畫面中心 (Center Fallback)   → 最低優先級（保底機制）
```

---

### 實作架構

#### Phase 1: 眼睛地標偵測（Traycer 方案）

**目標**：人像攝影時，優先對焦眼睛而非人臉中心

**技術實作**：
1. 啟用 MLKit `LANDMARK_MODE_ALL`（已在 `CameraRepositoryImpl` 啟用）
2. 擴展 `DetectionResult` 加入 `eyePositions: List<EyePosition>`
3. 計算最近眼睛（基於 `headEulerAngleY`）：
   - 若 `headEulerAngleY > 10°`：右眼較近
   - 若 `headEulerAngleY < -10°`：左眼較近
   - 若 `-10° ≤ headEulerAngleY ≤ 10°`：選擇 Y 座標較低的眼睛

**修改檔案**：
- `MLKitDetector.kt`：提取眼睛地標
- `DetectionResult.kt`：新增 `EyePosition` 資料模型
- `CameraViewModel.kt`：優先使用眼睛座標對焦

**GPU 成本**：+5% FPS 影響（MLKit 地標計算開銷）

---

#### Phase 2: 智慧主體權重演算（Gemini 方案）

**目標**：無手動點擊時，自動識別畫面主體並對焦

**啟發式權重公式**：
```kotlin
fun calculateSaliencyScore(detection: Detection): Float {
    val boxSize = detection.boundingBox.width() * detection.boundingBox.height()
    val centerX = detection.boundingBox.exactCenterX()
    val centerY = detection.boundingBox.exactCenterY()

    // 中心性計算（距離畫面中心越近，分數越高）
    val centerDistance = sqrt(
        (centerX - viewWidth/2).pow(2) + (centerY - viewHeight/2).pow(2)
    )
    val maxDistance = sqrt((viewWidth/2).pow(2) + (viewHeight/2).pow(2))
    val centrality = 1 - (centerDistance / maxDistance)

    // 權重計算
    var score = (boxSize * 0.6f) + (centrality * 0.4f)

    // 人臉加權（+30 分）
    if (detection.type == DetectionType.FACE) {
        score += 30f
    }

    return score
}
```

**觸發條件**（每 500ms 評估一次）：
```kotlin
// 1. 先決條件
val canAutoFocus = !state.value.isLocked
    && !state.value.isFocusing
    && (System.currentTimeMillis() - lastManualTapTime > 5000)  // 手動點擊後 5 秒內不自動觸發

// 2. 計算最高分目標
val topTarget = detectionResult.detections
    .map { it to calculateSaliencyScore(it) }
    .maxByOrNull { it.second }

// 3. 觸發對焦
if (topTarget != null && topTarget.second > CONFIDENCE_THRESHOLD) {
    focusOnPoint(topTarget.first.boundingBox.exactCenterX(), ...)
}
```

**信心閾值**：
- `CONFIDENCE_THRESHOLD = 50f`（寧可不抓，也不要抓錯）
- 目標需佔畫面 > 1/3 或位於中心區域

**修改檔案**：
- `CameraViewModel.kt`：新增 `calculateSaliencyScore()` 和 `autoFocusOnSalientTarget()`
- 整合至 `observeDetectionResults` 流程

**GPU 成本**：~0%（重用現有 ML Kit 數據，僅增加輕量級計算）

#### ⭐ 狀態 6: Fade-out 優化（新增）

**問題**：Alpha 0.4 持續時，如果物體劇烈移動，對焦框應立即回歸 Alpha 1.0

**解決方案**：運動偵測觸發重新對焦

```kotlin
// 監測物體位置變化
val positionDelta = sqrt(
    (newX - oldX).pow(2) + (newY - oldY).pow(2)
)

// 劇烈移動閾值（30px）
if (isFading && positionDelta > 30.dp.toPx()) {
    // 立即重置為 Alpha 1.0
    _state.update {
        it.copy(
            focusIndicatorFading = false,
            isFocusing = true
        )
    }

    // 重新觸發對焦
    focusOnPoint(newX, newY, viewWidth, viewHeight)
}
```

**效果**：
- 物體靜止時：Alpha 0.4 低調存在
- 物體移動時：立即 Alpha 1.0 + 重新對焦
- 提升追蹤體驗

#### 實作原理

```kotlin
Canvas(modifier = modifier) {
    val halfSize = 48.dp.toPx() / 2

    // ========== Glow 層（底層）==========
    // 四邊形輪廓（寬度 2.4 倍，Alpha 0.3）
    drawRect(
        color = color,
        topLeft = Offset(x - halfSize, y - halfSize),
        size = Size(halfSize * 2, halfSize * 2),
        alpha = alpha * 0.3f,
        style = Stroke(width = strokeWidth * 2.4f)
    )

    // ========== Core 層（頂層）==========
    // 四邊形輪廓（原寬度，原 Alpha）
    drawRect(
        color = color,
        topLeft = Offset(x - halfSize, y - halfSize),
        size = Size(halfSize * 2, halfSize * 2),
        alpha = alpha,
        style = Stroke(width = strokeWidth)
    )

    // ========== 角落括號（條件顯示）==========
    if (showCornerBrackets) {
        drawCornerBrackets(
            x = x,
            y = y,
            size = halfSize * 2,
            bracketLength = 12.dp.toPx(),
            strokeWidth = strokeWidth,
            color = color,
            alpha = alpha
        )
    }
}
```

### 角落括號繪製（動態顯示）

```kotlin
fun DrawScope.drawCornerBrackets(
    x: Float,
    y: Float,
    size: Float,
    bracketLength: Float,
    strokeWidth: Float,
    color: Color,
    alpha: Float
) {
    val halfSize = size / 2

    // 左上角
    drawLine(
        color = color,
        start = Offset(x - halfSize, y - halfSize),
        end = Offset(x - halfSize + bracketLength, y - halfSize),
        strokeWidth = strokeWidth,
        alpha = alpha
    )
    drawLine(
        color = color,
        start = Offset(x - halfSize, y - halfSize),
        end = Offset(x - halfSize, y - halfSize + bracketLength),
        strokeWidth = strokeWidth,
        alpha = alpha
    )

    // 右上角
    drawLine(
        color = color,
        start = Offset(x + halfSize, y - halfSize),
        end = Offset(x + halfSize - bracketLength, y - halfSize),
        strokeWidth = strokeWidth,
        alpha = alpha
    )
    drawLine(
        color = color,
        start = Offset(x + halfSize, y - halfSize),
        end = Offset(x + halfSize, y - halfSize + bracketLength),
        strokeWidth = strokeWidth,
        alpha = alpha
    )

    // 左下角
    drawLine(
        color = color,
        start = Offset(x - halfSize, y + halfSize),
        end = Offset(x - halfSize + bracketLength, y + halfSize),
        strokeWidth = strokeWidth,
        alpha = alpha
    )
    drawLine(
        color = color,
        start = Offset(x - halfSize, y + halfSize),
        end = Offset(x - halfSize, y + halfSize - bracketLength),
        strokeWidth = strokeWidth,
        alpha = alpha
    )

    // 右下角
    drawLine(
        color = color,
        start = Offset(x + halfSize, y + halfSize),
        end = Offset(x + halfSize - bracketLength, y + halfSize),
        strokeWidth = strokeWidth,
        alpha = alpha
    )
    drawLine(
        color = color,
        start = Offset(x + halfSize, y + halfSize),
        end = Offset(x + halfSize, y + halfSize - bracketLen),
        strokeWidth = strokeWidth,
        alpha = alpha
    )
}
```
