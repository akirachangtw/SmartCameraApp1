# v2.9.9 Day 1-2 - Traycer v2 專業對焦系統實作計畫

## 目標

實作 v2.9.9 Day 1-2 完整的專業對焦系統（Traycer v2 Phase 1），實現：

### 核心功能
1. **連續物件追蹤**：點擊人臉/物件後，對焦圓圈隨目標移動
2. **AE/AF Lock**：長按鎖定曝光與對焦（專業相機必備）
3. **手動對焦模式（MF）**：焦距滑桿控制，精準對焦（預留 Phase 2）
4. **專業模式**：ISO、曝光補償手動控制（預留 Phase 3）

### 視覺設計（方案 B：白色 + 螢光藍點綴）
- **虛線3等分弧線設計**：每段 120° 弧線，間隔 120°，極簡專業
  - GPU 負擔分析：與完整圓圈相同（總弧長 360°），多 2 次 draw call（開銷 < 1%）
  - 視覺效果：極簡專業，符合現代相機 UI 趨勢
- **智能配色**：
  - 對焦中（處理狀態）：螢光藍 (#00E5FF) - 科技感
  - AE/AF Lock（鎖定狀態）：黃色 (#FFC107) - 專業標準
  - 追蹤/靜態：白色 (#FFFFFF) - 簡潔優雅
- **平滑動畫**：Spring 彈性過渡、PathEffect 虛線效果

### 步驟 2: 實作 AE/AF Lock 邏輯

**檔案**: [CameraViewModel.kt](app/src/main/java/com/akirachang/ai/photographer/presentation/camera/CameraViewModel.kt)

```kotlin
/**
 * Lock Auto Exposure and Auto Focus at specified point
 */
private fun lockAEAF(x: Float, y: Float, viewWidth: Int, viewHeight: Int) {
    viewModelScope.launch {
        try {
            // 若已鎖定，跳過
            if (_state.value.isAEAFLocked) {
                Log.d(TAG, "AE/AF already locked")
                return@launch
            }

            // 清除追蹤狀態（與鎖定互斥）
            _state.update {
                it.copy(
                    trackedObjectId = null,
                    trackedObjectType = null,
                    focusPoint = Pair(x, y),
                    isFocusing = true
                )
            }

            // 執行 AE/AF Lock（不設定自動取消時間）
            val result = cameraRepository.lockAEAF(x, y, viewWidth, viewHeight)

            if (result.isSuccess) {
                _state.update {
                    it.copy(
                        isAEAFLocked = true,
                        lockPoint = Pair(x, y),
                        isFocusing = false,
                        focusSuccess = true
                    )
                }
                Log.i(TAG, "AE/AF locked at ($x, $y)")
            } else {
                _state.update { it.copy(isFocusing = false, focusSuccess = false) }
                Log.w(TAG, "AE/AF lock failed: ${result.exceptionOrNull()?.message}")
            }

        } catch (e: Exception) {
            Log.e(TAG, "AE/AF lock error", e)
            _state.update { it.copy(isFocusing = false, focusSuccess = false) }
        }
    }
}

/**
 * Unlock AE/AF and restore auto mode
 */
private fun unlockAEAF() {
    viewModelScope.launch {
        try {
            cameraRepository.cancelFocusAndMetering()
            _state.update {
                it.copy(
                    isAEAFLocked = false,
                    lockPoint = null,
                    focusPoint = null,
                    focusSuccess = null
                )
            }
            Log.i(TAG, "AE/AF unlocked")
        } catch (e: Exception) {
            Log.e(TAG, "Failed to unlock AE/AF", e)
        }
    }
}
```

### 步驟 4: 實作 LiveCameraSource AE/AF Lock

**檔案**: [LiveCameraSource.kt](app/src/main/java/com/akirachang/ai/photographer/data/source/camera/LiveCameraSource.kt)

**新增方法**（在 `focusOnPoint()` 之後）：

```kotlin
override suspend fun lockAEAF(
    x: Float, y: Float, viewWidth: Int, viewHeight: Int
): Result<Unit> = suspendCancellableCoroutine { continuation ->
    try {
        if (!::camera.isInitialized) {
            continuation.resume(Result.failure(IllegalStateException("Camera not initialized")))
            return@suspendCancellableCoroutine
        }

        val cameraControl = camera.cameraControl
        val factory = androidx.camera.core.SurfaceOrientedMeteringPointFactory(
            viewWidth.toFloat(), viewHeight.toFloat()
        )
        val focusPoint = factory.createPoint(x, y)

        // AE/AF Lock: 同時鎖定對焦與曝光，無自動取消
        val action = androidx.camera.core.FocusMeteringAction.Builder(
            focusPoint,
            androidx.camera.core.FocusMeteringAction.FLAG_AF or
            androidx.camera.core.FocusMeteringAction.FLAG_AE
        ).build()  // 不設定 setAutoCancelDuration

        val future = cameraControl.startFocusAndMetering(action)

        future.addListener({
            try {
                val result = future.get()
                if (result.isFocusSuccessful) {
                    Log.d(TAG, "AE/AF locked at ($x, $y)")
                    Timber.d("LiveCameraSource: AE/AF locked at ($x, $y)")
                    continuation.resume(Result.success(Unit))
                } else {
                    Log.w(TAG, "AE/AF lock failed at ($x, $y)")
                    Timber.w("LiveCameraSource: AE/AF lock failed at ($x, $y)")
                    continuation.resume(Result.failure(Exception("AE/AF lock failed")))
                }
            } catch (e: Exception) {
                Log.e(TAG, "AE/AF lock error", e)
                Timber.e(e, "LiveCameraSource: AE/AF lock error")
                continuation.resume(Result.failure(e))
            }
        }, ContextCompat.getMainExecutor(context))

        continuation.invokeOnCancellation {
            Log.w(TAG, "AE/AF lock operation cancelled")
        }

    } catch (e: Exception) {
        Log.e(TAG, "Failed to lock AE/AF", e)
        Timber.e(e, "LiveCameraSource: Failed to lock AE/AF")
        continuation.resume(Result.failure(e))
    }
}

override suspend fun cancelFocusAndMetering(): Result<Unit> = withContext(Dispatchers.Main) {
    try {
        if (!::camera.isInitialized) {
            return@withContext Result.failure(IllegalStateException("Camera not initialized"))
        }

        camera.cameraControl.cancelFocusAndMetering()
        Log.d(TAG, "Focus and metering cancelled")
        Timber.d("LiveCameraSource: Focus and metering cancelled")
        Result.success(Unit)
    } catch (e: Exception) {
        Log.e(TAG, "Failed to cancel focus and metering", e)
        Timber.e(e, "LiveCameraSource: Failed to cancel focus and metering")
        Result.failure(e)
    }
}
```

### 步驟 5: 更新 FocusIndicator 視覺設計（虛線單圓圈）

**檔案**: [CameraScreen.kt](app/src/main/java/com/akirachang/ai/photographer/presentation/camera/CameraScreen.kt)

**完整替換 FocusIndicator** (Line 478-535)：

```kotlin
@Composable
private fun FocusIndicator(
    x: Float,
    y: Float,
    isFocusing: Boolean,
    focusSuccess: Boolean?,
    isTracking: Boolean,
    isLocked: Boolean,  // ✅ 新增參數
    modifier: Modifier = Modifier
) {
    // 追蹤模式：位置平滑過渡
    val animatedX by animateFloatAsState(
        targetValue = x,
        animationSpec = if (isTracking) {
            spring(
                dampingRatio = Spring.DampingRatioMediumBouncy,
                stiffness = Spring.StiffnessLow
            )
        } else {
            tween(durationMillis = 0)
        },
        label = "focus_x"
    )

    val animatedY by animateFloatAsState(
        targetValue = y,
        animationSpec = if (isTracking) {
            spring(
                dampingRatio = Spring.DampingRatioMediumBouncy,
                stiffness = Spring.StiffnessLow
            )
        } else {
            tween(durationMillis = 0)
        },
        label = "focus_y"
    )

    // 鎖定/追蹤模式：無 scale 動畫
    val scale by animateFloatAsState(
        targetValue = if (isLocked || isTracking) 1.0f else if (isFocusing) 1.2f else 1.0f,
        animationSpec = tween(durationMillis = 300),
        label = "focus_scale"
    )

    // 鎖定模式：固定 alpha 1.0
    val alpha by animateFloatAsState(
        targetValue = if (isLocked) 1.0f else if (isTracking) 1.0f else if (focusSuccess != null) 0.6f else 1.0f,
        animationSpec = tween(durationMillis = 500),
        label = "focus_alpha"
    )

    // ✅ 顏色邏輯（方案 B）
    val color = when {
        isLocked -> Color(0xFFFFC107)  // 黃色（AE/AF Lock）
        isFocusing -> Color(0xFF00E5FF)  // 螢光藍（對焦中）
        else -> Color.White  // 白色（追蹤/靜態）
    }

    // ✅ 虛線效果
    val pathEffect = PathEffect.dashPathEffect(
        intervals = floatArrayOf(10f, 5f),  // 10px 實線, 5px 間隔
        phase = 0f
    )

    Canvas(modifier = modifier) {
        val radius = 40.dp.toPx() * scale

        // ✅ 鎖定模式：虛線方框
        if (isLocked) {
            drawRect(
                color = color,
                topLeft = Offset(animatedX - radius * 1.2f, animatedY - radius * 1.2f),
                size = Size(radius * 2.4f, radius * 2.4f),
                alpha = alpha,
                style = Stroke(width = 2.dp.toPx(), pathEffect = pathEffect)
            )
        }

        // ✅ 虛線3等分弧線（所有模式統一）
        // 繪製 3 段 120° 弧線，間隔 120°
        for (i in 0..2) {
            val startAngle = i * 120f  // 0°, 120°, 240°
            drawArc(
                color = color,
                startAngle = startAngle,
                sweepAngle = 120f,  // 每段 120°
                useCenter = false,
                topLeft = Offset(animatedX - radius, animatedY - radius),
                size = Size(radius * 2, radius * 2),
                alpha = alpha,
                style = Stroke(width = 2.dp.toPx(), pathEffect = pathEffect)
            )
        }

        // 中心點
        drawCircle(
            color = color,
            radius = 3.dp.toPx(),
            center = Offset(animatedX, animatedY),
            alpha = alpha
        )
    }
}
```

## 風險與備案

### 技術風險
- **PathEffect 效能影響**：虛線繪製可能增加 GPU 負擔 → 使用簡化虛線間隔（10/5）
- **CameraX FocusMeteringAction 持久鎖定**：部分裝置可能不支援 → 提供降級方案（5 分鐘自動取消）
- **Camera2Interop 相容性**：手動對焦需硬體支援 → Phase 2 前檢查裝置能力

### 回滾方案
- FeatureFlags 關閉 `enableAEAFLock`：退回純追蹤模式
- FeatureFlags 關閉 `enableFocusTracking`：退回靜態對焦模式
