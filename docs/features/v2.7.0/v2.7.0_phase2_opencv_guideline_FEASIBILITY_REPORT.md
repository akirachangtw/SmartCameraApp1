### B. PreviewView 設定與 ScaleType ⚠️

#### 發現事項

#### 架構分析
1. **當前實作**: Bitmap → Compose `Image`
   - `contentScale = ContentScale.Crop` 會裁切 Bitmap 以填滿 View
   - 類似 PreviewView 的 `FILL_CENTER` 行為

2. **座標對齊挑戰**
   - Bitmap 尺寸: 640x480 (來自 ImageAnalysis)
   - View 尺寸: 動態(由螢幕決定)
   - **需自建映射**: `bufferRect → viewRect`

3. **✅ 已有 ML Kit 對齊參考**
   - [DetectionOverlay.kt:50-51](../../app/src/main/java/com/akirachang/ai/photographer/presentation/camera/components/overlay/DetectionOverlay.kt#L50-L51):
     > "With v1.4.0, coordinates from MlKitAnalyzer are already in VIEW space"
   - **證明**: MlKitAnalyzer 使用 `COORDINATE_SYSTEM_VIEW_REFERENCED` 成功實現對齊

#### 建議方案
**Step 1**: 建立 `FrameToViewTransform` Utility
```kotlin
data class FrameToViewTransform(
    val imageWidth: Int,
    val imageHeight: Int,
    val viewWidth: Int,
    val viewHeight: Int,
    val contentScale: ContentScale,  // Crop or Fit
    val rotationDegrees: Int,
    val isFrontCamera: Boolean

    fun mapPoint(bufferX: Float, bufferY: Float): Pair<Float, Float>
    fun mapRect(bufferRect: Rect): Rect
}
```

**Step 2**: 複用 ML Kit MlKitAnalyzer 的對齊策略
- 參考 `MlKitAnalyzer` 如何處理 `COORDINATE_SYSTEM_VIEW_REFERENCED`
- 套用相同的 transform matrix 計算

class GuidelineAnalyzer {
    private val matPool = ArrayDeque<Mat>(3)

    private fun acquireMat(width: Int, height: Int): Mat {
        return matPool.removeFirstOrNull()?.apply {
            if (cols() != width || rows() != height) {
                release()
                return Mat(height, width, CvType.CV_8UC1)
            }
        } ?: Mat(height, width, CvType.CV_8UC1)
    }

    private fun releaseMat(mat: Mat) {
        if (matPool.size < 3) {
            matPool.addLast(mat)
        } else {
            mat.release()
        }
    }
}
