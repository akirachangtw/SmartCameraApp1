# v2.9.6 Phase 2.5 - ML Kit 16KB Native Alignment Upgrade (Optional)

**Status**: Optional Enhancement (Phase 2.4 is sufficient for Google Play)
**Priority**: Low (can defer to 2026 Q2-Q3)
**Prerequisite**: Phase 2.4 physical device tests must pass first

---

## Executive Summary

This is an **optional enhancement** to Phase 2.4. While `pageSizeCompat="enabled"` successfully eliminates the warning and ensures Google Play compliance, upgrading ML Kit to 16KB-aligned versions would provide **native 16KB support** without backward compatibility mode.

**Current Status**:
- OpenCV: ✅ 16KB aligned (NDK 27)
- ML Kit: ❌ 4KB aligned (older versions)

**Upgrade Goal**:
- ML Kit: ✅ 16KB aligned (newer versions)

---

## Analysis from 16KB Compatibility Report

### Current Versions (Phase 2.4)

From `gradle/libs.versions.toml`:
```toml
mlkitObjectDetection = "17.0.1"
mlkitFaceDetection = "16.1.5"
```

### Recommended Versions (from Report)

```toml
mlkitObjectDetection = "17.0.3"  # +0.0.2
mlkitFaceDetection = "16.1.7"    # +0.0.2
```

### Expected Impact

**If Upgrade Succeeds**:
- ✅ All native libraries 16KB aligned
- ✅ Can remove `android:pageSizeCompat` attribute
- ✅ App runs in **normal mode** (not compatibility mode)
- ✅ Theoretical performance improvement (minimal, likely unnoticeable)

**If Upgrade Fails/Breaks**:
- ❌ Potential ML Kit API breaking changes
- ❌ Need to test face detection accuracy
- ❌ Rollback to Phase 2.4 required

## Implementation Plan (IF Pursuing This)

### Phase 2.5A: ML Kit Version Upgrade

#### Step 1: Update Dependencies

**File**: `gradle/libs.versions.toml`

**Change**:
```diff
[versions]
-mlkitObjectDetection = "17.0.1"
-mlkitFaceDetection = "16.1.5"
+mlkitObjectDetection = "17.0.3"
+mlkitFaceDetection = "16.1.7"
```

#### Step 2: Sync and Build

```bash
./gradlew clean
./gradlew assembleDeviceDebug
```

**Expected**: Build succeeds with no compilation errors

#### Step 3: Verify 16KB Alignment

**Using Android Studio**:
1. Build → Analyze APK...
2. Select `app-device-debug.apk`
3. Navigate to `lib/arm64-v8a/`
4. Check alignment for:
   - ✅ `libmlkitcommonpipeline.so` → Should show **16 KB**
   - ✅ `libface_detector_v2_jni.so` → Should show **16 KB**
   - ✅ `libopencv_java4.so` → Already **16 KB**

**Using Command Line** (Alternative):
```bash
# Extract APK
unzip app-device-debug.apk -d tmp/apk_extracted

# Check alignment with zipinfo
zipinfo -l tmp/apk_extracted/lib/arm64-v8a/libface_detector_v2_jni.so | grep "extra:"
# Look for "alignment:16384" or "offset" divisible by 16384
```

#### Step 4: Test on Emulators

**Same tests as Phase 2.4**:
- MPhone A11
- Pixel9a-virtual
- **Pixel9a-16KB** (critical)

**Expected**:
- No PageSizeMismatchDialog (same as Phase 2.4)
- All functionality works
