## 根本原因分析

### PreviewView.meteringPointFactory 的誤解

**假設（錯誤）**：
```kotlin
// 我們以為 meteringPointFactory 會自動過濾 letterbox
val factory = previewView.meteringPointFactory
val point = factory.createPoint(x, y)  // 自動處理？
```

**實際行為**：
- meteringPointFactory 只負責**座標轉換**（View 座標 → Camera 座標）
- **不會自動過濾** letterbox 區域的點擊
- 需要**手動檢查** 點是否在 contentBounds 內

### ContentBounds 獲取的時序問題

**問題流程**：
1. `setPreviewView(previewView)` 被調用
2. 嘗試獲取 PreviewView.SurfaceView → **找不到（尚未創建）**
3. CameraX `bindToLifecycle()` 執行
4. Preview UseCase 連接 SurfaceProvider
5. PreviewView 創建 SurfaceView → **現在才存在**

**解決方向**：
- 需要在 **步驟 5 之後** 才能獲取 SurfaceView 的位置和大小
- 使用 ViewTreeObserver 或其他延遲機制
