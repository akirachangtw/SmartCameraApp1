# v2.10.0 Settings UI Modernization Proposal (設定介面現代化提案)

本提案針對 SmartCameraApp1 的設定介面進行現代化改造，目標是提升科技感、減少視覺干擾，並優化操作體驗。

## 1. 核心概念：Glassmorphism Control Center (毛玻璃控制中心)

### 現狀痛點
*   目前點擊設定按鈕會跳轉至全新的 `SettingsScreen` 頁面，導致使用者脫離拍攝情境 (Context Switch)。
*   設定項目以條列式呈現，隨著功能增加 (如 GPS, Timer, Ratio)，列表會過長，操作效率低。
*   視覺風格較為傳統 (Material Design List)，缺乏 "AI 相機" 的科技感。

### 建議方案：懸浮控制面板 (Overlay Control Panel)
將全螢幕設定頁面改為 **半透明懸浮面板 (Bottom Sheet 或 Top Drawer)**。

#### A. 互動設計 (Interaction)
*   **觸發**: 點擊頂部設定 (齒輪) 圖示。
*   **動效**: 面板從螢幕頂部向下滑出 (Top Drawer) 或從底部向上滑出 (Bottom Sheet)，帶有彈性動畫 (Spring Animation)。
*   **背景**: 使用 `BlurEffect` (毛玻璃) 背景，讓使用者依稀可見相機預覽畫面，保持拍攝臨場感。
*   **關閉**: 點擊面板外部空白區域或下滑/上滑手勢關閉。

#### B. 視覺風格 (Visual Style)
*   **色調**: 深色半透明背景 (Dark Translucent) + 霓虹強調色 (Neon Accent，如青色 Cyan 或 橙色 Orange) 表示啟用狀態。
*   **排版**:
    *   **第一層 (Quick Toggles)**: 使用圓形圖示按鈕列 (Icon Row)，快速切換常用功能 (如 網格線、水平儀、HDR)。
    *   **第二層 (Parameters)**: 使用滑桿 (Slider) 或 分段控制 (Segmented Control) 調整數值 (如 長寬比、倒數計時)。
    *   **第三層 (Advanced)**: "更多設定" 按鈕，進入詳細列表 (針對較少更動的選項，如 隱私權限、關於我們)。

#### C. 版面配置範例 (Layout Example)

```
[ ------ Settings ------ ]  <-- Top Drawer
|                        |
|  [ 4:3 ] [ 16:9 ] [ 1:1 ]  <-- 長寬比 (Segmented Button)
|                        |
|  (O) Timer: [ OFF | 3s | 10s ]
|                        |
|  Grid:   [ON]  Level: [OFF]  <-- 圓形 Toggle Buttons
|  Focus:  [ON]  GPS:   [ON]
|                        |
|  [  More Settings >  ]     <-- 進入深層設定
|________________________|
```

## 2. 具體功能整合

### I. 隱藏式選單 (Hidden/Expandable Menu)
*   **實作**: 使用 `AnimatedVisibility` (Compose) 控制面板顯示。
*   **優點**: 不佔用預覽畫面空間，僅在需要時出現。

### II. 項目分類優化
將散落的設定歸類，提升查找效率：
1.  **構圖輔助 (Composition)**: 網格線 (Grid)、水平儀 (Level)、構圖指引 (Guide)。
2.  **拍攝參數 (Shooting)**: 長寬比 (Ratio)、倒數計時 (Timer)、HDR 模式。
3.  **智慧功能 (AI Intelligence)**: 物件偵測框 (Detection)、自動光線分析 (Auto Light)。
4.  **系統 (System)**: GPS 標記、快門聲。

## 3. 風險評估 (Risk Assessment)

| 風險項目 | 可能性 | 影響程度 | 緩解措施 |
| :--- | :--- | :--- | :--- |
| **效能影響 (Performance)** | 中 | 低 | 毛玻璃 (Blur) 效果在低階裝置可能掉幀。**對策**: 檢測裝置效能，低階裝置改用純色半透明黑色背景 (Fallback)。 |
| **操作複雜度** | 低 | 中 | 若面板過高遮擋預覽，可能干擾構圖。**對策**: 控制面板高度不超過螢幕 40%，或支援半透明點擊穿透 (如果技術可行)。 |
| **可發現性 (Discoverability)** | 低 | 低 | 使用者習慣齒輪圖示代表設定，改為 Overlay 面板符合現代 App (如 Google Camera, iOS Camera) 操作邏輯，學習成本低。 |

## 4. 執行建議 (Recommendation)

建議優先實作 **"Top Drawer Overlay" (頂部下滑面板)**：
1.  保留頂部工具列的 "閃光燈" 與 "設定" 按鈕。
2.  移除原本的 "長寬比" 獨立按鈕，將其整合進設定面板的第一列。
3.  點擊 "設定" 後，面板滑出，提供長寬比、Timer、Grid 等快速開關。
4.  面板底部提供 "進階設定" 連結，保留原本的 `SettingsScreen` 作為詳細設定頁 (Deep Settings)。

這樣既能滿足 **"更簡潔"** 的需求，又保留了 **"功能擴充性"**。
