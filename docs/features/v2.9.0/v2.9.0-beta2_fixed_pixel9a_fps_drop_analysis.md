# v2.9.0-beta3 Resolution Fix Implementation Plan

## Executive Summary

**Goal**: Fix CameraX resolution selection to avoid 1080x1080 fallback on Pixel 9a, reducing Graphics memory from 216 MB to ~100-120 MB while maintaining FPS performance.

**Root Cause**: CameraX's `setTargetResolution(480, 360)` falls back to 1080x1080 because 480x360 is not in Pixel 9a's supported resolution list.

**Solution**: Query supported resolutions and intelligently select the smallest resolution ≥ 480x360 (target: 640x480 or 720p).

---

## Background Context

### Problem Validation (from 4 L2 Analysis Documents)

1. **FPS Drop is NOT a Bug** ✅
   - v2.8.5/v2.8.6/v2.9.0-beta2 all show identical thermal throttling pattern
   - Confirmed as Pixel 9a Tensor G4 hardware characteristic
   - Pattern: Normal (22-28 FPS) → Drop at 4-6 min (11-20 FPS) → Partial recovery
   - **Action**: Accept as known behavior, no code fix needed

2. **Graphics Memory is the Real Issue** 🎯
   - v2.9.0-beta2: 216.1 MB (vs v2.8.6: 64 MB) = **+238%**
   - Cause: Actual resolution 1080x1080 (6.75x pixels vs target 480x360)
   - Impact: Each Bitmap ~4.4 MB (vs 0.66 MB for 480x360)
   - **Action**: Fix resolution selection

3. **v2.9.0-beta2 vs beta1 Key Difference**
   - beta1: FPS 8-10 (RenderScript broken, CPU fallback 89ms)
   - beta2: FPS 20-23 (RenderScript working, GPU 3-5ms)
   - **Conclusion**: RenderScript critical for performance

### Phase 2: Implement Smart Resolution Selection (Step 2 from L2)

**Goal**: Select optimal resolution from supported list

**Strategy** (Priority Order):
1. **Ideal**: 640x480 (4:3 aspect, ~300K pixels, close to 480x360)
2. **Acceptable**: 720p variants (e.g., 960x720, 1280x720)
3. **Avoid**: 1080p or higher (>1M pixels)

**Algorithm**:
```kotlin
private fun selectOptimalResolution(
    supportedSizes: List<Size>,
    targetSize: Size = Size(480, 360)
): Size {
    // 1. Filter: width >= 480 AND height >= 360
    // 2. Sort by: pixel count (ascending)
    // 3. Return: first match (smallest valid size)
    // 4. Fallback: if none found, return target (let CameraX handle)
}
```

**File**: `LiveCameraSource.kt:525-529`

**Modified Code**:
