# v2.9.6 Phase 2.1 - 快速測試指令參考

## 🚀 快速開始

### 1. 確認裝置連接
```bash
adb devices
adb shell getprop ro.product.model
adb shell getprop ro.build.version.release
```

### 2. 安裝 APK
```bash
adb install -r app/build/outputs/apk/device/debug/app-device-debug.apk
```

### 3. 啟動 Logcat 監控
```bash
adb logcat -c
adb logcat > tmp/pixel9a_test_logcat.txt
```
（在另一個終端執行，保持運行）

## 📋 測試 1: Android 15 相容性

### 啟動應用並收集 logcat
```bash
# 清除 logcat
adb logcat -c

# 啟動應用
adb shell am start -n com.akirachang.ai.photographer/.MainActivity

# 等待 5 秒
sleep 5

# 擷取 logcat
adb logcat -d > tmp/pixel9a_android15_startup.txt
```

### 檢查 16 KB 警告
```bash
grep -iE "16.*kb|page.*align|unaligned.*page|native.*lib.*warn" tmp/pixel9a_android15_startup.txt
```

**預期**: 無輸出（0 個警告）

### 檢查函式庫載入
```bash
grep -E "libopencv|libface_detector|libmlkit" tmp/pixel9a_android15_startup.txt | grep "ok"
```

**預期**: 看到 "ok" 表示成功載入
