## 測試案例 1: Android 15 相容性驗證

### 目標
確認 Phase 2.1 的 NDK 27 升級和現代化 JNI 封裝成功解決 Android 15 的 16 KB 頁面對齊警告。

### 測試步驟

#### 步驟 1.1: 清除環境並啟動應用
```bash
# 清除 logcat
adb logcat -c

# 啟動應用
adb shell am start -n com.akirachang.ai.photographer/.MainActivity
```

#### 步驟 1.2: 收集啟動 logcat
```bash
# 等待應用完全啟動（約 5 秒）
sleep 5

# 擷取 logcat
adb logcat -d > tmp/pixel9a_android15_startup_logcat.txt
```

#### 步驟 1.3: 檢查 16 KB 對齊警告
```bash
# 搜尋 16 KB 對齊相關警告
grep -iE "16.*kb|page.*align|unaligned.*page|native.*lib.*warn" tmp/pixel9a_android15_startup_logcat.txt
```

### 預期結果
- ✅ **無任何 16 KB 對齊警告**
- ✅ 以下函式庫成功載入：
  - `libopencv_java4.so`
  - `libface_detector_v2_jni.so`
  - `libmlkitcommonpipeline.so`
  - `libc++_shared.so`
  - `libsurface_util_jni.so`
  - `libimage_processing_util_jni.so`
  - `libdatastore_shared_counter.so`
  - `libandroidx.graphics.path.so`
- ✅ 應用正常啟動，無崩潰或錯誤

## 測試案例 2: Phase 2 旋轉修復驗證

### 目標
驗證 Phase 2 的固定旋轉方案在所有裝置方向下都能正確顯示預覽，無雙重旋轉問題。

### 測試步驟

#### 步驟 2.1: 後置鏡頭測試

**2.1.1 Portrait (手機直立)**
1. 確保手機直立（Home 鍵在下方）
2. 開啟後置鏡頭
3. 觀察預覽方向
4. 截圖保存：
   ```bash
   adb shell screencap -p > /sdcard/Download/test_back_portrait.png
   adb pull /sdcard/Download/test_back_portrait.png tmp/
   adb shell rm /sdcard/Download/test_back_portrait.png
   ```

**預期結果**: ✅ 預覽方向正確，物體顯示正立

**2.1.2 Landscape Right (向右橫放)**
1. 手機向右旋轉 90°（Home 鍵在右側）
2. 觀察預覽方向
3. 截圖保存：
   ```bash
   adb shell screencap -p > /sdcard/Download/test_back_landscape_right.png
   adb pull /sdcard/Download/test_back_landscape_right.png tmp/
   adb shell rm /sdcard/Download/test_back_landscape_right.png
   ```

**預期結果**: ✅ 預覽方向正確，**不會向左轉 90°**（Phase 2 前的 bug）

**2.1.3 Landscape Left (向左橫放)**
1. 手機向左旋轉 90°（Home 鍵在左側）
2. 觀察預覽方向
3. 截圖保存：
   ```bash
   adb shell screencap -p > /sdcard/Download/test_back_landscape_left.png
   adb pull /sdcard/Download/test_back_landscape_left.png tmp/
   adb shell rm /sdcard/Download/test_back_landscape_left.png
   ```

**預期結果**: ✅ 預覽方向正確，**不會向右轉 90°**（Phase 2 前的 bug）

#### 步驟 2.2: 前置鏡頭測試

**2.2.1 Portrait (手機直立)**
1. 切換至前置鏡頭
2. 手機直立

**2.2.2 Landscape Right (向右橫放)**

2. 觀察預覽方向
3. 截圖保存（同上方指令，檔名改為 `test_front_landscape_right.png`）

**預期結果**: ✅ 預覽方向正確，**不會向左轉 180°**（Phase 2.0 前的 bug）

**2.2.3 Landscape Left (向左橫放)**
