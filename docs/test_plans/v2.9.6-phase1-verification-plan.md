## 1. 驗證目標
本計畫旨在驗證 v2.9.6 Phase 1 針對以下兩個關鍵問題的修復成效：
1.  **EXIF Orientation 遺失**：確認照片存檔後，是否包含正確的旋轉資訊（EXIF Tag 0x0112）。
2.  **預覽畫面雙重旋轉**：確認在橫向（Landscape）模式下，相機預覽畫面是否正確顯示（無過度旋轉或變形）。

## 2. 測試環境需求
*   **硬體裝置**:
    *   **主要**: Google Pixel 9a (Android 16) - *重現原問題的目標裝置*
    *   **次要**: 任意 Android 10+ 實體裝置 (Samsung, Pixel 舊款等) - *確認相容性*
    *   **模擬器**: Android Studio Emulator (API 34+) - *確認基本功能不崩潰*
*   **軟體版本**: SmartCameraApp1 v2.9.6-phase1 (Debug/Release build)
*   **輔助工具**:
    *   **Google Photos**: 檢視照片方向。
    *   **ExifTool** (PC/Mac) 或 **Exif Viewer** (Android App): 檢查 EXIF Metadata。
    *   **Logcat**: 觀察 `CameraRepositoryImpl` 與 `LiveCameraSource` 的除錯日誌。

## 4. 驗證執行指引

### 步驟 1: 驗證 EXIF (Phase 1)
1. 執行 `gradlew assembleDebug` 安裝 v2.9.6-phase1。
2. 執行 **TC-EM-001** ~ **TC-EM-003**。
3. 將照片導出至電腦，使用命令列檢查：
   ```bash
   exiftool photo.jpg | grep Orientation
   ```
   或使用線上檢視器。
4. **通過標準**：全部方向的 EXIF Tag 正確，且照片顯示無誤。

### 步驟 2: 診斷預覽 (Phase 2 前置)
1. 連接手機至 Logcat，過濾 Tag: `LiveCameraSource`。
2. 執行 **TC-PR-002**，觀察 Log 中的 `rotationDegrees` 與 `currentRotation` 數值。
3. 若發現預覽錯誤（預覽畫面躺下），記錄 Log 並回報，作為 Phase 2 參數調整依據。
4. **Phase 2 執行後**：再次執行 TC-PR 系列，確認修復。
