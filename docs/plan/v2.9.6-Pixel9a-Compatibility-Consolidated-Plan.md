## Issue 1: 16KB Page Alignment Warning

### Problem Statement

**Symptom**: Android 16 displays `PageSizeMismatchDialog` on app startup with the message:
> "This app uses native libraries that are not aligned to 16KB page boundaries."

**Affected Libraries**:
- `libopencv_java4.so` (OpenCV 4.13.0)
- `libface_detector_v2_jni.so` (ML Kit)
- `libmlkitcommonpipeline.so` (ML Kit)
- `libc++_shared.so`
- `libsurface_util_jni.so`
- `libimage_processing_util_jni.so`
- `libdatastore_shared_counter.so`
- `libandroidx.graphics.path.so`

**Impact**:
- ❌ **User Experience**: User must manually dismiss dialog on every app launch
- ✅ **Functionality**: No impact - app works normally after dismissing dialog
- ⚠️ **Priority**: Medium (UX issue, not functional blocker)

---

### Root Cause Analysis

#### Why Phase 2.1 Failed (Emulator vs Physical Device)

**Phase 2.1 Configuration**:
```kotlin
// app/build.gradle.kts
ndkVersion = "27.0.12077973"
jniLibs {
    useLegacyPackaging = false  // Modern packaging
}
```

**Why it worked on emulator**:
- ✅ Emulators (x86_64) don't enforce 16KB alignment
- ✅ All 3 emulator tests showed 0 warnings

**Why it failed on Pixel 9a**:
- ❌ Physical ARM64 devices with Android 16 enforce 16KB alignment
- ❌ Third-party libraries (OpenCV, ML Kit) compiled with NDK < 27 (only 4KB aligned)
- ❌ Modern packaging (`useLegacyPackaging=false`) requires direct mmap → needs 16KB alignment

#### Why Phase 2.2 Failed (App-Level Config Insufficient)

**Phase 2.2 Configuration**:
```kotlin
// app/build.gradle.kts
jniLibs {
    useLegacyPackaging = true  // Legacy packaging
}
```

```xml
<!-- AndroidManifest.xml -->
<application
    android:extractNativeLibs="true">
```

**Verification Results**:
```bash
# ✅ extractNativeLibs="true" was correctly set
adb shell run-as com.akirachang.ai.photographer cat AndroidManifest.xml
# Found: android:extractNativeLibs="true"

# ✅ Libraries were extracted to filesystem
adb shell run-as com.akirachang.ai.photographer ls -la lib/arm64/
# Found: libopencv_java4.so, libface_detector_v2_jni.so, etc.
```

**But PageSizeMismatchDialog still appeared!**

**Root Cause Discovered**:
- ❌ **OpenCV is a library module** with its own native libraries
- ❌ **AGP 8.10.1 behavior**: App-level `useLegacyPackaging=true` does **NOT propagate** to library modules
- ❌ **opencv/build.gradle** (Lines 138-151) has **NO packaging configuration**
- ❌ OpenCV libs default to modern packaging → requires 16KB alignment

---

### Phase 2.3 Solution: OpenCV Module Packaging Fix

#### Implementation

**File**: `opencv/build.gradle`
**Lines**: 138-151

**Add packaging configuration to BOTH buildTypes**:

```groovy
buildTypes {
    debug {
        // v2.9.6 Phase 2.3: Force legacy packaging for 4KB-aligned OpenCV libs
        packagingOptions {
            jniLibs {
                useLegacyPackaging = true
            }
            doNotStrip '**/*.so'  // Keep symbols for debugging
        }
    }
    release {
        // v2.9.6 Phase 2.3: Force legacy packaging for 4KB-aligned OpenCV libs
        packagingOptions {
            jniLibs {
                useLegacyPackaging = true
            }
            doNotStrip '**/*.so'  // Keep symbols for crash reports
        }
        minifyEnabled false
        proguardFiles getDefaultProguardFile('proguard-android.txt'), 'proguard-rules.txt'
    }
}
```

**File**: `app/build.gradle.kts`
**Lines**: 20-21

```kotlin
versionCode = 55
versionName = "2.9.6-phase2.3"
```

---

#### Why Phase 2.3 Will Succeed

**Packaging Decision Matrix**:

| Module | Phase 2.1 | Phase 2.2 | Phase 2.3 |
|--------|-----------|-----------|-----------|
| **App Module** | useLegacyPackaging=false | useLegacyPackaging=true | useLegacyPackaging=true |
| **OpenCV Module** | No config (default=false) | No config (default=false) | **useLegacyPackaging=true** |
| **Result** | ❌ Dialog on physical device | ❌ Dialog (OpenCV not configured) | ✅ **Should work** |

**Key Difference**:
- Phase 2.3 explicitly configures OpenCV module to use legacy packaging
- OpenCV libs will be extracted to filesystem → no 16KB alignment requirement

```kotlin
private fun writeExifOrientation(uri: Uri, rotation: Int) {
    val exifOrientation = when (rotation) {
        Surface.ROTATION_0 -> ExifInterface.ORIENTATION_NORMAL      // 1
        Surface.ROTATION_90 -> ExifInterface.ORIENTATION_ROTATE_90  // 6
        Surface.ROTATION_180 -> ExifInterface.ORIENTATION_ROTATE_180 // 3
        Surface.ROTATION_270 -> ExifInterface.ORIENTATION_ROTATE_270 // 8
        else -> ExifInterface.ORIENTATION_NORMAL
    }

    context.contentResolver.openFileDescriptor(uri, "rw")?.use { pfd ->
        val exif = ExifInterface(pfd.fileDescriptor)
        exif.setAttribute(ExifInterface.TAG_ORIENTATION, exifOrientation.toString())
        exif.saveAttributes()
    }
}
```

private fun writeEnhancedExif(uri: Uri, rotation: Int, imageProxy: ImageProxy) {
    context.contentResolver.openFileDescriptor(uri, "rw")?.use { pfd ->
        val exif = ExifInterface(pfd.fileDescriptor)

**Phase 3.2: Camera Parameters** (Medium Risk, Medium Value)
- Add exposure, ISO, focal length if available
- Requires CaptureResult access from ImageCapture callback
- Gracefully handle null values

**Implementation**:
```kotlin
// Modify ImageCapture.OnImageCapturedCallback
override fun onCaptureSuccess(imageProxy: ImageProxy) {
    val captureResult = imageProxy.imageInfo.captureResult  // May be null

    // Extract camera parameters
    val exposureTime = captureResult?.get(CaptureResult.SENSOR_EXPOSURE_TIME)
    val iso = captureResult?.get(CaptureResult.SENSOR_SENSITIVITY)
    val focalLength = cameraCharacteristics.get(CameraCharacteristics.LENS_INFO_AVAILABLE_FOCAL_LENGTHS)?.firstOrNull()

    // Pass to EXIF writer
    writeEnhancedExif(uri, rotation, imageProxy, exposureTime, iso, focalLength)
}

private fun writeEnhancedExif(
    uri: Uri,
    rotation: Int,
    imageProxy: ImageProxy,
    exposureTime: Long?,
    iso: Int?,
    focalLength: Float?
) {
    context.contentResolver.openFileDescriptor(uri, "rw")?.use { pfd ->
        val exif = ExifInterface(pfd.fileDescriptor)

        // Phase 3.1 metadata (as above)
        // ...

        // Phase 3.2: Camera parameters (if available)
        exposureTime?.let {
            val exposureFraction = "1/${(1_000_000_000L / it).toInt()}"
            exif.setAttribute(ExifInterface.TAG_EXPOSURE_TIME, exposureFraction)
        }

        iso?.let {
            exif.setAttribute(ExifInterface.TAG_ISO_SPEED_RATINGS, it.toString())
        }

        focalLength?.let {
            exif.setAttribute(ExifInterface.TAG_FOCAL_LENGTH, "${it}mm")
        }

        exif.saveAttributes()
        Log.i(TAG, "Enhanced EXIF written: camera parameters")
    }
}
```

**Effort**: 4-6 hours
**Risk**: Medium (CaptureResult may be null, device-dependent)
**Testing**: Test on multiple devices, handle null gracefully

**Phase 3.3: GPS Location** (Requires New Permission)
- Add GPS coordinates if user grants permission
- Must request ACCESS_FINE_LOCATION permission
- Requires LocationManager integration

**Permission Addition** (AndroidManifest.xml):
```xml
<uses-permission android:name="android.permission.ACCESS_FINE_LOCATION" />
<uses-permission android:name="android.permission.ACCESS_COARSE_LOCATION" />
```

**UI Flow**:
1. Add "Save GPS location" toggle in Settings screen
2. Request permission when user enables GPS tagging
3. Retrieve location before each capture (with timeout)
4. Write GPS EXIF tags if location available

**Implementation**:
```kotlin
private suspend fun getLocationForPhoto(): Location? = withContext(Dispatchers.IO) {
    if (ContextCompat.checkSelfPermission(context, Manifest.permission.ACCESS_FINE_LOCATION)
        != PackageManager.PERMISSION_GRANTED) {
        Log.w(TAG, "GPS permission not granted")
        return@withContext null
    }

    val locationManager = context.getSystemService(Context.LOCATION_SERVICE) as LocationManager

    try {
        // Get last known location (fast)
        val location = locationManager.getLastKnownLocation(LocationManager.GPS_PROVIDER)
            ?: locationManager.getLastKnownLocation(LocationManager.NETWORK_PROVIDER)

        if (location != null && System.currentTimeMillis() - location.time < 5 * 60 * 1000) {
            // Location is recent (< 5 minutes old)
            return@withContext location
        }

        // Location too old or null - skip GPS tagging this time
        Log.w(TAG, "GPS location unavailable or stale")
        return@withContext null
    } catch (e: Exception) {
        Log.e(TAG, "Failed to get GPS location", e)
        return@withContext null
    }
}

private fun writeEnhancedExif(
    uri: Uri,
    rotation: Int,
    imageProxy: ImageProxy,
    location: Location?  // New parameter
) {
    context.contentResolver.openFileDescriptor(uri, "rw")?.use { pfd ->
        val exif = ExifInterface(pfd.fileDescriptor)

        // Phase 3.1 & 3.2 metadata
        // ...

        // Phase 3.3: GPS location (if available)
        location?.let {
            exif.setGpsInfo(it)  // ExifInterface helper method
            Log.i(TAG, "GPS EXIF written: lat=${it.latitude}, lon=${it.longitude}")
        }

        exif.saveAttributes()
    }
}
```
