
# v2.9.6 Phase 2.6: ZIP 對齊修復計畫 (ZIP Alignment Plan)

## 1. 執行摘要 (Executive Summary)

根據 `handofflog_20260127_223000.md` 的分析，雖然 Phase 2.5 成功升級了 CameraX 並解決了部分 ELF 對齊問題，但實體 Pixel 9a 上的 `PageSizeMismatchDialog` 警告依然存在。

**根本原因 (Root Cause)**：
Android 16 執行兩層對齊檢查：
1.  **ELF LOAD Segments** (二進位層級)：Phase 2.5 已修復 6/8。
2.  **ZIP Entry Offsets** (APK 封裝層級)：**目前 0/8 對齊**。所有 `.so` 檔在 APK 內的起始偏移量都不是 16384 的倍數。這是導致警告持續的主因。

**解決方案**:
實作 **Phase 2.6**，使用 `zipalign -p -f -z 16` 強制對 APK 進行 16KB 分頁對齊。此方案經評估為最有效且合規的路徑，優於先前失敗的 `useLegacyPackaging` 嘗試。

---

## 2. 技術分析 (Technical Analysis)

### 2.1 雙層對齊模型
| 層級 | 檢查目標 | 當前狀態 | 修正方法 |
| :--- | :--- | :--- | :--- |
| **Layer 1** | **ZIP Entry Offset** | ❌ 0/8 Fails | **`zipalign -z 16`** (本階段) |
| **Layer 2** | **ELF LOAD Segment** | ⚠️ 6/8 Pass | CameraX 升級 (Phase 2.5) / ML Kit 待升級 |

**關鍵發現**：即便 ELF 內部未對齊 (如 ML Kit)，只要 Layer 1 (ZIP Offset) 正確對齊，Android 封裝管理器通常能以相容模式處理，或至少對於已對齊的 ELF (CameraX) 能正確 `mmap`。目前警告是因為**所有**函式庫的 ZIP 偏移量都錯誤，導致系統無法使用任何優化載入路徑。

### 2.2 為何 useLegacyPackaging 失敗？
根據 Log 紀錄，`useLegacyPackaging = true` 在 Phase 2.2/2.3 測試失敗。這可能是因為：
1.  **AGP 傳播問題**：屬性未正確套用到所有傳遞依賴 (Transitive Dependencies)。
2.  **Android 16 安裝檢查**：新版 OS 可能在安裝階段仍會檢查 APK 結構，即使宣告了 `extractNativeLibs="true"`。

相比之下，**ZIP 對齊 (zipalign)** 是即改即效的後處理步驟，不依賴 Gradle 複雜的屬性傳遞機制。

## 3. 實作計畫 (Implementation Plan)

### 步驟 1: 更新 APK 建置流程
我們將採用手動/腳本化後處理方式驗證修復效果。

- **Action**: 使用 `zipalign` 工具處理 Debug 版 APK。
- **Command**:
  ```bash
  zipalign -p -f -z 16 \
    app/build/outputs/apk/device/debug/app-device-debug.apk \
    app/build/outputs/apk/device/debug/app-device-debug-aligned.apk
  ```

### 步驟 2: 驗證 ZIP 偏移量
- **Action**: 使用 `zipinfo` 檢查處理後的 APK。
- **Pass Criteria**: 所有 `.so` 檔的 Offset 除以 16384 餘數為 0。
- **Command**:
  ```bash
  zipinfo -v app-device-debug-aligned.apk | grep "lib/arm64-v8a" -A 3
  ```

### 步驟 3: 實機驗證
- **Action**: 安裝對齊後的 APK 至 Pixel 9a。
- **Command**:
  ```bash
  adb install -r app/build/outputs/apk/device/debug/app-device-debug-aligned.apk
  ```
- **Pass Criteria**: 啟動 App 時，**完全無** `PageSizeMismatchDialog` 警告。
