# Plan: Preview 放大修正 + 長寬比 Toggle UI

## Context — 為什麼做這個變更

### 問題背景
當前 SmartCameraApp Preview 顯示 **1.6x 視覺放大**，相比 Pixel 9a 原生相機 FOV (視角) 明顯偏小。使用者開啟 APP 第一眼就會覺得「畫面好像被放大了」。

### 技術根因
1. **CameraX Resolution Negotiation 問題**：
   - Preview 和 ImageAnalysis 共用同一個 `ResolutionSelector`（`LiveCameraSource.kt:857-875`）
   - 目標解析度設為 1280x720 (16:9)，但 CameraX 為兩個 UseCase 協商共同解析度時選中 **1280x960 (4:3)**
   - Logcat 證據：`Preview resolution mismatch! Requested=1280x960, Expected=1280x720`

2. **ScaleType 導致視覺裁切**：
   - `CameraPreview.kt:107` 使用 `FILL_CENTER` (CENTER_CROP)
   - 4:3 image 顯示在 9:19 螢幕上，水平裁切 36.6%
   - 等效放大倍數：1.577x（數學推導見 `docs/issues/preview_zoom_aspect_ratio.md`）

3. **ImageCapture 未同步長寬比**：
   - `LiveCameraSource.kt:912-918` ImageCapture 無 `ResolutionSelector`
   - 拍照輸出與 Preview 長寬比不一致（非 WYSIWYG）

### 預期成果
1. **修正 FOV 放大問題**：1.6x → ~1.1-1.2x（接近原生相機）
2. **專業相機 app 體驗**：長寬比 Toggle UI（4:3 / 16:9 / 1:1），參考 Pixel 9a 原生相機設計
3. **WYSIWYG 拍照**：Preview 與 ImageCapture 長寬比一致
