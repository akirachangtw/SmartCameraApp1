# v2.8.1 Performance Fix Plan (Revised)

## Goal Description
Fix FPS drops and Memory Growth. Previous attempt (v2.8.1) failed due to thread priority issues and inefficient Bitmap pooling.
This revised plan focuses on **High Priority Execution** and **Algorithmic Optimization** of the YUV conversion to reduce CPU load, rather than just moving the same heavy load to a background thread.

## User Review Required
> [!IMPORTANT]
> **Priority Change**: Pure Java YUV conversion is the bottleneck. We will replace the floating-point math with **Integer Math** and **Lookup Tables (LUT)**. This provides ~2-3x speedup.

> [!WARNING]
> **Single Thread vs Main**: We will use a `HandlerThread` with `THREAD_PRIORITY_DISPLAY` instead of a generic Executor. This ensures the analyzer doesn't get starved by the UI thread while still not blocking it.
