## 🔧 手動設定步驟

### Option A: 使用本地 AAR (推薦)

OpenCV Android SDK 目前沒有穩定的 Maven 倉庫,建議使用本地 AAR 方式:

#### 步驟 1: 下載 OpenCV Android SDK

1. 前往 [OpenCV Releases](https://github.com/opencv/opencv/releases)
2. 下載 **opencv-4.8.0-android-sdk.zip**
3. 解壓縮到本地目錄

#### 步驟 2: 提取 AAR 檔案

```bash
# 從解壓的 SDK 中找到 AAR 檔案
# 路徑通常是: opencv-4.8.0-android-sdk/sdk/
```

#### 步驟 3: 新增 AAR 到專案

方式 1 - 直接放入 libs 目錄:
```bash
mkdir app/libs
cp path/to/opencv-4.8.0.aar app/libs/
```

方式 2 - 使用 OpenCV Module:
```bash
# 將整個 opencv/sdk 作為 module 匯入專案
```

#### 步驟 4: 修改 build.gradle.kts

取消註解並修改為:

```kotlin
// === OpenCV (v2.7.0 Phase 2) ===
implementation(files("libs/opencv-4.8.0.aar"))
// 或使用 module 方式:
// implementation(project(":opencv"))
```

#### 步驟 5: 取消註解所有 OpenCV 相關代碼

1. **SmartCameraApplication.kt**
   - 取消註解 `import org.opencv.android.OpenCVLoader`
   - 取消註解 `initializeOpenCV()` 函數及其調用

2. **ImageProxyExtensions.kt**
   - 取消註解 `import org.opencv.core.CvType`
   - 取消註解 `import org.opencv.core.Mat`
   - 取消註解 `toGrayMat()` 和 `toBgrMat()` 函數

3. **GuidelineAnalyzer.kt**
   - 取消註解 `import com.akirachang.ai.photographer.data.source.camera.toGrayMat`
   - 取消註解 `analyze()` 函數中的完整實作
   - 刪除暫時的 placeholder 代碼

#### 步驟 6: 重新編譯

```bash
.\gradlew.bat assembleEmulatorDebug
```

## 📝 已知問題

### 1. OpenCV Maven 倉庫不可用

**原因**: `org.opencv:opencv-android:4.8.0` 在標準 Maven Central 和 Google Maven 中不存在。

**解決方案**: 使用本地 AAR(見 Option A)。

### 2. 編譯警告

```
w: 'fun setTargetResolution(p0: Size): Preview.Builder' is deprecated. Deprecated in Java.
```

這是 CameraX API 的 deprecation 警告,不影響功能,可在後續版本修正。
