## 觀察重點

目前系統使用 Lucas-Kanade 單點光流追蹤（`OpticalFlowTracker.kt`），已實作降採樣、速度限制、抖動抑制和模板匹配漂移修正。測試顯示追蹤品質穩定（平均 0.91），但存在嚴重漂移問題：與 Pixel 9a 內建相機相比漂移比例為 10:1，且「移動動作稍微大點，其定點偏移度就變大」。已嘗試的模板匹配修正（每 10 幀進行 TM_CCOEFF_NORMED 匹配）完全無效，因為相機平移導致透視和外觀變化破壞了歸一化互相關匹配。系統已具備 `DeviceSensorManager` 提供 IMU 數據（加速度計、磁力計），但未用於光流追蹤。

## 方案選擇

採用**多點追蹤 + RANSAC 離群值過濾**作為主要方案，並輔以 **IMU 輔助預測**作為增強方案。理由：(1) 單點 LK 光流的累積漂移是根本性限制，無法通過模板匹配解決；(2) 多點追蹤可通過中位數/RANSAC 平均化個別點的漂移，本質上更穩健；(3) IMU 數據可預測相機運動，補償大幅度移動；(4) OpenCV 已整合，`goodFeaturesToTrack` 和 `calcOpticalFlowPyrLK` 可直接使用；(5) 保持現有架構，僅升級 `OpticalFlowTracker` 內部實作。

### 1. 混合追蹤核心架構

**新增檔案**: `file:app/src/main/java/com/akirachang/ai/photographer/data/opencv/HybridPointTracker.kt`

實作混合追蹤策略，根據運動幅度動態選擇追蹤方法：

```kotlin
/**
 * Hybrid Point Tracker: 特徵匹配 + 光流混合追蹤
 * 
 * 策略：
 * - 小運動 (< 20px): 使用快速光流 (LK)
 * - 大運動 (>= 20px): 使用魯棒特徵匹配 (ORB + RANSAC)
 * - 失敗時自動降級或重新初始化
 */
class HybridPointTracker(
    private val config: OpticalFlowConfig = OpticalFlowConfig.DEFAULT
) {
    // 光流追蹤器（小運動）
    private var lkTracker: LKOpticalFlowTracker? = null
    
    // 特徵匹配追蹤器（大運動）
    private var featureMatchTracker: FeatureMatchTracker? = null
    
    // 當前追蹤狀態
    private var trackedCenter: Point? = null
    private var lastMotionMagnitude: Float = 0f
    private var trackingMode: TrackingMode = TrackingMode.IDLE
    
    enum class TrackingMode {
        IDLE,           // 未追蹤
        LK_OPTICAL_FLOW, // 光流模式（小運動）
        FEATURE_MATCH    // 特徵匹配模式（大運動）
    }
    
    fun startTracking(initialPoint: Point, imageWidth: Int, imageHeight: Int) {
        trackedCenter = initialPoint
        lkTracker = LKOpticalFlowTracker(config)
        featureMatchTracker = FeatureMatchTracker(config)
        
        lkTracker?.startTracking(initialPoint, imageWidth, imageHeight)
        featureMatchTracker?.startTracking(initialPoint, imageWidth, imageHeight)
        
        trackingMode = TrackingMode.LK_OPTICAL_FLOW // 初始使用光流
    }
    
    fun track(currentGray: Mat): TrackingResult {
        if (trackedCenter == null) return TrackingResult.LOST
        
        // 嘗試當前模式追蹤
        val result = when (trackingMode) {
            TrackingMode.LK_OPTICAL_FLOW -> {
                val lkResult = lkTracker?.track(currentGray) ?: return TrackingResult.LOST
                lastMotionMagnitude = lkResult.distance
                
                // 若運動幅度大且品質下降，切換到特徵匹配
                if (lkResult.distance >= 20f && lkResult.quality < 0.6f) {
                    Log.i(TAG, "Motion large (${lkResult.distance}px) + low quality (${lkResult.quality}) → switching to feature match")
                    trackingMode = TrackingMode.FEATURE_MATCH
                    featureMatchTracker?.track(currentGray)
                } else {
                    lkResult
                }
            }
            
            TrackingMode.FEATURE_MATCH -> {
                val fmResult = featureMatchTracker?.track(currentGray) ?: return TrackingResult.LOST
                lastMotionMagnitude = fmResult.distance
                
                // 若運動幅度小且品質好，切換回光流（更快）
                if (fmResult.distance < 10f && fmResult.quality > 0.7f) {
                    Log.i(TAG, "Motion small (${fmResult.distance}px) + good quality (${fmResult.quality}) → switching to LK")
                    trackingMode = TrackingMode.LK_OPTICAL_FLOW
                    lkTracker?.track(currentGray)
                } else {
                    fmResult
                }
            }
            
            TrackingMode.IDLE -> TrackingResult.LOST
        }
        
        if (result.isValid) {
            trackedCenter = result.point
        }
        
        return result
    }
    
    fun stopTracking() {
        lkTracker?.stopTracking()
        featureMatchTracker?.stopTracking()
        trackedCenter = null
        trackingMode = TrackingMode.IDLE
    }
}
```

### 2. 特徵匹配追蹤器實作

**新增檔案**: `file:app/src/main/java/com/akirachang/ai/photographer/data/opencv/FeatureMatchTracker.kt`

使用 ORB 特徵檢測 + RANSAC 匹配，處理大幅度運動和透視變化：

```kotlin
/**
 * Feature Match Tracker: ORB 特徵 + RANSAC 匹配
 * 
 * 優點：
 * - 處理大幅度運動（無小運動假設）
 * - 處理透視變化（通過 homography）
 * - 處理旋轉和尺度變化
 * - 魯棒性強（RANSAC 離群值過濾）
 * 
 * 缺點：
 * - 計算量較大（~30-50ms）
 * - 需要足夠的紋理特徵
 */
class FeatureMatchTracker(
    private val config: OpticalFlowConfig
) {
    companion object {
        private const val TAG = "FeatureMatchTracker"
        private const val MAX_DOWNSAMPLE_DIM = 640
        private const val ORB_FEATURES = 500        // ORB 檢測特徵數
        private const val MATCH_RATIO_THRESHOLD = 0.7f  // Lowe's ratio test
        private const val RANSAC_THRESHOLD = 5.0    // RANSAC 內點閾值（像素）
    }
    
    private var prevGray: Mat? = null
    private var prevKeypoints: List<KeyPoint>? = null
    private var prevDescriptors: Mat? = null
    private var trackedCenter: Point? = null
    private var initialROI: Rect? = null
    
    private val orb = ORB.create(ORB_FEATURES)
    private val matcher = BFMatcher(NORM_HAMMING, crossCheck = false)
    
    private var downsampleWidth: Int = 0
    private var downsampleHeight: Int = 0
    private var scaleX: Float = 1f
    private var scaleY: Float = 1f
    
    fun startTracking(initialPoint: Point, imageWidth: Int, imageHeight: Int) {
        val scale = minOf(MAX_DOWNSAMPLE_DIM.toFloat() / imageWidth, MAX_DOWNSAMPLE_DIM.toFloat() / imageHeight)
        downsampleWidth = (imageWidth * scale).toInt()
        downsampleHeight = (imageHeight * scale).toInt()
        scaleX = downsampleWidth.toFloat() / imageWidth
        scaleY = downsampleHeight.toFloat() / imageHeight
        
        trackedCenter = Point(initialPoint.x * scaleX, initialPoint.y * scaleY)
        initialROI = Rect(
            (trackedCenter!!.x - 100).toInt().coerceAtLeast(0),
            (trackedCenter!!.y - 100).toInt().coerceAtLeast(0),
            200, 200
        )
    }
    
    fun track(currentGray: Mat): TrackingResult {
        if (trackedCenter == null) return TrackingResult.LOST
        
        val downsampledGray = downsampleMat(currentGray)
        
        try {
            // 首幀：檢測特徵並保存
            if (prevGray == null) {
                prevGray = downsampledGray.clone()
                detectFeatures(downsampledGray)
                return TrackingResult(
                    point = scalePointToOriginal(trackedCenter!!),
                    quality = 1.0f,
                    distance = 0f,
                    isValid = true
                )
            }
            
            // 檢測當前幀特徵
            val currKeypoints = mutableListOf<KeyPoint>()
            val currDescriptors = Mat()
            orb.detectAndCompute(downsampledGray, null, currKeypoints, currDescriptors)
            
            if (currKeypoints.isEmpty() || prevDescriptors == null || prevDescriptors!!.empty()) {
                Log.w(TAG, "Insufficient features for matching")
                return TrackingResult.LOST
            }
            
            // KNN 匹配 + Lowe's ratio test
            val matches = knnMatch(prevDescriptors!!, currDescriptors, 2)
            val goodMatches = matches.filter { match ->
                match.size == 2 && match[0].distance < MATCH_RATIO_THRESHOLD * match[1].distance
            }
            
            if (goodMatches.size < 4) {
                Log.w(TAG, "Too few good matches: ${goodMatches.size}")
                return TrackingResult.LOST
            }
            
            // 提取匹配點對
            val prevPts = goodMatches.map { prevKeypoints!![it[0].queryIdx].pt }
            val currPts = goodMatches.map { currKeypoints[it[0].trainIdx].pt }
            
            // RANSAC 計算 homography
            val srcPts = MatOfPoint2f(*prevPts.toTypedArray())
            val dstPts = MatOfPoint2f(*currPts.toTypedArray())
            val homography = Calib3d.findHomography(srcPts, dstPts, Calib3d.RANSAC, RANSAC_THRESHOLD)
            
            if (homography.empty()) {
                Log.w(TAG, "Failed to compute homography")
                return TrackingResult.LOST
            }
            
            // 應用 homography 變換追蹤點
            val trackedPt = MatOfPoint2f(trackedCenter!!)
            val transformedPt = MatOfPoint2f()
            Core.perspectiveTransform(trackedPt, transformedPt, homography)
            
            val newCenter = transformedPt.toArray()[0]
            val distance = calculateDistance(trackedCenter!!, newCenter)
            
            // 品質 = 內點比例 * 匹配品質
            val inlierRatio = goodMatches.size.toFloat() / prevKeypoints!!.size.toFloat()
            val matchQuality = (goodMatches.size.toFloat() / 10f).coerceIn(0f, 1f)
            val quality = (inlierRatio * matchQuality).coerceIn(0f, 1f)
            
            Log.v(TAG, "Matches: ${goodMatches.size}/${prevKeypoints!!.size}, quality=${"%.2f".format(quality)}, distance=${"%.1f".format(distance)}px")
            
            // 驗證結果
            val isValid = validateTracking(newCenter, downsampledGray.width().toFloat(), downsampledGray.height().toFloat(), quality, distance)
            
            if (isValid) {
                trackedCenter = newCenter
                prevGray = downsampledGray.clone()
                prevKeypoints = currKeypoints
                prevDescriptors?.release()
                prevDescriptors = currDescriptors.clone()
                
                return TrackingResult(
                    point = scalePointToOriginal(trackedCenter!!),
                    quality = quality,
                    distance = distance,
                    isValid = true
                )
            } else {
                return TrackingResult.LOST
            }
            
        } finally {
            downsampledGray.release()
        }
    }
    
    fun stopTracking() {
        prevGray?.release()
        prevDescriptors?.release()
        prevGray = null
        prevDescriptors = null
        prevKeypoints = null
        trackedCenter = null
    }
    
    private fun detectFeatures(gray: Mat) {
        val keypoints = mutableListOf<KeyPoint>()
        val descriptors = Mat()
        orb.detectAndCompute(gray, null, keypoints, descriptors)
        prevKeypoints = keypoints
        prevDescriptors = descriptors
    }
    
    private fun knnMatch(descriptors1: Mat, descriptors2: Mat, k: Int): List<List<DMatch>> {
        // OpenCV 的 knnMatch 實作
        return matcher.knnMatch(descriptors1, descriptors2, k)
    }
    
    private fun downsampleMat(src: Mat): Mat {
        val dst = Mat()
        Imgproc.resize(src, dst, Size(downsampleWidth.toDouble(), downsampleHeight.toDouble()), 0.0, 0.0, Imgproc.INTER_LINEAR)
        return dst
    }
    
    private fun scalePointToOriginal(point: Point): Point {
        return Point(point.x / scaleX, point.y / scaleY)
    }
    
    private fun calculateDistance(p1: Point, p2: Point): Float {
        val dx = p2.x - p1.x
        val dy = p2.y - p1.y
        return sqrt(dx * dx + dy * dy).toFloat()
    }
    
    private fun validateTracking(point: Point, imageWidth: Float, imageHeight: Float, quality: Float, distance: Float): Boolean {
        return point.x >= 0 && point.x < imageWidth && point.y >= 0 && point.y < imageHeight &&
               quality >= config.minQuality && distance <= config.maxTrackingDistance
    }
}

class TrackingPerformanceMonitor {
    private val frameTimings = mutableListOf<Long>()
    private val maxFrameTime = 33L  // 30 FPS = 33ms per frame
    
    fun recordFrameTime(timeMs: Long) {
        frameTimings.add(timeMs)
        if (frameTimings.size > 30) frameTimings.removeAt(0)
    }
    
    fun getAverageFrameTime(): Long = frameTimings.average().toLong()
    
    fun shouldDowngrade(): Boolean {
        val avgTime = getAverageFrameTime()
        return avgTime > maxFrameTime * 0.8f  // 若平均耗時 > 26ms，考慮降級
    }
}
```

### 7. 實機測試場景

**功能驗證**：

1. **小運動場景**（光流模式）：
   - 點擊目標 → 輕微移動手機（< 20px/frame）
   - 預期：使用 LK 光流，快速響應（< 15ms）

2. **大運動場景**（特徵匹配模式）：
   - 點擊目標 → 快速平移手機（> 20px/frame）
   - 預期：自動切換到特徵匹配，追蹤不失效

3. **透視變化場景**：
   - 點擊目標 → 手機旋轉或傾斜
   - 預期：特徵匹配通過 homography 處理透視，追蹤穩定

4. **模式切換場景**：
   - 快速移動 → 逐漸減速
   - 預期：自動從特徵匹配切換回 LK 光流

**效能指標**：

- LK 光流：< 15ms/frame
- 特徵匹配：< 50ms/frame（可接受，因為運動大時不需要高頻率）
- 模式切換延遲：< 100ms
- 整體 FPS：≥ 25 FPS
