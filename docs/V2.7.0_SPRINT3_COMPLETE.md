## 📋 Sprint 3 完成項目

### 1. GuidelineAnalysisResult 資料模型 ✅

**檔案**: [`app/src/main/java/com/akirachang/ai/photographer/domain/model/GuidelineAnalysisResult.kt`](../app/src/main/java/com/akirachang/ai/photographer/domain/model/GuidelineAnalysisResult.kt)

**功能**:
- 定義完整的線條資料結構 (`Line`)
- 正規化座標系統 `[0.0, 1.0]` (與螢幕無關)
- 線條強度計算 (`strength` 0.0-1.0)
- 線條類型分類 (`LineType` enum):
  - `GENERAL` - 一般線條
  - `LEADING` - 引導線 (道路、欄杆)
  - `SYMMETRY` - 對稱軸
  - `HORIZON` - 地平線
  - `ARCHITECTURAL` - 建築線條

**輔助功能**:
```kotlin
// 線條方向判斷
line.isHorizontal  // 水平線 (±15°)
line.isVertical    // 垂直線 (90° ±15°)
line.isDiagonal    // 對角線

// 過濾與排序
result.filterByStrength(0.5f)  // 過濾弱線條
result.topLines(10)            // 取前 10 條最強線條
result.horizontalLines()       // 只取水平線
```

### 2. OpenCV Hough Line Transform 實作 ✅

**檔案**: [`app/src/main/java/com/akirachang/ai/photographer/data/source/analysis/GuidelineAnalyzer.kt`](../app/src/main/java/com/akirachang/ai/photographer/data/source/analysis/GuidelineAnalyzer.kt)

**核心 Pipeline**:
```
ImageProxy → toGrayMat() → Canny Edge Detection → Hough Line Transform → Line Filtering
```

**OpenCV 參數**:
```kotlin
// Canny Edge Detection
CANNY_THRESHOLD_1 = 50.0   // 低閾值
CANNY_THRESHOLD_2 = 150.0  // 高閾值

// Hough Line Transform (Probabilistic)
HOUGH_RHO = 1.0              // 距離解析度 (pixels)
HOUGH_THETA = π/180          // 角度解析度 (1 degree)
HOUGH_THRESHOLD = 50         // 最小票數
HOUGH_MIN_LINE_LENGTH = 50.0 // 最小線長 (pixels)
HOUGH_MAX_LINE_GAP = 10.0    // 最大間隙 (pixels)

// Line Filtering
MAX_LINES = 10               // 最多回傳線條數
MIN_LINE_STRENGTH = 0.3f     // 最小強度閾值
```

**效能目標**:
- 平均處理時間: < 15ms
- P95 處理時間: < 30ms
- 記憶體: 自動 Mat.release()

**使用方式**:
```kotlin
val analyzer = GuidelineAnalyzer { result ->
    // Callback with GuidelineAnalysisResult
    // Called on background thread
    Log.d(TAG, "Detected ${result.lines.size} lines")
}
```

### 3. GuidelineOverlay 動態渲染 ✅

**檔案**: [`app/src/main/java/com/akirachang/ai/photographer/presentation/camera/components/overlay/GuidelineOverlay.kt`](../app/src/main/java/com/akirachang/ai/photographer/presentation/camera/components/overlay/GuidelineOverlay.kt)

**視覺設計**:
- **檢測線條**: 金黃色 `#FFD700` (與 UI/UX 計劃一致)
  - Alpha: `0.3 + (strength * 0.7)` (強度越高越明顯)
  - StrokeWidth: `1.5dp + (strength * 1.5dp)` (強度越高越粗)
  - StrokeCap: `Round` (圓角線條)

- **Fallback 格線**: 白色半透明 (`alpha=0.5`)
  - 三分法 2x2 格線
  - 當無檢測結果時自動顯示

**使用方式**:
```kotlin
GuidelineOverlay(
    enabled = isGuidelineEnabled,
    analysisResult = guidelineResult,  // null = 顯示固定格線
    modifier = Modifier.fillMaxSize()
)
```

@Test
fun `should detect horizontal lines in test image`() {
    val testImage = loadTestImage("horizontal_lines.jpg")

    assertThat(result.lines).isNotEmpty()
    assertThat(result.horizontalLines().lines).hasSize(greaterThan(0))

        assertThat(line.start.y).isBetween(0f, 1f)

## 📝 重要提醒

### OpenCV 記憶體管理
```kotlin
// ✅ 正確
val mat = image.toGrayMat()
try {
    // Use mat
} finally {
    mat.release()  // 必須釋放
    image.close()
}

// ❌ 錯誤
val mat = image.toGrayMat()
// Forgot to release() → Memory leak!
```

### 執行緒安全
- `GuidelineAnalyzer.analyze()` 在 ImageAnalysis executor (background thread)
- StateFlow 更新會自動切換到 main thread (Compose recomposition)
- 不需要手動 `withContext(Dispatchers.Main)`
