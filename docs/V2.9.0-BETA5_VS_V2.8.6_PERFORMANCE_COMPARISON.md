## 🔬 技術深度分析

### 為什麼 v2.8.6 Graphics 會成長到 216 MB？

**根本原因**: 解析度失控

1. **CameraX 自由選擇**: v2.8.6 無 ResolutionSelector
2. **選擇高解析度**: CameraX 預設選擇 1080x1080 (1.17 MP)
3. **每幀記憶體大**: 1080x1080 YUV = ~1.7 MB/frame
4. **記憶體持續累積**: 10 分鐘內 Graphics 從 63.8 MB → 216 MB
5. **BitmapPool 無法完全抵消**: 雖有 BitmapPool，但解析度太高導致記憶體洩漏仍明顯

**數學計算**:
```
v2.8.6:
- 解析度: 1080x1080 = 1,166,400 pixels
- YUV_420_888: 1.5 bytes/pixel
- 每幀大小: 1,166,400 * 1.5 = ~1.75 MB
- BitmapPool (ARGB_8888): 1,166,400 * 4 = ~4.4 MB/bitmap
- 3 個 buffer: 4.4 * 3 = 13.2 MB (最小)
- 實際 Graphics @ T0: 63.8 MB (包含其他 GPU 資源)
```

---

### 為什麼 v2.9.0-beta5 Graphics 只需 46 MB？

**解決方案**: 解析度精確控制

1. **ResolutionSelector**: 主動設定 target = 640x480
2. **ResolutionFilter**: 硬性過濾 ≤800x600
3. **CameraX 遵守**: 精確選擇 640x480
4. **每幀記憶體小**: 640x480 YUV = ~0.45 MB/frame
5. **BitmapPool 效率高**: 較小 bitmap = 更高回收率 (99%)

**數學計算**:
```
v2.9.0-beta5:
- 解析度: 640x480 = 307,200 pixels
- YUV_420_888: 1.5 bytes/pixel
- 每幀大小: 307,200 * 1.5 = ~0.45 MB
- BitmapPool (ARGB_8888): 307,200 * 4 = ~1.2 MB/bitmap
- 3 個 buffer: 1.2 * 3 = 3.6 MB (最小)
- 實際 Graphics @ T0: 46 MB (包含其他 GPU 資源)

vs v2.8.6:
- 像素數: 307,200 vs 1,166,400 = -73.7% ✅
- Bitmap 大小: 1.2 MB vs 4.4 MB = -73% ✅
- Graphics @ T0: 46 MB vs 63.8 MB = -28% ✅
```

---

### 為什麼 v2.9.0-beta5 FPS 更高？

**原因分析**:

1. **YUV 轉換更快**:
   - v2.8.6: 1080x1080 = 1.17 MP → RenderScript ~5-8ms
   - v2.9.0-beta5: 640x480 = 0.31 MP → RenderScript ~2-3ms
   - **改善**: -3 to -5ms per frame

2. **Transform 更快**:
   - 較小的 bitmap rotation/mirror
   - v2.8.6: ~10-15ms
   - v2.9.0-beta5: ~5-10ms
   - **改善**: -5ms per frame

3. **記憶體分配更少**:
   - BitmapPool 99% hit rate → 幾乎無記憶體分配延遲
   - 較小 bitmap → 更快的記憶體操作

4. **GC 暫停更少**:
   - 較低記憶體用量 → 較少 GC 觸發
   - 較快 GC (更少物件)

**FPS 計算**:
```
v2.8.6:
- Frame time: YUV(6ms) + Transform(12ms) + Analysis(8ms) = 26ms
- Max FPS: 1000/26 = 38 FPS (理論)
- 實際 FPS: ~25 (GPU/memory overhead)

v2.9.0-beta5:
- Frame time: YUV(2ms) + Transform(6ms) + Analysis(8ms) = 16ms
- Max FPS: 1000/16 = 62 FPS (理論)
- 實際 FPS: ~29 (GPU/memory overhead)

改善: +4 FPS (+16%) ✅
```
