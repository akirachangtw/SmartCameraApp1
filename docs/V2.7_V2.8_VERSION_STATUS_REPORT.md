**測試結果** (Final Validation):
| 指標 | v2.8.3 | v2.8.4 | 改善 | 目標 | 狀態 |
|------|--------|--------|------|------|------|
| **Average FPS** | 19-20 | **27.2** | **+36%** | ≥26 | ✅ **達標** |
| **Pool Keys** | 10+ | **1** | **-90%** | ≤2 | ✅ **超越** |
| **Pool Hit Rate** | <50% | **99%** | **+49%** | >90% | ✅ **超越** |
| **Min FPS** | - | 25.3 | - | - | ✅ Good |
| **Max FPS** | - | 29.0 | - | - | ✅ Excellent |
| **P95 FPS** | - | 29.0 | - | - | ✅ Excellent |

**關鍵發現** 💡:
1. **BitmapPool Key Explosion 根本原因**:
   - `ceil(mapRect())` 浮點誤差 → 721, 719, 722 vs 720
   - 修復: 固定整數尺寸計算
   - 結果: Keys 10+ → 1, Hit Rate 99%

2. **光線影響 FPS (硬體行為)**:
   - 良好光線 (桌燈 ON): 27-29 FPS ✅
   - 低光線 (桌燈 OFF): 16-17 FPS ⚠️
   - 原因: 相機自動增加曝光時間以改善畫質
   - 結論: **正常硬體行為,非軟體問題**

3. **管道解耦有效**:
   - Camera pipeline: 27 FPS (獨立運行)
   - Analysis pipeline: 10 FPS (throttled)
   - ML Kit 120ms 不阻塞相機 FPS ✅
