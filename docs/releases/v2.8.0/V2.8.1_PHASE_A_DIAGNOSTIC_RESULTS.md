## 🔬 Root Cause Analysis

### Why is YUV Conversion So Slow?

Current implementation ([LiveCameraSource.kt:748-790](../app/src/main/java/com/akirachang/ai/photographer/data/source/camera/LiveCameraSource.kt#L748-L790)):

```kotlin
private fun ImageProxy.toBitmap(pool: BitmapPool): BitmapPool.BitmapBuffer {
    // ... extract Y/U/V planes ...

    for (y in 0 until height) {
        for (x in 0 until width) {
            val yValue = (yBuffer.get(yRowOffset + x).toInt() and 0xFF)
            val uValue = (uBuffer.get(uvPixelIndex).toInt() and 0xFF) - 128
            val vValue = (vBuffer.get(uvPixelIndex).toInt() and 0xFF) - 128

            // ❌ FLOATING-POINT MATH (SLOW on mid-range CPUs!)
            val r = (yValue + 1.402f * vValue).toInt().coerceIn(0, 255)
            val g = (yValue - 0.344f * uValue - 0.714f * vValue).toInt().coerceIn(0, 255)
            val b = (yValue + 1.772f * uValue).toInt().coerceIn(0, 255)

            pixels[pixelIndex++] = (0xFF shl 24) or (r shl 16) or (g shl 8) or b
        }
    }
}
```

**Problem**:
- 640 × 480 = 307,200 pixels
- Each pixel: 6 floating-point multiplications
- Total: **~1.8 million float operations per frame**
- Snapdragon 690's FPU is **not optimized** for this workload

## 💡 Recommendations

### Immediate Action: Implement Phase B-1 (YUV Integer Optimization)

**Current Performance**:
```
YUV Conversion (float): 44.4ms avg
```

**Expected After Integer Optimization**:
```
YUV Conversion (integer + LUT): 15-20ms avg  (2-3x speedup)
Total Per Frame: 28-33ms
Expected FPS: 30-35 FPS  ✅
```

### Implementation Strategy

1. **Create `YuvConverter.kt`** with integer math:
   ```kotlin
   val r = yValue + ((359 * (vValue - 128)) shr 8)  // No float!
   val g = yValue - ((88 * (uValue - 128)) shr 8) - ((182 * (vValue - 128)) shr 8)
   val b = yValue + ((454 * (uValue - 128)) shr 8)
   ```

2. **Add Lookup Tables** for further optimization:
   ```kotlin
   private val rLut = IntArray(256) { v -> (359 * (v - 128)) shr 8 }
   private val gLut = IntArray(256) { v -> (88 * (v - 128)) shr 8 }
   private val bLut = IntArray(256) { v -> (454 * (v - 128)) shr 8 }
   ```

3. **A/B Test**:
   - Before: Float math (44.4ms)
   - After: Integer math (target: < 20ms)
   - Expected FPS improvement: 16.0 → 26+ FPS
