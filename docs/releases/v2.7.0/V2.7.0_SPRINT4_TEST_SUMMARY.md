## Root Cause Analysis

### Performance Bottleneck

**LiveCameraSource overhead** dominates processing time:

```
Real Device Processing Breakdown (Average 132.8ms):
  1. YUV→Bitmap Conversion (implicit): ~35ms  (26%)
  2. Bitmap.toGrayMat() (RGBA→Gray): ~25ms   (19%)
  3. Camera Buffer Management: ~20ms          (15%)
  ------------------------------------------------
  Subtotal (Camera Pipeline): ~80ms           (60%)

  4. Canny Edge Detection: ~20ms              (15%)
  5. Hough Line Transform: ~25ms              (19%)
  6. Line Filtering: ~5ms                     (4%)
  ------------------------------------------------
  Subtotal (OpenCV Processing): ~50ms         (40%)

Total: ~130ms
```

**Bottleneck**: Camera pipeline (Steps 1-3) accounts for **60% of total time**.

### Why Emulator is Faster

```
Emulator Best Frame (14ms):
  1. Bitmap.toGrayMat() [StaticImageSource]: ~2ms  (no YUV conversion)
  2. Canny Edge Detection: ~4ms
  3. Hough Line Transform: ~6ms
  4. Line Filtering: ~2ms
Total: 14ms ✅

Emulator Average (50ms):
  - Includes ~20-30ms image switching overhead (StaticImageSource artifact)
```

**Key Difference**: StaticImageSource skips YUV→Bitmap conversion (**~35ms saved**).

## Optimization Recommendations

### Priority 1: OpenCV Parameter Tuning 🔧

**Target**: Reduce Hough Transform complexity

**Changes to GuidelineAnalyzer.kt**:
```kotlin
// Current (Sprint 3)
HOUGH_THRESHOLD = 50
HOUGH_MIN_LINE_LENGTH = 50.0
MAX_LINES = 10
MIN_LINE_STRENGTH = 0.3f

// Optimized (Sprint 5)
HOUGH_THRESHOLD = 70         (+40% stricter)
HOUGH_MIN_LINE_LENGTH = 80.0 (+60% longer)
MAX_LINES = 6                (-40% fewer)
MIN_LINE_STRENGTH = 0.5f     (+67% stronger)
```

**Expected Impact**:
- OpenCV processing: 50ms → **~20ms** (2.5x faster)
- Total time: 132.8ms → **~100ms** (1.3x faster)

**Effort**: Low (change 4 constants)
**Risk**: Low (Feature Flag rollback available)
**Timeline**: Sprint 5 (1-2 hours)

### Priority 2: Bypass Bitmap Conversion 🚀

**Target**: Eliminate YUV→Bitmap→Mat double conversion

**Architectural Changes**:
1. Modify ViewModel to sample `ImageProxy` instead of `previewBitmap`
2. Use existing `ImageProxy.toGrayMat()` (direct Y plane extraction)
3. Update GuidelineAnalyzer to accept `ImageProxy`

**Expected Impact**:
- Eliminate Bitmap conversion: ~25ms → **0ms**
- Reduce YUV overhead: ~35ms → **~10ms**
- Total time: 100ms → **~60-70ms** (1.7x faster)

**Effort**: Medium (refactor ViewModel + tests)
**Risk**: Medium (architectural change)
**Timeline**: v2.8.0 (1-2 days)

### Priority 3: Image Downsampling 📐

**Target**: Reduce input resolution

**Changes to ImageProxyExtensions.kt**:
```kotlin
fun Bitmap.toGrayMat(): Mat {
    // Downsample to 800x600 for faster processing
    val scaledBitmap = Bitmap.createScaledBitmap(
        this, 800, (800.0 * height / width).toInt(), true
    )
    // ... rest of conversion
}
```

**Expected Impact**:
- Reduce pixel count: ~70% (assuming 1920x1080 input)
- OpenCV processing: ~45ms → **~15ms** (3x faster)
- Total time: 60-70ms → **~40-50ms** (1.5x faster)

**Effort**: Low (add scaling step)
**Risk**: Low (quality vs performance tradeoff)
**Timeline**: v2.8.0 (as needed)
