## 🤔 模擬器測試的挑戰與限制

### ⚠️ 已知限制

#### 1. 相機硬體模擬不完整
```
問題: Android Emulator 的相機是虛擬的
影響:
- 支援的解析度列表可能與實體裝置不同
- Camera2 API 回報的特性可能不準確
- 某些解析度可能無法實際使用
```

#### 2. 裝置識別問題
```
問題: 模擬器的 Build.MANUFACTURER 和 Build.MODEL 不同於實體裝置
影響:
- 可能被識別為 "Google" + "sdk_gphone" 或類似名稱
- 不會匹配 Pixel 或 Sony 策略
- 會使用 Generic 策略（這其實是好事，可測試 fallback）
```

#### 3. Graphics 記憶體測量不準確
```
問題: 模擬器的 GPU 模擬與實體裝置差異大
影響:
- Graphics 記憶體數值可能不具參考價值
- 無法驗證記憶體優化效果
```

#### 4. 效能不具代表性
```
問題: 模擬器效能依賴主機電腦
影響:
- FPS 可能很高（主機強）或很低（主機弱）
- 無法驗證實際裝置的效能表現
```

## 🔧 已知問題與 Workaround

### 問題 1: 模擬器相機權限

**現象**: 啟動後黑畫面或權限拒絕

**Workaround**:
```bash
# 手動授予相機權限
adb shell pm grant com.akirachang.ai.photographer android.permission.CAMERA
```

**現象**: 選擇的解析度無法實際使用

**預期行為**: 應自動 fallback 到其他解析度

**驗證**: 檢查 ImageAnalysis 是否正常接收幀

### 問題 3: 模擬器效能差

**現象**: FPS < 10

**影響**: 不影響解析度選擇邏輯測試

**說明**: 這是預期行為，模擬器效能本來就差

## 🤖 自動化測試腳本（可選）

```bash
#!/bin/bash
# emulator_resolution_test.sh

EMULATOR_NAME="Pixel_9_Pro_XL_API_35"
OUTPUT_DIR="tmp/test_outputs"
TIMESTAMP=$(date +%Y%m%d_%H%M%S)

echo "🚀 Starting emulator resolution test..."

# 1. 啟動模擬器
echo "📱 Launching emulator: $EMULATOR_NAME"
emulator -avd $EMULATOR_NAME &
EMULATOR_PID=$!

# 等待模擬器完全啟動
echo "⏳ Waiting for emulator to boot..."
adb wait-for-device
sleep 30

# 2. 安裝 APK
echo "📦 Installing APK..."
./gradlew installDeviceDebug

# 3. 授予權限
echo "🔓 Granting permissions..."
adb shell pm grant com.akirachang.ai.photographer android.permission.CAMERA

# 4. 清除並啟動
echo "🎬 Launching app..."
adb logcat -c
adb shell am start -n com.akirachang.ai.photographer/.MainActivity

# 5. 等待並擷取日誌
echo "⏱️ Waiting 60 seconds..."
sleep 60

echo "📝 Capturing logs..."
adb logcat -d > "$OUTPUT_DIR/emulator_test_${TIMESTAMP}.log"

# 6. 檢查記憶體
echo "💾 Checking memory..."
adb shell dumpsys meminfo com.akirachang.ai.photographer > "$OUTPUT_DIR/emulator_memory_${TIMESTAMP}.txt"

# 7. 分析日誌
echo "🔍 Analyzing logs..."
grep "\[v2.9.0-beta5\]" "$OUTPUT_DIR/emulator_test_${TIMESTAMP}.log" > "$OUTPUT_DIR/emulator_beta5_${TIMESTAMP}.log"

echo "✅ Test complete!"
echo "📄 Logs saved to: $OUTPUT_DIR/"
echo ""
echo "📊 Quick Summary:"
grep "Device:" "$OUTPUT_DIR/emulator_beta5_${TIMESTAMP}.log" | head -1
grep "Smart Resolution:" "$OUTPUT_DIR/emulator_beta5_${TIMESTAMP}.log" | head -1

# 8. 關閉模擬器
read -p "⏸️ Press Enter to shutdown emulator..."
kill $EMULATOR_PID
```
