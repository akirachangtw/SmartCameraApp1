我們需要換到一個新的對話視窗以重置 Context Window。

### 1. 檔案命名要求

撰寫一份「交接提示詞 (Handoff Prompt)」，自動儲存到腳本所在目錄的\chat_logs\
- 對話記錄檔案命名格式：`handofflog_YYYYMMDD_HHMMSS.md` (請自動帶入當下的日期與時間)

### 2. 內容結構要求
交接內容必須包含以下章節，並採用 Markdown 格式：

1. **專案背景 (Context)**：簡述我們正在解決的問題。
2. **語言規範 (Language Rules)**：
   - **腳本內容 (Scripts/Code)**：必須使用 **英文** 撰寫（包含變數名稱、註解、Log 輸出訊息）。
   - **對話溝通 (Chat)**：請使用 **繁體中文** 與我進行說明、討論與互動。
3. **目前狀態 (Current Status)**：已完成的項目、解決的關鍵錯誤。
4. **最新交付成果 (Latest Deliverable)**：
   - 請附上目前為止**最正確、完整**的程式碼版本。
   - **禁止**使用省略號 (如 `// ... rest of code`)，必須是完整可執行的內容。
5. **下一步行動 (Next Steps)**：在新對話中立即要執行的任務。

請確保生成的這段文字是**給「下一位 Claude」看的指令**。
