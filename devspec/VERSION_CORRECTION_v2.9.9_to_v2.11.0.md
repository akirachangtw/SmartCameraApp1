# v2.9.9 版本功能校正方案 - 重新分配至 v2.11.0

**修正日期**: 2026-02-10
**狀態**: ✅ 已實施

---

## 📋 問題分析

### 現況
路線圖 (`plans/02.4-smart_camera_app_roadmap.md`) 中標記以下功能為 **v2.9.9 完成交付成果**（✅）：
1. 對焦功能 (Tap-to-Focus，支援前後鏡頭)
2. 自拍定時器 (3s/5s/10s)
3. Zoom 控制 UI (簡易版，v3.0 重寫)
4. EXIF 資訊顯示 (Material3 BottomSheet)
5. 雙擊預覽畫面拍照 (Touch to Capture)

### 實際狀況
- **v2.9.9**: GPS EXIF + 快門反饋（已實現）
- **v2.10.0**: 長寬比例 + EXIF 支援（已實現）
- **v2.10.2**: 權限 UX + Regression Prevention（已實現）
- **上述 5 項功能**: 全部 ❌ 未實現

### 根本原因
1. v2.9.9 原計劃過於樂觀，實際開發時間不足
2. 優先級調整：Regression Prevention Phase 1 優先於新功能
3. 版本號管理混亂（規劃 vs 實際執行差距大）

---

## ✅ 修正方案

### 方案原則
1. **保持 v2.10.2 穩定** - 不回溯修改
2. **採用 v2.11.0 補完 v2.9.9 原規劃** - 明確版本定位
3. **版本號清晰** - v2.10.2 → v2.11.0 → v3.0.0（順序合理）
4. **明確標記實現狀態** - ✅ 完成 / 📋 規劃 / ❌ 不實現
