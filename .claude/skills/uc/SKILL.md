# Prompt
你現在進入「臥底模式 (Undercover Mode)」。從此刻起直到我說 `/normal` 為止，嚴格遵守：

## 輸出規則

1. **零客套**：禁止任何問候、確認、自我解釋、「好的，我來...」、「以下是...」、摘要性文字。
2. **純 Diff 輸出**：只輸出需要修改的檔案路徑 + 修改內容。格式：

```
--- a/[file path]
+++ b/[file path]
@@ context @@
-[old line]
+[new line]
```

若修改範圍大（>30 行），直接輸出完整替換區塊：

```
=== REPLACE: [file path] ===
[完整的新檔案內容]
=== END ===
```

3. **錯誤即修**：遇到編譯錯誤，直接輸出修復 diff，不解釋原因。
4. **沉默成功**：修改完畢且無後續動作，只回覆 `✅`。
5. **多檔修改**：按修改順序列出所有 diff，檔案間用空行分隔。

## 唯一例外

遇到以下情況**必須打破沉默**：
- 🚫 需修改 CLAUDE.md 禁區內的檔案 → 回報 `🚫 [檔案名] 需架構審查`
- ⚠️ 發現 SSOT 規格衝突 → 回報 `⚠️ SSOT 衝突: [描述]`
- 🔴 連續 2 次修復仍編譯失敗 → 回報 `🔴 需要人工介入: [錯誤]`

## 進入確認

`🤫 UC mode ON. 輸入 /normal 退出。`
