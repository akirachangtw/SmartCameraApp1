### P1 殘留：Eye-AF 動態節流

**原始需求** (Final.md Fix 1.2 混合策略)：
- 靜態場景：2s 基礎節流（已完成 ✅）
- **動態場景**：Eye 移動 > 50px 時，400ms 後提前觸發（最快 2.5Hz）

**實作**（Final.md code snippet）：
```kotlin
// CameraViewModel.kt — autoFocusOnSalientTarget()
private var lastEyePosition: PointF? = null
private val EYE_MOVEMENT_THRESHOLD = 50f

val shouldThrottle = when {
    now - lastAutoFocusTime < AUTO_FOCUS_THROTTLE_BASE -> true
    lastEyePosition != null && now - lastAutoFocusTime > 400L -> {
        val eyePos = detectionResult.eyePositions.firstOrNull()?.nearestEye
        if (eyePos != null) {
            val dist = sqrt((eyePos.x - lastEyePosition!!.x).pow(2) + (eyePos.y - lastEyePosition!!.y).pow(2))
            dist < EYE_MOVEMENT_THRESHOLD  // 移動 < 50px 才節流
        } else true
    }
    else -> false
}
// Focus 成功後：lastEyePosition = eyePos
```

### P2 殘留：自適應對焦框 48-120dp

**原始需求** (Final.md Fix 2.1)：

**實作範圍**（Final.md Fix 2.1 四步驟）：

```
1. CameraState.kt
   + focusFrameWidth: Float = 48f
   + focusFrameHeight: Float = 48f
   + isAutoFocused: Boolean = false

2. CameraViewModel.kt
   + calculateAdaptiveFrameSize(boundingBox, density): Pair<Float, Float>
   - autoFocusOnSalientTarget() → 觸發對焦前 _state.update { focusFrameWidth/Height, isAutoFocused=true }

3. CameraScreen.kt — FocusIndicator()
   + focusFrameWidth: Float, focusFrameHeight: Float 參數
   + animateFloatAsState(Spring.DampingRatioMediumBouncy, StiffnessLow) 平滑動畫
   - Canvas 繪製改用 halfWidth/halfHeight

4. 狀態機 isAutoFocused → else 分支 focusIndicatorFading reset
```

### P3 殘留：OF 參數強化 + 熱控監控

**⚠️ 必須先實作熱控監控，才能啟用高 FPS/大 Window 配置（Pixel 9a 熱控風險）**

#### P3-A: 熱控監控（前置依賴）

**原始需求** (Final.md P3 Thermal Monitoring)：

```kotlin
// LiveCameraSource.kt
private fun setupThermalMonitoring() {  // API 29+
    powerManager.addThermalStatusListener { status ->
        handleThermalStatusChange(status)
    }
}
private fun handleThermalStatusChange(status: Int) {
    when (status) {
        THERMAL_STATUS_MODERATE/SEVERE/CRITICAL →
            opticalFlowTracker?.updateConfig(OpticalFlowConfig.THERMAL_REDUCED)  // 31px, L3, 15fps
        THERMAL_STATUS_NONE/LIGHT →
            opticalFlowTracker?.updateConfig(OpticalFlowConfig.DEFAULT)           // 51px, L5, 30fps
    }
}
```

需同步新增：
- `OpticalFlowConfig.THERMAL_REDUCED` 物件（31px, maxLevel 3, 15fps）
- `OpticalFlowTracker.updateConfig()` 方法
