# **現代主流手機相機長寬比與技術分析報告**

在開發相機 App 或進行 AI 影像分析測試時，理解長寬比（Aspect Ratio）的物理限制與軟體裁切邏輯是確保 UI/UX 不變形、AI 偵測不偏移的關鍵。

## **1\. 主流長寬比概覽**

目前市面上主流手機（iPhone、Samsung Galaxy、Google Pixel 等）的內建相機 App 普遍支援以下四種比例：

| 比例 | 名稱 | 說明 |
| :---- | :---- | :---- |
| **4:3** | **標準 (Standard)** | **絕大多數手機感光元件（Sensor）的原生比例**。提供最高像素輸出。 |
| **16:9** | **寬螢幕 (Widescreen)** | 電視、YouTube 與多數社群媒體影片的標準比例。通常由 4:3 裁切而成。 |
| **1:1** | **正方形 (Square)** | Instagram 早期標準。常用於頭貼或特定社群排版。 |
| **Full / 20:9** | **全螢幕 (Full Screen)** | 根據手機螢幕實際比例填滿。常見於 19.5:9 或 21:9。 |

## **2\. 為什麼 4:3 和 16:9 是核心？**

### **A. 4:3：感光元件的物理真相**

* **硬體原生**：多數手機使用的 CMOS 感光元件（如 Sony IMX 系列或 Samsung ISOCELL）物理設計就是 4:3。  
* **畫質最優**：選擇 4:3 時，App 會讀取感光元件上所有的像素。若選擇其他比例，系統通常會對上下或左右進行「數位裁切 (Cropping)」。

### **B. 16:9：影片與視覺平衡**

* **影片標準**：HD、4K 影片的標準格式。  
* **構圖考量**：由於現代螢幕較長，16:9 在預覽時比 4:3 更具視覺張力，且能更好地適配影片錄製需求。

## **3\. 主流品牌設計邏輯**

* **Apple (iPhone)**：預設提供 4:3、16:9 與 1:1。值得注意的是，iPhone 的「全螢幕」預覽實際上是 4:3 的變體或特定裁切。  
* **Samsung / Android 旗艦**：通常在頂部選單直接標示 3:4、9:16、1:1 與 Full。  
* **全螢幕 (Full) 的陷阱**：Full 比例雖然視覺效果最好，但因為每款手機螢幕比例不同（如 19.5:9 或 21:9），這對 **AI 座標換算 (ML Kit)** 挑戰最大，因為它涉及了複雜的縮放與填滿（Fill vs Fit）計算。

## **4\. 對「AI 智能攝影師」APP 的開發建議**

針對您的專案，長寬比的選擇會直接影響 MlKitAnalyzer 的表現：

1. **AI 偵測建議使用 4:3**：  
   * 由於 4:3 是原生比例，影像不會經過二次處理或嚴重裁切，這能保留最多的畫面資訊供 AI 分析（如人臉特徵點）。  
2. **預覽與 UI 適配**：  
   * **直向 (9:16)**：這是目前短影音的主流，建議作為 App 的預設拍攝模式。  
   * **橫向 (16:9)**：適用於風景或電影感拍攝。  
3. **座標換算公式**：  
   * 如果您在 16:9 的畫面上繪製 NeuralFocusRing，但 AI 是在 4:3 的數據流上運算，務必確認 CoordinateTransform 的正確性，否則對焦環會出現偏移。  
4. **Veo 3 測試素材**：  
   * 如前所述，測試時應生成 **9:16 (直向)** 與 **16:9 (橫向)** 的影片，因為這涵蓋了 95% 使用者的實際使用場景。

## **5\. 結論**

現代手機相機確實以 **4:3 (拍照核心)** 與 **16:9 (錄影與視覺核心)** 為主。

在您的 APP 設計中，建議提供一個「智慧切換」功能：

* **拍照模式**：預設 4:3，確保畫質與 AI 分析精度。  
* **影片模式**：預設 16:9，提供沉浸式構圖引導。
